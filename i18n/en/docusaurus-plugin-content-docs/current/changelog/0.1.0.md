*릴리스: 2026-07-14*

Easy Mesh Editor의 첫 배포입니다. Unity 씬뷰 안에서 메쉬를 조형하고, 편집하고, 블렌드쉐이프와 스킨 웨이트를 다루는 네 개의 탭이 들어 있습니다.

## 새 기능

- **`스컬프트` 탭** — 엘라스틱 · 스무딩 · 평탄화 브러시로 표면을 직접 조형합니다. → [문서](/guides/sculpt#브러시)
- **`편집` 탭** — 정점 · 엣지 · 페이스 선택과 기즈모 변형, 삭제와 분리. → [문서](/guides/edit#요소-모드)
- **`블렌드쉐이프` 탭** — 표정 키를 만들고, 고치고, 이름을 바꾸고, 순서를 옮깁니다. → [문서](/guides/blendshape#목록)
- **`웨이트` 탭** — 본 트리에서 본을 고르고 씬뷰에서 웨이트를 칠합니다. → [문서](/guides/weight-paint#본-고르기)
- **Work Mesh 안전 모델** — `Bake` 전까지 원본 메쉬 에셋은 바뀌지 않습니다. → [문서](/internals/session-and-undo#work-mesh)
- **다중 메쉬 세션** — 토폴로지가 서로 다른 대상을 함께 열고 공용 기즈모로 변형합니다. → [문서](/guides/multi-mesh#활성-대상)
- **프로포셔널 편집** — 선택하지 않은 주변 정점이 반경 안에서 부드럽게 따라옵니다. → [문서](/guides/edit#프로포셔널-편집)
- **공간 기반 대칭** — 좌우 정점 수가 정확히 같지 않아도 대응점을 찾습니다. → [문서](/guides/sculpt#대칭)
- **아일랜드 마스크** — 건드리면 안 되는 덩어리를 클릭으로 잠가 둡니다. → [문서](/guides/sculpt#마스크-모드)
- **provenance 기반 저장** — 같은 원본에서 나온 출력은 GUID를 유지하며 갱신하고, 남의 에셋은 덮어쓰지 않습니다. → [문서](/reference/output-files#provenance와-owner)
- **3개 국어** — 한국어 / English / 日本語 UI와 탭별 내장 가이드.

## 문서

- 지원 범위는 Unity 2019.4.31f1 ~ 2022.3.22f1 입니다. → [문서](/getting-started/installation)
