*Release: 2026-07-14*

First release of Easy Mesh Editor. Includes four tabs for sculpting, editing, blend shapes, and skin weights in Unity's Scene view.

## New Features

- **`Sculpt` tab** — Sculpt surfaces directly with Elastic, Smooth, and Flatten brushes. → [docs](/guides/sculpt#브러시)
- **`Edit` tab** — Select vertices, edges, and faces; transform with gizmos; delete and separate. → [docs](/guides/edit#요소-모드)
- **`BlendShape` tab** — Create, edit, rename, and reorder expression keys. → [docs](/guides/blendshape#목록)
- **`Weight` tab** — Select bones and paint weights in the Scene view. → [docs](/guides/weight-paint#본-고르기)
- **Work Mesh safety model** — Original mesh asset doesn't change until `Bake`. → [docs](/internals/session-and-undo#work-mesh)
- **Multi-mesh sessions** — Open targets with different topology together and transform with shared gizmo. → [docs](/guides/multi-mesh#활성-대상)
- **Proportional editing** — Unselected nearby vertices smoothly follow within radius. → [docs](/guides/edit#프로포셔널-편집)
- **Space-based symmetry** — Finds corresponding points even if left/right vertex counts don't match exactly. → [docs](/guides/sculpt#대칭)
- **Island mask** — Click to lock parts you shouldn't touch. → [docs](/guides/sculpt#마스크-모드)
- **Provenance-based save** — Output from the same source keeps its GUID and updates; never touches others' assets. → [docs](/reference/output-files#provenance와-owner)
- **Three languages** — Korean / English / 日本語 UI and built-in guides per tab.

## Docs

- Support range is Unity 2019.4.31f1 ~ 2022.3.22f1. → [docs](/getting-started/installation)
