*Release: 2026-09-02*

## Things to Check When Upgrading

:::caution[Unused vertices are cleaned up at `Bake`]
Orphan vertices left after deleting faces are now removed from `Bake` output. Vertex indices change, so double-check if you have external tools relying on vertex indices. → [docs](/internals/bake#고아-정점-정리)
:::

:::caution[`Auto Normalize` option added to `Weight` tab]
Default is on, so behavior is the same as before. Turn off for pure add/subtract, allowing weight sums ≠ 1. → [docs](/guides/weight-paint#자동-정규화와-최대-영향-본-수)
:::

:::caution[`Alt+click` selects edge loops in `Edit` tab]
Only responds to click without dragging, so `Alt+drag` scene rotation is preserved. If you're used to clicking while holding `Alt`, selections may change. → [docs](/guides/edit#엣지-루프와-엣지-링)
:::

:::caution[Mesh object name in `Bake` output matches filename]
Mesh object's name inside the asset is matched to the filename. If you have scripts finding assets by mesh name string, double-check. → [docs](/internals/bake)
:::

## New Features

- **`G` / `R` / `S` modal transforms** — Blender-style move/rotate/scale with axis constraints and numeric input. → [docs](/guides/edit#모달-변형)
- **Edge loops and edge rings** — `Alt+click` for loop, `Ctrl+Alt+click` for ring. → [docs](/guides/edit#엣지-루프와-엣지-링)
- **Expand / shrink selection** — `Ctrl` + `+` / `-`. → [docs](/guides/edit#엣지-루프와-엣지-링)
- **Hide** — `H` · `Shift+H` · `Alt+H`. Not an undo target; auto-clears when structure changes. → [docs](/guides/edit#숨기기)
- **Four pivot modes** — `Median Point` · `Individual Origins` · `Active Element` · `Bounding Box Center`. → [docs](/guides/edit#피벗)
- **Normals display, flip, recalculate** — Flipping also reverses blend shape normal/tangent deltas. → [docs](/guides/edit#노멀)
- **`Merge by Distance`** — Preserves UV seams by not merging if UV0 differs. → [docs](/guides/edit#거리로-병합)
- **`Pinch (4)` and `Inflate (5)` brushes** added. → [docs](/guides/sculpt#브러시)
- **Brush mask and box mask** — Paint in radius and select by screen rectangle, plus island click. → [docs](/guides/sculpt#마스크-모드)
- **`Show Symmetry Plane`** — Draws mirror plane and opposite-side brush in Scene view. → [docs](/guides/sculpt#대칭)
- **`Brush Presets` 3 slots** — Save and load frequent brush settings. → [docs](/guides/sculpt#브러시-프리셋)
- **Mirror key generation** — Flip left/right notation in names to create opposite expression keys. → [docs](/guides/blendshape#미러-키)
- **Import keys from another mesh** — Transfer face expression keys by proximity mapping. → [docs](/guides/blendshape#키-전송)
- **Solo preview, key lock, prefix groups, delta heatmap, `Expand Range`** — Manage long lists. → [docs](/guides/blendshape#솔로-프리뷰)
- **Batch-select multiple keys** — Pick with `Ctrl` / `Shift` click to change values, lock, order, delete at once. → [docs](/guides/blendshape#다중-선택)
- **Import weights from another mesh** — Core clothing-fit operation: transfer avatar body weights to clothing. → [docs](/guides/weight-paint#다른-메쉬에서-웨이트-가져오기)
- **`Symmetric Paint`** — Paint corresponding bones on the opposite side too. → [docs](/guides/weight-paint#대칭-페인트)
- **`Merge Bone Weights`** — Move weights before deleting bones. → [docs](/guides/weight-paint#본-웨이트-합치기)
- **`Blur (4)` and `Average (5)` weight brushes** plus **bone lock**. → [docs](/guides/weight-paint#브러시)
- **`Max Bone Influences`** — Limit bones per vertex to 1~4. → [docs](/guides/weight-paint#자동-정규화와-최대-영향-본-수)
- **Unsaved badge** — `SAVED` · `UNSAVED` · `IN TRANSACTION`. → [docs](/guides/window#상태-배지)
- **`Load candidates` list** — Check vertex count and warn of duplicates and Read/Write issues before `Load`. → [docs](/guides/window#불러올-후보)
- **`Keys` shortcut sheet** — See current tab's shortcuts in Scene view. → [docs](/guides/window#단축키-시트)
- **Compact mode** — Auto-collapses header and guides when window height is tight. → [docs](/guides/window#컴팩트-모드)
- **Bake result table** — Arrange success/fail results when baking multiple meshes. → [docs](/guides/window)

## Changes

- Symmetry axis shortcuts unified to `Shift+Alt+X` / `Y` / `Z`. Solo keys reserved for Unity tool handles. → [docs](/reference/shortcuts#스컬프트)
- `R` is rotation modal only when you have selection and cursor is over Scene view; otherwise Unity's scale gizmo. → [docs](/reference/shortcuts#편집)
- Scene view status display cleaned up to not overlap target line. → [docs](/guides/window)
- Structural undo snapshots now have memory limit; oldest records dropped when exceeded and reported. → [docs](/internals/session-and-undo#되돌리기)

## Improvements

- Multi-mesh delete/separate/batch key operations bundled into one undo step; all-or-nothing rollback. → [docs](/guides/multi-mesh#원자적-롤백)
- Weight transfer warns if source/target transforms differ; offers bind-pose local space option. → [docs](/guides/weight-paint#전송-공간)
- Multi-frame key editing warns; intermediate frames update proportionally on save. → [docs](/guides/blendshape#다중-프레임)
- Multiple renderers using same source mesh output files don't overwrite each other. → [docs](/reference/output-files#provenance와-owner)
- Blend shape keys with invalid characters auto-cleaned on save. → [docs](/guides/blendshape#새-쉐이프-조형)
- Scene view picking and overlay skip off-screen elements; lighter on high-density meshes. → [docs](/limitations)
- `Bake` shows progress bar. → [docs](/internals/bake)
- Brush pressure sustained during stroke; values don't jitter. → [docs](/guides/sculpt#브러시-설정)

## Fixes

- **Painting weights once cut entire mesh to 4-slot** — now only painted weld groups convert; unpainted vertices with 5+ influences preserved. → [docs](/internals/bake#가변-본-웨이트)
- **Recompiling loses edits without warning** — now auto-saves before reload and restores after. → [docs](/internals/session-and-undo#자동-저장과-복원)
- **Undo delete/separate lost 5+ influences and UV4~UV7** — fixed. → [docs](/internals/session-and-undo#되돌리기)
- **Read/Write-off mesh `Load` broke renderer** — now shows guide and `Enable Read/Write` button, restores. → [docs](/getting-started/installation)
- **Editing existing key didn't update its normal deltas** — fixed. → [docs](/internals/bake)
- Undo past edit start invalidates transaction; silently cancel instead. → [docs](/internals/session-and-undo#트랜잭션)
- Runtime error on 8-bit color channel meshes using float colors — fixed. → [docs](/internals/bake)
- Failed separate now deletes partial `_Part.asset` and reverts fully. → [docs](/guides/edit#분리)
- Hide state persisting after delete/separate — fixed. → [docs](/guides/edit#숨기기)
- Flip normals didn't reverse blend shape normal/tangent deltas — fixed. → [docs](/guides/edit#노멀)
