# 最初の編集セッション

**このドキュメントを読むと**、選択から`Bake`まで一周できるようになり、`Tab`で編集を一時的に無効にする方法と`Revert`ですべてを元に戻す方法が理解できます。

## 1. 選択して`Load`

1. Hierarchyで編集するオブジェクトを1つ以上選択します。子に付いている`SkinnedMeshRenderer`と`MeshFilter + MeshRenderer`も一緒に検索されます。
2. `StudioRaming > Easy Mesh Editor`を開きます。
3. ターゲット行に`選択: {0}個のレンダラー（Loadを押してください）`が表示されるか確認し、`Load`をクリックします。

`Load`する前にどのレンダラーが検出されたかを見たい場合は、`読み込み候補`リストを展開してください。頂点数、ブレンドシェイプ数、`[ソース重複]`・`[Read/Write無効]`警告が各行に表示されます。行を1つクリックするとそのレンダラーのみを読み込みます。→ [ウィンドウの使い方](/guides/window#불러올-후보)

`Load`が完了するとヘッダー下の状態が`編集中: {0}`に変わります。この時点からレンダラーは元のメッシュではなくWork Meshを使用しています。

## 2. 編集

タブを選択して作業します。

| やりたいこと | タブ |
|---|---|
| 表面を押すか膨らませる | `スカルプト` → [ドキュメント](/guides/sculpt) |
| 頂点を移動またはフェイスを削除する | `編集` → [ドキュメント](/guides/edit) |
| 表情キーを作成する | `ブレンドシェイプ` → [ドキュメント](/guides/blendshape) |
| ボーンウェイトを塗画する | `ウェイト` → [ドキュメント](/guides/weight-paint) |

タブは自由に切り替えられます。選択、マスク、元に戻す履歴はタブを切り替えても保持されます。

元に戻すはUnityの`Ctrl+Z`そのものです。ブラシの1ストローク、ギズモの1回の変形、ウェイト作業1つ、構造変更1つが各ステップを構成します。→ [セッションと元に戻す](/internals/session-and-undo)

## 3. `Tab` — 編集を一時的に無効にする

シーンビューでカメラだけを回転させたいが、クリックがどうしても選択になってしまう場合があります。`Tab`を押すと編集入力のみが無効になります。セッションはそのまま生きています。

編集が無効である間、ウィンドウはこのように通知します。

> `編集は一時的にオフです。作業内容は保持されています — 「編集」トグルまたはシーンビューの「編集を再開」で続行。`

再度有効にするには、`Tab`をもう一度押すか、シーンビューの`編集を再開`ボタン、またはウィンドウの`編集（Tab）`トグルをクリックします。

:::note[`Tab`はセッションを破棄しません]
編集を終了するのは`Bake`または`Revert`のみです。`Tab`は入力スイッチです。
:::

## 4. 未保存バッジを確認

ヘッダーのバッジが現在の状態を示しています。

| バッジ | 意味 |
|---|---|
| `保存済み` | `Load`以後、変更がありません |
| `未保存の変更` | 保存されていない編集があります |
| `編集確定待ち` | ブレンドシェイプ編集がまだ確定されていません |

`編集確定待ち`の場合、`Bake`がブロックされます。画面に固定されたバーで`Enter`（保存）または`Esc`（キャンセル）で先に終了してください。→ [ブレンドシェイプ](/guides/blendshape#기존-키-편집)

## 5. `Bake`で保存

`全変更を最終保存`セクションの`Bake`をクリックします。

- 元の横に`<元名>_Edit.asset`が作成され、レンダラーがそのアセットを使用するようになります。
- どの三角形からも参照されない頂点が残っている場合、この時点で1回整理されます。
- セッションが終了します。続けて作業する場合は、再度`Load`する必要があります。

複数のメッシュを一緒に編集した場合、`Bake結果（{0}/{1} 成功）`テーブルが表示されます。失敗したセッションは保持されるため、原因を修正して再度試行できます。→ [生成されるファイル](/reference/output-files)

:::caution[`Bake`は最後に1回]
ウィンドウは`作業をすべて終わらせてから1回だけ実行してください。`と案内しています。中間保存が必要な場合は`新規キーとして保存`（クイックブレンドシェイプキャプチャ）を使用してください — こちらはセッションを終了せず、アセットもまだ変更しません。
:::

## 6. `Revert` — すべてを破棄

`Revert`は`すべての編集を破棄して元に戻します。続行しますか？`を確認した後、レンダラーを元のメッシュに復元します。すでに`Bake`で作成されたアセットは削除されません。

ウィンドウを閉じるか、プレイモードに入ろうとする時も、保存されていない編集がある場合は`Bake` / `破棄`（プレイモードは`キャンセル`も含む）が表示されます。
