# 最初の編集セッション

**このページを読むと** 対象を選んでから `メッシュ保存` までの一連の流れを試せます。また、`Tab` で編集入力を一時的に止める方法と、`編集を破棄` ですべてを元に戻す方法がわかります。

## 1. 選んで `読み込み`

1. Hierarchy で編集するオブジェクトを 1 つ以上選びます。子に付いている `SkinnedMeshRenderer` と `MeshFilter + MeshRenderer` も一緒に見つかります。
2. `StudioRaming > Easy Mesh Editor` を開きます。
3. 開始カードに `対象を選ぶ → 読み込み → モード選択 → メッシュ保存` の順番が表示されます。対象の行に見つかったレンダラーの数が出たら、`読み込み` を押します。

読み込む前にどのレンダラーが見つかったかを確認したい場合は、`読み込み候補` の一覧を開きます。行ごとに名前、頂点数、キー数、警告が表示されます。行を 1 つクリックすると、そのレンダラーだけを読み込みます。選択を外すと候補すべてを読み込みます。→ [ウィンドウの使い方](/guides/window#불러올-후보)

読み込みが終わると編集の状態になります。この時点からレンダラーは元のアセットではなく Work Mesh を使っています。

## 2. 編集する

タブを選んで作業します。

| やりたいこと | タブ |
|---|---|
| 表面を押したりふくらませたりする | `形を整える` → [ページ](/guides/sculpt) |
| 頂点を動かす、フェイスを削除する | `選択・移動` → [ページ](/guides/edit) |
| 表情キーを作る | `表情キー` → [ページ](/guides/blendshape) |
| ボーンウェイトを塗る | `ボーン接続` → [ページ](/guides/weight-paint) |

タブは自由に行き来できます。`Ctrl+Tab` で次のタブ、`Ctrl+Shift+Tab` で前のタブに移動します。選択、マスク、元に戻す履歴はタブを移動しても残ります。

元に戻すには `Ctrl+Z` を使います。ブラシの 1 ストローク、ギズモの 1 回の変形、ウェイト操作 1 回、構造変更 1 回が、それぞれ 1 段階です。→ [セッションと元に戻す](/internals/session-and-undo)

## 3. `Tab`: 編集を一時的に止める

シーンビューでカメラだけを動かしたいのに、クリックがすぐに選択として扱われてしまうことがあります。`Tab` を押すと編集の入力だけがオフになります。セッションはそのまま残ります。

もう一度編集を有効にするには、`Tab` をもう一度押すか、シーンビューに表示される編集開始ボタンを押します。

:::note[`Tab` ではセッションは破棄されません]
編集を終わらせるのは `メッシュ保存` と `編集を破棄` だけです。`Tab` は入力のスイッチです。
:::

## 4. 未保存バッジを確認する

対象の行にあるバッジで、今の状態がわかります。

| バッジ | 意味 |
|---|---|
| `保存済み` | `読み込み` の後で変更したものはありません |
| `未保存の変更` | 保存されていない編集があります |
| `編集確定待ち` | 表情キーの編集がまだ確定していません |

バッジが `編集確定待ち` の間は、`メッシュ保存` が使えません。ウィンドウ上部に固定されたバーで、先に `保存`（キー編集の確定）か `キー編集を取消` を押してください。→ [表情キー](/guides/blendshape#기존-키-편집)

## 5. `メッシュ保存` で仕上げる

すべての作業が終わったら `メッシュ保存` を押します。

- 元のアセットの隣に `<元の名前>_Edit.asset` ができ、レンダラーがそのアセットを使うようになります。
- どのポリゴンからも使われていない頂点は、このときに 1 回整理されます。
- セッションが終わります。続けて作業するには、もう一度 `読み込み` を押します。

複数のメッシュをまとめて編集した場合は、対象ごとの結果表が表示されます。保存に失敗した対象のセッションは残るので、原因を直して再度試せます。→ [生成されるファイル](/reference/output-files)

:::caution[`メッシュ保存` は最後に 1 回だけ]
途中で保存したい場合は `新規キーとして保存` を使ってください。こちらはセッションを終わらせず、アセットもまだ変更しません。→ [表情キーのクイックキャプチャ](/guides/blendshape#빠른-캡처와-bake)
:::

## 6. `編集を破棄`: すべて捨てる

`編集を破棄` は、現在の編集をすべて捨てて、レンダラーを元のメッシュに戻します。実行前に確認を求めます。確認ダイアログでは `Enter` と `Esc` のどちらを押しても作業はそのまま残ります。操作名の書かれたボタンを押したときだけ実行されます。`メッシュ保存` で作成済みのメッシュは削除されません。

ウィンドウを閉じたり、プレイモードに入ったりしても、保存していない編集については確認は出ません。編集内容は保持されます。プレイモード中は元のメッシュが表示され、編集モードに戻ると編集内容が復元されます。→ [セッションと元に戻す](/internals/session-and-undo#자동-보존과-복원)
