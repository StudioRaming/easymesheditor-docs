# インストール

**このページを読むと** 対応する Unity のバージョン、`.unitypackage` とフォルダーコピーの 2 つの導入方法、一緒に入れておく必要があるファイル、DLL 版とソース版を同時に入れたときに出るエラー、そして 0.1.x からの移行方法がわかります。

## 1. 対応範囲

| 項目 | 内容 |
|---|---|
| 製品バージョン | `1.0.0` |
| 対応 Unity | **Unity 2019.4 ~ Unity 6（6000.0、6000.3 LTS）** |
| 直接コンパイルで確認したバージョン | `2019.4.31f1` · `2021.3.45f2` · `2022.3.22f1`（警告をエラーとして扱うビルド） |
| レンダーパイプライン | Built-in Render Pipeline · URP |
| 実行範囲 | Unity Editor 専用 |

上記のすべてのバージョンで、1 つの DLL が動作します。バージョンごとの分岐はなく、同じファイルを使います。コードは Unity 2019.4 の公開 API と C# 7.3 を下限としています。

頂点あたり 4 つを超えるボーン影響（可変ボーンウェイト）は、2019.4 にも存在する公開 API（`GetAllBoneWeights` / `SetBoneWeights`）で読み書きします。詳しくは [Bake の内部動作](/internals/bake#가변-본-웨이트)を見てください。

:::note[シェーダーではありません]
Easy Mesh Editor はメッシュデータを編集するエディターツールです。アバターに使うシェーダーやマテリアルはそのままにしてください。BRP と URP のどちらでも動作します。
:::

## 2. `.unitypackage` でインストール

1. Unity で `Assets > Import Package > Custom Package` を選び、配布された `EasyMeshEditor_v1.0.0.unitypackage` を開きます。
2. `Assets/StudioRaming/EasyMeshEditor` の下のファイルを**すべて** Import します。
3. メニューから `StudioRaming > Easy Mesh Editor` を開きます。

## 3. フォルダーを直接コピーしてインストール

`Assets/StudioRaming/EasyMeshEditor` フォルダー全体を、プロジェクトの同じ場所にコピーします。次のファイルは必ず一緒にある必要があります。

- `README.md`
- `Editor/EasyMeshEditor.Editor.dll` とその `.meta`
- `Editor/Shaders/EmeOverlay.shader`
- `Editor/Shaders/EmeSceneGL.shader`

:::caution[シェーダーを 2 つ欠くと、シーンビューに何も表示されません]
2 つのシェーダーは、シーンビューのオーバーレイ、X-Ray、頂点・ボーン・ウェイトの表示に使われます。DLL だけをコピーするとツールは読み込まれますが、シーンビューの表示が正しく動作しません。
:::

## 4. DLL 版とソース版を一緒に入れないでください {#4-dll판과-소스판을-함께-넣지-마세요}

ソースの `.cs` が残っているプロジェクトに DLL 版を入れると、**同じクラスが 2 回定義され、コンパイルエラー**になります。どちらか一方だけをインストールしてください。

`メッシュ保存` で作られた `_Edit.asset` や `_Part.asset` は元のメッシュの隣にできるため、ここで削除するファイルではありません。→ [生成されるファイル](/reference/output-files)

## 5. 0.1.x からの更新 {#0-1x에서-올리기}

**0.1.x をお持ちの方は 1.0.0 に無料でアップデートできます。**

編集セッションを開いたままアップデートしないでください。開いている編集は `メッシュ保存` で保存するか `編集を破棄` で捨て、Easy Mesh Editor のウィンドウを閉じてから、アップデートします。

既存の `Assets/StudioRaming/EasyMeshEditor` フォルダーの上から 1.0.0 を上書きインポートします。0.1.x からアップデートするときに、ほかに削除するファイルはありません。例外は、ソース（`.cs`）版を入れていたプロジェクトです。この場合は、先にソース版を削除してください。このフォルダーの中に自分で作ったファイルがある場合は、先に外へ移してください。

すでに `_Edit.asset` を使っているレンダラーを再度 `読み込み` して `メッシュ保存` を押すと、1.0 が作った出力は同じファイルを GUID を保ったまま更新します。0.1.x が作った `_Edit.asset` には所有の記録がないため更新されず、隣に新しいファイル `<元の名前>_Edit 1.asset` が作られます。0.1.x で保存した `_Edit.asset` はそのまま残り、引き続き動作します。新しいファイルには新しい GUID が付くため、古いファイルを参照しているプレハブやアニメーションは、新しいファイルへ参照を向け直す必要があります。

## 6. ウィンドウを開く

`StudioRaming > Easy Mesh Editor`

ウィンドウはドッキングできます。開くと対象がないことが表示されます。Hierarchy でオブジェクトを選ぶと、対象の行が埋まります。→ [最初の編集セッション](/getting-started/first-session)

## 7. メッシュの Read/Write がオフになっている場合 {#7-메쉬가-readwrite-꺼짐이라면}

インポートした FBX のメッシュは、既定で Read/Write がオフになっていることがあります。そのようなメッシュを `読み込み` しようとすると、ウィンドウが Read/Write がオフであることを示し、ステータス行に `Read/Writeを有効化` ボタンが表示されます。ボタンを押すとモデルのインポーター設定が有効になり、再インポートされます。自動で変更できないモデルでは、元のファイルの Import Settings で手動でオンにしてください。

設定をオンにしただけでは編集セッションは開きません。設定をオンにしたあと、もう一度 **読み込み** を押してください。

## 8. 言語を変える

ウィンドウで 한국어 / English / 日本語 から選びます。最初に開くときは Unity Editor のシステム言語に従います。韓国語なら韓国語、日本語なら日本語、それ以外は英語になります。
