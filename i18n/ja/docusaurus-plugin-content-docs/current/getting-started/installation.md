# インストール

**このドキュメントを読むと**、サポートされているUnityバージョン、`.unitypackage`とフォルダコピーの2つのインストール方法、必ず一緒に含まれなければならないファイル、DLL版とソース版を重ねた場合に発生するエラーについて理解できます。

## 1. サポート範囲

| 項目 | 内容 |
|---|---|
| 製品バージョン | `0.1.1` |
| サポートUnity | **2019.4.31f1 ~ 2022.3.22f1** |
| 直接コンパイルを検証したバージョン | `2019.4.31f1` · `2021.3.45f2` · `2022.3.22f1` |
| レンダーパイプライン | Built-in Render Pipeline · URP |
| 実行対象 | UnityEditor専用 |

コードはUnity 2019.4パブリックAPIとC# 7.3を最小限に使用しています。頂点ごと5つ以上のボーン影響を処理する[可変ボーンウェイト](/internals/bake#가변-본-웨이트)APIは2020.1以上でのみ提供されるため、前処理分岐で分かれています。2019.4ではレガシーな4スロットのみを処理します。

:::note[シェーダーではありません]
Easy Mesh Editorはメッシュデータを編集するエディターツールです。アバターで使用するシェーダーやマテリアルはそのまま保たれ、BRP・URP両方で動作します。
:::

## 2. `.unitypackage`でインストール

1. Unityで`Assets > Import Package > Custom Package`を選択して、提供された`.unitypackage`を開きます。
2. `Assets/StudioRaming/EasyMeshEditor`以下のファイルを**すべて**インポートします。
3. メニューから`StudioRaming > Easy Mesh Editor`を開きます。

## 3. フォルダを直接コピーしてインストール

`Assets/StudioRaming/EasyMeshEditor`フォルダ全体をプロジェクトの同じ場所にコピーします。以下のファイルは必ず一緒に必要です。

- `README.md`
- `Editor/EasyMeshEditor.Editor.dll`とその`.meta`
- `Editor/Shaders/EmeOverlay.shader`
- `Editor/Shaders/EmeSceneGL.shader`

:::caution[2つのシェーダーを忘れると画面に何も表示されません]
2つのシェーダーはシーンビューオーバーレイ、X-Ray、頂点・ボーン・ウェイトヒートマップ表示に使用されます。DLLだけをコピーするとツールはロードされますが、シーンビュー表示が正常に動作しません。
:::

## 4. DLL版とソース版を一緒に入れないでください

ソース`.cs`が残っているプロジェクトにDLL版を一緒に入れると、**同じクラスが2回定義されてコンパイルエラー**が発生します。どちらか一方だけをインストールしてください。

以前のバージョンに上書きする代わりに、既存の`Assets/StudioRaming/EasyMeshEditor`フォルダを削除して新しくインポートする方が安全です。フォルダ内に直接作成したファイルがある場合は、先に外に移動してください。

`Bake`で作成された`_Edit.asset`・`_Part.asset`は元のメッシュの横に生成されるため、この削除対象ではありません。→ [生成されるファイル](/reference/output-files)

## 5. ウィンドウを開く

`StudioRaming > Easy Mesh Editor`

ウィンドウはドッキング可能です。開くと、すぐに`対象なし — オブジェクトを選択してLoad`状態で始まり、Hierarchyでオブジェクトを選択するとターゲット行が埋まります。→ [最初の編集セッション](/getting-started/first-session)

## 6. メッシュのRead/Writeが無効な場合

インポートされたFBXのメッシュは、デフォルトではRead/Writeが無効な場合があります。そのようなメッシュを`Load`しようとすると、ウィンドウは`メッシュはRead/Write無効です。インポート設定でRead/Writeを有効にしてください。`を表示し、その場所に`Read/Writeを有効化`ボタンが一緒に表示されます。ボタンをクリックするとモデルインポーターの設定を有効にして再度インポートします。

## 7. 言語を変更

ウィンドウの右上で、日本語 / English / 한국어を選択します。初めて開く時はUnityエディターのシステム言語に従います — 日本語なら日本語、韓国語なら韓国語、その他は英語です。
