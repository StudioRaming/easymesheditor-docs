# ショートカット

**このドキュメントを読むと**、タブ別にどのキーが何をするかを1つの表から探せます。ウィンドウ内で同じ内容を見るにはシーンビューのヒントバーの`Keys`ボタンをクリックしてください。→ [ショートカットシート](/guides/window#단축키-시트)

:::note[シーンビューでのみ動作します]
ここに記載されたキーはシーンビューにマウスカーソルがあるときに処理されます。テキスト入力中には傍受されず、Unityのグローバルショートカットプロファイルも変更しません。
:::

## 共通 {#공통}

すべてのタブで動作します。

| キー | 動作 |
|---|---|
| `Tab` | `編集の切り替え` |
| `Ctrl+Tab` | `ツールタブを巡回`（次のタブ） |
| `Ctrl+Shift+Tab` | 前のタブ |
| `Ctrl+Z` / `Ctrl+Y` | `元に戻す / やり直し` |
| `Enter` / `Esc` | `トランザクション確定 / 取消` |
| `[` / `]` | `ブラシサイズ` |
| `<` `>` `,` `.` | `ブラシ強度` |
| `Alt+Z` | X-Ray切り替え |

`<` `>` は `,` `.`と同じキーです。`Shift`を押しても同様に動作します。

## スカルプト {#스컬프트}

| キー | 動作 |
|---|---|
| `1` / `2` / `3` | `エラスティック / スムーズ / フラット化ブラシ` |
| `4` / `5` | `ピンチ / インフレートブラシ` |
| `[` / `]` | `ブラシ半径を縮小／拡大` |
| `,` / `.` | `ブラシ強度を下げる／上げる` |
| `F` / `Shift+F` | `マウスで半径 / 強度を調整（クリック確定、Esc取消）` |
| `Shift`（押している間） | `押している間だけスムーズブラシ` |
| `Ctrl`（押している間） | `押している間だけブラシ方向を反転` |
| `Shift+Alt+X` / `Y` / `Z` | 軸対称を切替 |
| `M` | `マスクモードの切替` |
| `Ctrl+I` | `マスクを反転` |
| `Alt+M` | `マスク全解除` |
| `Alt+Z` | `X-Ray切替` |

:::caution[`Keys`シートの対称表記が実際と異なります]
0.1.1の`Keys`シートは対称を`X / Y / Z` · `Alt+X / Y / Z`と記載していますが、実際に動作するのは`編集`タブと同じ`Shift+Alt+X` / `Y` / `Z`です。単独の`X` `Y` `Z`とそれぞれUnityのツールハンドルショートカットとX-Rayとして保持しているため傍受しません。ウィンドウの`対称`チェックボックスでも有効にできます。
:::

## 編集 {#편집}

| キー | 動作 |
|---|---|
| `1` / `2` / `3` | `頂点 / エッジ / フェイスモード` |
| `Q` / `W` / `E` / `R` | `ビュー / 移動 / 回転 / スケールギズモ` |
| `G` / `R` / `S` | `マウス操作のモーダル変形（選択必要）` |
| `X` / `Y` / `Z`（モーダル中） | `モーダル中の軸拘束（2回=ワールド、Shift+軸=平面、数字=数値）` |
| `Alt+クリック`（ドラッグしない） | `エッジループ` |
| `Ctrl+Alt+クリック` | エッジリング（`Shift`併用 = 追加） |
| `Ctrl` + `+` / `-` | `選択の拡張 / 縮小` |
| `H` / `Alt+H` / `Shift+H` | `隠す / 全表示 / 選択以外を隠す` |
| `A` / `Alt+A` / `Ctrl+I` | `全選択 / 解除 / 反転` |
| `B` / `L` / `O` | `ボックス選択 / リンク選択 / プロポーショナル` |
| `Shift+L` | リンク選択を解除 |
| `X` / `Delete` / `Backspace` | 選択削除 |
| `P` / `Shift+P` | `選択を分離 / アイランド分離` |
| `Esc` | ボックス選択待機解除、または選択解除 |
| `Alt+Z` | X-Ray |
| `Shift+Alt+X` / `Y` / `Z` | 軸対称を切替 |
| `[` / `]` | プロポーショナル有効時は半径、頂点モード時は頂点表示サイズ |

:::caution[`R`は状況で2つのことをします]
`R`は**選択があり、カーソルがシーンビュー上にあるときのみ**回転モーダルです。それ以外はUnity式`R` = スケールギズモです。
:::

:::caution[`Alt+ドラッグ`はシーン回転のままです]
エッジループ選択は`Alt`を押した状態で**動かさず**クリックしたときのみ発生します。少しでもドラッグするとカメラが通常通り回転します。
:::

## ブレンドシェイプ {#블렌드쉐이프}

このタブは`Keys`シートに独自の一覧を登録していないため、`このタブに登録されたショートカットはありません。`が表示されます。実際に動作するキーは下記の通りです。

| キー | 動作 | 条件 |
|---|---|---|
| `N` | 新規シェイプ造形開始 | 造形・編集中でないとき |
| `Esc` | ソロプレビュー解除 | トランザクションなし、ソロ有効時 |
| `Enter` | 造形保存 | 造形中 |
| `Esc` | 造形キャンセル | 造形中 |
| `F` / `Shift+F` | 半径 / 強度モーダル | 造形中 |
| `[` / `]` · `,` / `.` | 半径 / 強度 | 造形中 |
| `Shift`（押している間） | スムーズブラシ | 造形中 |
| `Alt+Z` | X-Ray | |

## ウェイト {#웨이트}

| キー | 動作 |
|---|---|
| `1` / `2` / `3` | `加算 / 減算 / スムーズブラシ` |
| `4` / `5` | `ブラー / 平均ブラシ` |
| `[` / `]` | `ブラシ半径を縮小／拡大` |
| `,` / `.` | `ブラシ強度を下げる／上げる` |
| `F` / `Shift+F` | `マウスで半径 / 強度を調整（クリック確定、Esc取消）` |
| `Shift`（押している間） | `押している間だけスムーズブラシ` |
| `Ctrl`（押している間） | `押している間だけ加算 / 減算を反転` |
| `N` | `全体を正規化` |
| `K` | `チェック済みボーンのスムーズを適用` |
| `Ctrl+クリック` | `シーンでアクティブボーンを指定／解除` |
| `Ctrl+Shift+クリック` | `シーンでスムーズ対象チェックを切替` |
| `Alt+Z` | `X-Ray切替` |

:::note[`対称ペイント（X）`はキーではありません]
ラベルに`（X）`が付いていますが、現在のバージョンではこのオプションは**ウィンドウのチェックボックスのみで**有効/無効になります。→ [対称ペイント](/guides/weight-paint#대칭-페인트)
:::

`K`はチェック済みボーンがない場合は何もしません。
