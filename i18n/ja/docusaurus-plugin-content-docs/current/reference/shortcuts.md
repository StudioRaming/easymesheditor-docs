# ショートカット

**このページを読むと** タブごとに、どのキーが何をするかを 1 つの表で見つけられます。ウィンドウ内で同じ内容を見るには、シーンビューのヒントバーにある `Keys` ボタンを押してください。→ [ショートカットシート](/guides/window#단축키-시트)

:::note[シーンビューでのみ動作します]
ここに挙げたキーは、マウスがシーンビューの上にあるときに処理されます。テキスト入力中は横取りせず、Unity のグローバルな Shortcut プロファイルも変更しません。
:::

## 共通 {#공통}

すべてのタブで動作します。

| キー | 役割 |
|---|---|
| `Tab` | 編集入力のオン・オフ。セッションは保持されます |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 次のタブ / 前のタブ |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直し |
| `Enter` | 表情キーの編集を保存（取り消しは固定バーのボタン） |
| `Alt+Z` | X-Ray のオン・オフ |

## 形を整える {#모양-다듬기}

| キー | 役割 |
|---|---|
| `1` / `2` / `3` / `4` / `5` | 引っぱる / なめらかに / 平らに / 寄せる / ふくらませる |
| `[` / `]` | ブラシの半径を小さく / 大きく（×0.9） |
| `,` / `.`（`<` / `>`） | ブラシの強さを下げる / 上げる（±0.05） |
| `F` / `Shift+F` | マウスで半径 / 強さを調整（クリックで確定、`Esc` で取り消し） |
| `Shift`（押している間） | 一時的になめらかに |
| `Ctrl`（押している間） | ブラシの方向を反転 |
| テンキーの `.` | 選択範囲を表示（編集中のメッシュを画面に収めます） |
| `Alt+Shift+X` / `Y` / `Z` | 軸の対称をオン / オフ |
| `M` | マスクモード |
| `Ctrl+I` | マスクを反転 |
| `Alt+M` | マスクを全解除 |

:::caution[`X` `Y` `Z` だけを押しても対称はオンになりません]
対称のショートカットは `Alt+Shift+X` / `Y` / `Z` です。単独の `X` `Y` `Z` は Unity のツールハンドルのショートカットとして残るため、このツールは横取りしません。ウィンドウの `対称` のチェックボックスでもオンにできます。
:::

## 選択・移動 {#선택-이동}

| キー | 役割 |
|---|---|
| `1` / `2` / `3` | 頂点 / エッジ / フェイスモード |
| `A` / `Alt+A` / `Ctrl+I` | すべて選択 / 解除 / 反転 |
| `B` | ボックス選択（`Shift` で追加、`Ctrl` で除外） |
| `L` / `Shift+L` | 連結要素を選択 / 選択解除 |
| `Alt+クリック` | エッジループ（ドラッグしていないクリックのみ） |
| `Ctrl+Alt+クリック` | エッジリング（`Shift` を併用すると追加） |
| `Ctrl` + `+` / `-` | 選択を拡張 / 縮小 |
| `Esc` | 選択を解除 |
| `Q` / `W` / `E` / `R` | 表示 / 移動 / 回転 / スケールのギズモ |
| `G` / `R` / `S` | マウスでモーダル移動 / 回転 / スケール（選択が必要です） |
| モーダル中の `X` `Y` `Z` | 軸で拘束。もう一度押すとワールド軸 |
| モーダル中の `Shift` + 軸 | 平面で拘束 |
| モーダル中の数字 / `Enter` / `Esc` | 正確な値を入力 / 確定 / 取り消し |
| `O` | プロポーショナル編集のオン / オフ |
| `[` / `]` | プロポーショナルの半径（プロポーショナル編集がオフのときは頂点の表示サイズ） |
| `Alt+Shift+X` / `Y` / `Z` | 軸の対称をオン / オフ |
| `H` / `Shift+H` / `Alt+H` | 選択を非表示 / 選択外を非表示 / すべて表示 |
| `P` / `Shift+P` | 選択を分離 / アイランドを分離 |
| `X` または `Delete` | 選択を削除 |

:::caution[`R` は状況によって 2 つのどちらかになります]
`R` は、選択があり、カーソルがシーンビューの上にあるときだけ回転のモーダルになります。それ以外では、Unity 標準の `R`（スケールギズモ）として動作します。
:::

:::caution[`Alt+ドラッグ` は従来どおりシーンの回転です]
`Alt` を使ったループ選択は、3px 未満しか動かなかったクリックでのみ行われます。それより大きくドラッグすると、通常どおりカメラが回転します。
:::

`Ctrl` や `Cmd` を含む組み合わせ（`Ctrl+P`、`Ctrl+R`、`Ctrl+X` など）は Unity のショートカットとして残り、選択・移動の操作は実行されません。例外は `Ctrl+A`、`Ctrl+I`、`Ctrl` + `+` / `-` です。

## 表情キー {#표정-키}

| キー | 役割 |
|---|---|
| `N` | 新しいキーの造形を開始 |
| `Enter` | キー編集を保存 |
| `Esc` | ストロークの取り消し、またはソロの解除。キー編集は破棄しません |
| `F` / `Shift+F` / `[` / `]` / `,` / `.` | キーの造形中の半径と強さ |
| `Shift`（押している間） | 一時的になめらかに |

## ボーン接続 {#뼈-연결}

| キー | 役割 |
|---|---|
| `1` / `2` / `3` / `4` / `5` | 加算 / 減算 / スムーズ / ブラー / 平均 |
| `N` | すべて正規化 |
| `K` | 選択ボーンのスムーズ（チェックしたボーンがなければ何もしません） |
| `Ctrl+クリック` | シーンビューでアクティブボーンを設定 / 解除 |
| `Ctrl+Shift+クリック` | シーンビューでスムーズ対象のチェックをオン / オフ |
| `[` / `]` / `,` / `.` / `F` / `Shift+F` | 半径と強さの調整（形を整えると同じ） |
| `Shift`（押している間） | 一時的なスムーズ |
| `Ctrl`（押している間） | 加算と減算を反転 |

:::note[`対称ペイント` にはキーがありません]
ラベルには `(X)` が付いていますが、現在のバージョンでは、このオプションはウィンドウのチェックボックスでのみオン・オフします。→ [対称ペイント](/guides/weight-paint#대칭-페인트)
:::
