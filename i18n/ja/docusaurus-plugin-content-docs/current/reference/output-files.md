# 生成されるファイル

**このドキュメントを読むと**、このツールがプロジェクトで何を作成するか、既存ファイルを更新する場合と新しいファイルを作成する場合の違いは何か、そして他人のアセットを絶対に上書きしない理由が理解できます。

## 3つの種類

| パス | タイミング | バージョン管理 |
|---|---|---|
| `<元名>_Edit.asset` | `Bake` | コミット対象 |
| `<元名>_Part.asset` | `選択を分離（P）` · `アイランド分離（Shift+P）` | コミット対象 |
| `Library/EmeAutoSave/<id>.asset` | ドメインリロード直前に自動保存 | コミット対象ではない |

最初の2つは**元のメッシュアセットの隣**に作成されます。3番目は`Library/`の下にあるため、Unityはキャッシュとして扱い、バージョン管理から除外します。

## `_Edit.asset`

`Bake`が作成する最終メッシュアセットです。作成されると即座にレンダラーがこのアセットを使用するようになります。

含まれるもの：頂点、法線、接線、UV0～UV7、カラー、サブメッシュ・マテリアル対応、bindpose、ボーンウェイト（2020.1+の可変ボーンウェイト含）、全ブレンドシェイプフレーム。

`Bake`プロセス中、どの三角形からも参照されない頂点は1回整理されます — `未使用の頂点 {0}個を整理しました`。→ [Bake内部](/internals/bake)

アセット内のメッシュオブジェクト名はファイル名と一致するように設定されます。

## `_Part.asset`

`編集`タブで分離するときに作成されます。新しいGameObjectがシーンに表示され、そのレンダラーがこのアセットを使用します。

分離が途中で失敗すると、作成中の`_Part.asset`は削除され、元のデータはそのまま残ります — `分離に失敗したため元に戻しました: {0}`

## provenance と owner {#provenance와-owner}

出力アセットには**どこから来たか**を示すマーク が一緒に保存されます。このマークが以下の2つを決定します。

1. 再度`Bake`したときに**同じファイルを更新するか、新しいファイルを作成するか**
2. 名前が重複する**他人のアセットに絶対に手を加えないこと**

マークは`<元メッシュ GUID>:<localId>@<レンダラー owner トークン>`形式です。

| 状況 | 結果 |
|---|---|
| 同じソース、同じレンダラーから再度`Bake` | 既存の`_Edit.asset`を**GUIDを保持したまま更新** |
| 同じソースメッシュを使う別のレンダラー | 別の出力ファイルを作成 |
| 同じ名前の他人のアセットがすでに存在 | 上書きしない、ユニークなパスを新規作成 |

GUIDが保持されることが重要です。プリファブ・アニメーション・別のシーンがそのメッシュを参照していても、参照が切れません。

すでに`Bake`したアセットを使うレンダラーを再度`Load`して作業を続けると、その出力を更新し、同じアセットを使う他のロードされたレンダラーも新しいデータで同期します。

:::caution[シーンを保存しないとレンダラーを区別できません]
ownerトークンはレンダラーのグローバルIDから来ます。シーンが保存されたことがない場合、そのIDがないためウィンドウが通知します。

> `シーンが未保存のためレンダラーを識別できません。同じソースメッシュを使うレンダラーが複数ある場合、シーンを保存するまで同じ出力ファイルを共有します。`

同じメッシュを共有するレンダラーが複数ある場合は、作業前に1度シーンを保存してください。
:::

## `Library/EmeAutoSave/` {#자동-저장-폴더}

エディターがスクリプトを再度コンパイルする直前にWork Meshがここに直列化され、リロード後に自動的に復元されます。

- 復元成功時: `Easy Mesh Editor: 自動保存した編集セッションを復元しました（{0}）`
- 失敗時: `Easy Mesh Editor: 自動保存 {0}件を復元できませんでした。ファイルは保持しています: {1}` — ファイルは削除されないため、原因を確認できます。

これは**作業の最終出力ではなく、安全網**です。最終保存は常に`Bake`です。→ [セッションと元に戻す](/internals/session-and-undo#자동-저장과-복원)

## 保存前にブロックされるもの

不正なデータはファイルに出力される前に除外されます。

- NaN / Infinity座標
- トポロジー不一致
- ウェイト配列長の不一致

失敗したセッションは**閉じられず、保持**されるため、原因を修正して再度`Bake`できます。

## 削除してもよいもの

| ファイル | 削除してもよいか |
|---|---|
| `_Edit.asset` | レンダラーが使用していれば不可。元に戻してから削除してください |
| `_Part.asset` | そのパートオブジェクトを削除した後なら可 |
| `Library/EmeAutoSave/` | いつでも可。復元するセッションがなくなるだけ |
