# 設定項目

**このドキュメントを読むと**、ウィンドウのどの値が次に開くまで記憶されるか、どの値がセッションと共に消滅するかが理解できます。

## 記憶される値と消える値

ほぼすべての操作設定は**UnityエディターのEditorPrefs**に保存されます。プロジェクトを閉じて再度開くか、別のプロジェクトを開いても、そのまま残ります。

反対に**編集状態**（選択、マスク、隠す、undo履歴、ブレンドシェイプ値）はセッションに属します。`Bake`または`Revert`でセッションが終了すると消滅します。→ [セッションと元に戻す](/internals/session-and-undo)

キーロック状態は例外的にプロジェクト単位（EditorUserSettings）に保存されます。

## ウィンドウ共通

| 項目 | デフォルト値 |
|---|---|
| 言語 | エディターシステム言語（日本語ならそれ、韓国語ならそれ、その他は英語） |
| `Keys`シート開閉 | 閉じた状態 |
| アクティブタブ | スカルプト |

## 設定をリセットするには

個別の項目はウィンドウで元に戻すことで対応します。すべてをデフォルト値に戻すボタンはありません。必要な場合はUnityのEditorPrefsで`StudioRaming.EasyMeshEditor.`で始まるキーを削除してください。
