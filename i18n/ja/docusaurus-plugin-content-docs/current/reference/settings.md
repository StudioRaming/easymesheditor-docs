# 設定項目

**このページを読むと** ウィンドウのどの値が次に開くまで記憶され、どの値がセッションとともに消えるか、また何も保存されていないときの各値の初期状態がわかります。

既定値は 1.0 のソースで設定されている初期値です。保存された値がないときに使われる値です。

## 記憶される値と消える値

ウィンドウの操作設定のほとんどは、**Unity エディターの EditorPrefs** に保存されます。プロジェクトを閉じて開き直しても、別のプロジェクトを開いても、そのまま残ります。

例外は**キーのロック状態**で、プロジェクトの EditorUserSettings にメッシュの GUID ごとに保存されます。

一方、**編集の状態**（選択、マスク、非表示、元に戻す履歴、表情キーの値、塗った領域）はセッションに属します。`メッシュ保存` や `編集を破棄` でセッションが終わると消えます。→ [セッションと元に戻す](/internals/session-and-undo)

## ウィンドウ共通

| 項目 | 説明 | 既定値 |
|---|---|---|
| 言語 | English、한국어、日本語。最初は Unity Editor のシステム言語に従います | システム言語 |
| かんたんに始める / エキスパート | ウィンドウの表示モードです。編集値は変わりません | かんたんに始める |
| アクティブなタブ | 最後に使ったタブを記憶します | 最初のタブ |
| ショートカットシート（`Keys`） | 開いているかどうかを記憶します | 閉じている |

| 項目 | 範囲 | 既定値 |
|---|---|---|
| ブラシ | 引っぱる · なめらかに · 平らに · 寄せる · ふくらませる | 引っぱる |
| `半径` | 0.001 ～ 2 | 0.05 |
| `強さ` | 0 ～ 1 | 0.5 |
| `減衰` | `スムーズ` · `球形` · `シャープ` · `一定` | スムーズ |
| `範囲表示` | 0.05 ～ 1 | 0.9 |
| 筆圧サイズ / 筆圧の強さ | それぞれ 0～100% | 0% / 100% |
| `対称` X / Y / Z | オン / オフ | オフ |
| `平面表示` | オン / オフ | オン |
| マスクの方式 | `アイランド` · `ブラシ` · `ボックス` | アイランド |
| ブラシのプリセット | 3 スロット | 空き |
| X-Ray | オン / オフ | オフ |

## 表情キー

| 項目 | 説明 | 既定値 |
|---|---|---|
| `グループ` | 接頭辞で一覧を折りたたみます | オン |
| `拡張範囲`（-100～200） | スライダーの範囲を広げます | オフ |
| `ヒートマップ` | デルタヒートマップをオンにします | オフ |
| ミラー軸 | ミラーキーを作るときに使う軸 | X |
| キーのロック（`L`） | メッシュの GUID ごとにプロジェクトに保存されます | ロックなし |

## 設定を初期化するには

個別の項目は、ウィンドウで元に戻せます。すべてを一度に初期化するボタンはありません。どうしても必要な場合は、Unity の EditorPrefs から `StudioRaming.EasyMeshEditor.` で始まるキーを削除してください。
