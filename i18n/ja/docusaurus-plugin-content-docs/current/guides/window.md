# ウィンドウの使い方

**このページを読むと** ウィンドウの各部分の役割、ステータスバッジの意味、読み込み前に読み込み候補を使う方法、シーンビューのヒントとショートカットシートの開き方、保存結果表の読み方がわかります。


ウィンドウは上から順に、**ヘッダー、タブ、対象の行、保存の行、タブの本体**の並びです。どのタブを開いても、この枠組みは同じです。

## ヘッダーと言語

ヘッダーには製品名とバージョンバッジがあります。不具合を報告するときは、このバージョン番号も書いてください。

言語は English / 한국어 / 日本語 から選びます。変更すると、ウィンドウ、シーンビューのヒント、ツールチップが新しい言語で描き直されます。最初に開くときは Unity Editor のシステム言語に従います。

## タブ

タブは 4 つです。タブ名は画面に表示されるものをそのまま使います。

| タブ | ページ |
|---|---|
| `形を整える` | [形を整える](/guides/sculpt) |
| `選択・移動` | [選択・移動](/guides/edit) |
| `表情キー` | [表情キー](/guides/blendshape) |
| `ボーン接続` | [ボーン接続](/guides/weight-paint) |

`Ctrl+Tab` で次のタブ、`Ctrl+Shift+Tab` で前のタブに移動します。

`表情キー` と `ボーン接続` は `SkinnedMeshRenderer` でのみ動作します。通常の `MeshRenderer` だけを読み込んだ状態でこれらのタブを開くと、そのタブは使えないという案内が表示されます。

## 開始カード

編集を始める前に、ウィンドウに開始カードが表示されます。4 つの手順を示します。

1. 対象を選ぶ（Hierarchy でオブジェクトを選択）
2. 読み込み
3. モード選択（タブを選ぶ）
4. メッシュ保存

Play モード中に編集が保持されているあいだ、開始カードは `編集は保持されています` と表示します。編集は Play を終了すると戻り、Play モード中は `読み込み` を使えません。

## かんたんに始める / エキスパート表示

ウィンドウには **かんたんに始める** と **エキスパート** の 2 つの表示があります。かんたんに始めるでは、よく使う設定を先に表示します。エキスパートでは詳しい設定も開きます。どちらの表示でも、編集値と作業内容はそのまま保たれます。詳しい設定は `詳しい設定` から開けます。

ウィンドウを初めて開くと、**かんたんに始める** が表示されます。

## 対象の行と読み込み候補 {#불러올-후보}

Hierarchy で選んだオブジェクトの中にある `SkinnedMeshRenderer` と `MeshFilter + MeshRenderer` が **読み込み候補**として見つかります。一覧の行ごとに、名前、頂点数、キー数、警告が表示されます。

- 行を 1 つクリックすると、そのレンダラーだけを読み込みます。
- 選択を外して `読み込み` を押すと、候補すべてを読み込みます。
- Read/Write がオフのメッシュは、候補の行がグレーで表示されます。ステータス行の `Read/Write を有効化` ボタンでインポーター設定をオンにしてから、`読み込み` を押してください。→ [インストール](/getting-started/installation#7-메쉬가-readwrite-꺼짐이라면)
- 同じ元のメッシュを使うレンダラーは、それぞれ別々に読み込んで別々に編集します。編集結果も、レンダラーごとに別々に保存されます。

複数のメッシュを読み込んだ場合は、`アクティブ対象` のセレクターで、`表情キー` と `ボーン接続` の対象を選びます。→ [複数メッシュ](/guides/multi-mesh#활성-대상)

## ステータスバッジ {#상태-배지}

| バッジ | 意味 |
|---|---|
| `保存済み` | `読み込み` の後で変更したものはありません |
| `未保存の変更` | 保存されていない編集があります |
| `キー編集中` | 表情キーの編集が進行中で、まだ確定していません |

ウィンドウが狭いときは、バッジの表示が短くなります。正式な文言はツールチップに残ります。

## 保存の行

保存の行には 2 つの保存操作があります。役割が異なります。

| ボタン | 役割 |
|---|---|
| `新規キーとして保存` | 基本の形に今回追加した変形だけを、新しい表情キーとして残します。セッションは続きます。キー名は `表情キーの名前（任意）` の欄に入力します |
| `メッシュ保存` | 現在の Work Mesh 全体をメッシュアセットとして保存し、セッションを終わらせます |

`メッシュ保存` は、すべての作業が終わったあとに 1 回押すボタンです。`新規キーとして保存` はアセットをまだ変更しません。表情キーの編集が確定していない間は、どちらのボタンも押せません。→ [表情キー](/guides/blendshape#빠른-캡처와-bake)

表情キーのないメッシュでは、キー名の欄と `新規キーとして保存` ボタンは表示されません。

## 表情キー編集バー

表情キーを作成または編集している間は、ウィンドウの上部に固定されたバーが表示されます。ここで `保存`（キー編集の確定）または `キー編集を取消` を押します。このバーはどのタブにいても表示されます。

- `Enter` はキー編集を保存します。ただし、編集を開始したタブが有効なときだけ動作します。
- `Esc` は進行中のストロークやサイズ変更だけを取り消します。キー編集は破棄しません。
- `キー編集を取消` は、何か造形していれば一度確認します。

## ステータス行

ウィンドウの下部にあるステータス行には、直前の操作の結果と案内が表示されます。Read/Write を有効化するボタンもここに表示されます。

## 復元バナー

Unity が予期せず終了した場合、次にウィンドウを開くとバナーが表示されます。`復元` を押すと、最後のチェックポイントにセッションを戻します。`破棄` は 5 秒以内に 2 回押すと実行されます。復元できなかったファイルは削除されません。→ [セッションと元に戻す](/internals/session-and-undo#크래시-대비)

復元バナーは状況を分けて案内します。編集を作成したシーンのファイルが見つからない場合（削除済み、またはインポート中）は復旧ファイルを残し、インポートが終わると再確認します。対象オブジェクトが開いているシーンにない場合は復元できず、`編集N件を削除` だけが使えます。このボタンは 5 秒以内にもう一度押すと実行され、シーンとアセットは変更されません。

## シーンが未保存のときの保存案内

編集中のシーンが一度も保存されていない場合、ウィンドウに案内が表示されます。案内の中の `シーンを保存` を押すとシーンを保存します。`編集を破棄` を押すと編集を捨てます。保存したことのないシーンのオブジェクトは編集内容を保持できないため、先にシーンを保存してください。→ [セッションと元に戻す](/internals/session-and-undo#자동-보존과-복원)

## シーンビューのヒントとショートカットシート {#단축키-시트}

シーンビューの上部に、現在のタブで使える操作のヒントが 1 行で表示されます。ヒントバーの右端にある `Keys` を押すと、現在のタブのショートカットと共通のショートカットを一覧で開きます。もう一度押すと閉じます。ウィンドウ内にも、同じショートカットシートを開くボタンがあります。

テキスト入力中はショートカットは動作せず、Unity のグローバルな Shortcut プロファイルも変更しません。全一覧は [ショートカット](/reference/shortcuts) にあります。

ヒント、ツールのパネル、ショートカットシートは、Unity 2021.2 以降のシーンビューオーバーレイの上に描画されます。2019.4 と 2020 では従来の方法で描画されます。

## 保存結果表 {#저장-결과표}

複数のメッシュをまとめて `メッシュ保存` すると、対象ごとの成功・失敗と保存パスが、折りたためる結果表に表示されます。失敗した対象のセッションは開いたままになるので、やり直せます。成功した対象だけがアセットとして書き出されます。

## ブラシのプリセットと選択範囲の表示

`形を整える` と `ボーン接続` のブラシ設定の下には、プリセットのスロットがあります。空のスロットをクリックすると現在のブラシを保存します。保存済みのスロットをクリックすると読み込みます。`選択範囲を表示`（テンキーの `.`）は、編集中のメッシュをシーンビューの画面に収めます。
