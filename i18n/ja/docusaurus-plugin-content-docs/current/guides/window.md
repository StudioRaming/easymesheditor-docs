# ウィンドウの使い方

**このドキュメントを読むと**、ウィンドウの各行が何をするのか、ステータスバッジが何を意味するのか、狭い状態でドッキングしたときになぜ画面が変わるのか、そして`Keys`シートでそこからショートカットを確認する方法がわかります。

ウィンドウは上から下へ**ヘッダー → タブ → ターゲット行 → 保存行 → タブ本体 → ステータスバー**の順です。どのタブにいても、この構造は同じです。

## ヘッダー

左に製品名とサブタイトル`シーンビューのメッシュ編集 — StudioRaming`、右にバージョンバッジと言語ポップアップがあります。

バージョンバッジは、インストールされている製品バージョンをそのまま表示します。バグ報告する際は、この数字を記載してください。言語ポップアップには日本語 / English / 한국어の3つがあり、変更するとシーンビューのオーバーレイとヒントバーも即座に新しい言語で再描画されます。

## タブ

`スカルプト` · `編集` · `ブレンドシェイプ` · `ウェイト`の4つです。`Ctrl+Tab`で次のタブ、`Ctrl+Shift+Tab`で前のタブです。

`ブレンドシェイプ`と`ウェイト`は`SkinnedMeshRenderer`でのみ動作します。通常の`MeshRenderer`を読み込んだ状態で入ると、`ブレンドシェイプはSkinnedMeshRenderer専用です。`などのガイドが代わりに表示されます。

## ターゲット行

現在何を編集しているのかを1行で説明します。

| 表示 | ステータス |
|---|---|
| `対象なし — オブジェクトを選択してLoad` | 選択されたレンダラーがありません |
| `選択: {0}個のレンダラー（Loadを押してください）` | 候補を見つけましたが、まだ開いていません |
| `編集中: {0}` | 1つのメッシュを編集中です |
| `{0}個のメッシュを同時編集中` | 複数のメッシュを一緒に編集中です |

同じ行に`Load` · `Bake` · `Revert` · `編集（Tab）` · `X-Ray（Alt+Z）`があります。

複数のメッシュを開いた場合、`アクティブ対象`セレクターも一緒に表示されます。→ [マルチメッシュ](/guides/multi-mesh)

### 読み込み候補 {#불러올-후보}

`Load`する前に候補リストを展開して、どのレンダラーが検出されたかを確認できます。タイトルは`読み込み候補`で、各行に`{名前} · 頂点 {n} · キー {n}`が表示されます。

| 警告 | 意味 |
|---|---|
| `[ソース重複]` | 同じソースメッシュを使用するレンダラーがすでに候補にあります。一緒に開くと自動的に除外されます |
| `[Read/Write無効]` | インポーターでRead/Writeを有効にして編集する必要があります |

行をクリックするとそのレンダラーのみを読み込みます。選択を解除するとすべての候補を一緒に読み込みます。候補が多い場合は`他{0}件`で折り畳まれます。

## 保存行

2つの保存動作が1行に並んでいます。その動作は異なります。

| ボタン | セクション | 動作 |
|---|---|---|
| `新規キーとして保存` | `クイックブレンドシェイプキャプチャ` | ベースに追加した変形だけを新しいキーとして記録します。セッションは継続します |
| `Bake` | `全変更を最終保存` | 現在のWork Mesh全体をメッシュアセットとして保存し、セッションを終了します |

左の`キー名`フィールドは`新規キーとして保存`が使用する名前です。

ウィンドウはその下に次のように記載しています — `すべての作業が終わった後に1回だけ実行してください。クイックキャプチャはBakeではなく、アセットをまだ変更していません。`そして`確定したブレンドシェイプの追加・編集・削除・順序も両方法とも一緒に保存されます。`

両方のボタンも、ブレンドシェイプ編集が確定されない間は押せません。→ [ブレンドシェイプ](/guides/blendshape#기존-키-편집)

## ステータスバッジ {#상태-배지}

| バッジ | 意味 |
|---|---|
| `保存済み` | `Load`以降、変更がありません |
| `未保存の変更` | 保存されていない編集があります |
| `編集確定待ち` | ブレンドシェイプ編集が進行中で、まだ確定されていません |

:::note[`保存済み`は「何もしていない」という意味です]
バッジはセッションの変更カウンターを見ています。`Load`直後は`保存済み`ですが、ブラシを1回でも当てると`未保存の変更`になります。
:::

## コンパクトモード {#컴팩트-모드}

ウィンドウの高さがヘッダー・タブ・ターゲット行・保存行・ステータスバーを差し引いて本文に200pxも残らない場合、**コンパクトモード**に自動切り替わります。トグルではなく、サイズに基づいた自動判定です。

コンパクトモードで変わる内容:

- ヘッダーのサブタイトルが折り畳まれ、ヘッダーの高さが減ります。
- タブ内の`使い方ガイド`ガイドブロックが隠されます。
- 保存行の`キー名`ラベルが削除され、行全体がフィールドとボタンで使用されます。

ウィンドウを縦に拡大するすると、元に戻ります。

## ショートカットシート {#단축키-시트}

シーンビューのヒントバーの`Keys`ボタンがショートカットパネルを開いたり閉じたりします。開いた状態はエディターに記憶されます。

パネルは**現在のタブのショートカット + `共通`ショートカット**の2つのグループで表示されます。タイトルは`スカルプト · ショートカット`のようにタブ名が前に付きます。

`ブレンドシェイプ`タブには登録された行がないため、`このタブに登録されたショートカットはありません。`が表示されます。そのタブのキーについては、`共通`グループとこのドキュメントの[ショートカット](/reference/shortcuts#블렌드쉐이프)テーブルを参照してください。

## Bake結果テーブル

複数のメッシュを一緒に`Bake`すると、`Bake結果（{0}/{1} 成功）`テーブルがウィンドウに残ります。各行にメッシュ名と`成功` / `失敗`が表示されます。

1つでも失敗すると、`Bake失敗（成功 {0} / 失敗 {1}）... 失敗したセッションは保持され、再試行できます。`が一緒に表示されます。成功したものだけアセットになり、失敗したセッションは開いたまま残ります。

## シーンビューのヒントバー

シーンビューの上部に、現在のタブで使用できる操作が1行で表示されます。共通部分は`Tab=編集の切替 · Ctrl+Tab=ツールタブ`で、残りはタブごとに異なります。

編集がオフの場合は、代わりに`編集を再開`ボタンが表示されます。
