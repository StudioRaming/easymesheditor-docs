# 表情キー

**このページを読むと** 表情キーの一覧の扱い方、新しいキーの造形と既存キーの編集、ミラーキー・キーの取り込み・適用値の結合といった管理機能、そして `新規キーとして保存` と `メッシュ保存` の違いがわかります。

:::note[`SkinnedMeshRenderer` 専用です]
通常の `MeshRenderer` の対象では、このタブは使えません。代わりに案内が表示されます。
:::

## 一覧 {#목록}

各行には、名前、値のスライダー、数値入力があります。

- 値は `0～100` で、プレビューにリアルタイムで反映されます。
- 名前や値を左右にドラッグしても値が変わります。`Shift` を併用すると微調整になります。
- `すべての値を 0 に` で、すべてのキーを一度に 0 に戻します。

一覧の上の検索ボックスで、名前による絞り込みができます。

### 行のボタン

| ボタン | 役割 |
|---|---|
| `S` | ソロプレビュー。そのキーだけを 100 で表示します。`Esc` で解除します |
| `L` | ロック。誤った変更を防ぎます |
| `M` | ミラーキーを作成します |

### 接頭辞のグループ {#접두사-그룹}

`グループ` をオンにすると、名前の接頭辞で一覧が折りたたまれます。`eye_blink` と `eye_wide` は `eye` のグループにまとまります。`vrc.v_` や `mouth_` のような接頭辞も自動で認識します。

### 拡張範囲 {#확장-범위}

`拡張範囲` をオンにすると、スライダーが `-100～200` まで開きます。外挿なので、形が崩れることがあります。どこまで動かせるかを確認する用途に使い、その値のまま保存しないでください。

### デルタヒートマップ {#델타-히트맵}

`ヒートマップ` をオンにして、一覧でキー名をクリックします。そのキーが実際に動く頂点が、色で表示されます。キーを選んでいない場合は、選ぶように案内が出ます。

### ソロプレビュー {#솔로-프리뷰}

行の `S` を押すと、そのキーだけを 100 にして表示します。ほかのキーの値は、画面上で一時的に脇へ退きます。`Esc` で解除します。

ソロ中は、複数のキーの値を一度に変更できません。先にソロを解除してください。

### ロック {#잠금}

行の `L` を押すと、そのキーをロックします。ロックしたキーは、編集、値の変更、一括操作、キーの取り込みの対象から外れます。変更するには、`L` をもう一度押してロックを解除します。ロックの状態はプロジェクトごとに保存されます。

## 複数のキーをまとめて扱う {#다중-선택}

名前をクリックすると選択されます。`Ctrl` または `Shift` を押しながらクリックすると、複数のキーを選べます。選んだキーに対して、次の一括操作ができます。

- 同じ値を設定する、または 0 にする
- ロックとロック解除
- 順番を上下に移動する
- 削除

一括操作は、Unity の元に戻す操作 1 回として扱われます。押し間違えた場合は、`Ctrl+Z` で全部を元に戻せます。選んだキーがすべてロックされている場合は、何も変更されません。

## 新しいキーの造形 {#새-쉐이프-조형}

表情キーのタブにある新規キーのボタン、またはシーンビューで `N` を押すと、いま見えている絶対的な形を基準に造形が始まります。キーを作成中であることを示すバーが表示されます。

- ドラッグ: つかんで動かす（グラブ）
- `Shift`: なめらかに
- `F`: 半径、`Shift+F`: 強さ
- `Enter`: 新しいキーを保存、`Esc`: ストロークを取り消し

キー名は、キー名の欄で設定します。キー名に含まれる `/` や改行は、保存時に `_` に置き換えられます。

## 既存のキーの編集 {#기존-키-편집}

一覧でキーを編集すると、そのキーの **最終フレームの 100% の形** が単独のプレビューとして読み込まれます。編集が始まると、バッジが `編集確定待ち` になり、ウィンドウに固定されたバーが表示されます。

編集中でも、`形を整える` や `選択・移動` のタブに移動して作業できます。終わったら、固定バーで次のどちらかを選びます。

- `保存`: キー編集をセッションに確定します。
- `キー編集を取消`: 編集を破棄します。何か造形していた場合は、もう一度確認します。

:::caution[ここで確定しても、アセットはまだ変わりません]
保存したキー編集はセッション内でのみ確定されます。メッシュアセットに反映されるのは `メッシュ保存` のときです。
:::

キー編集を確定しないまま `メッシュ保存` や `新規キーとして保存` を押すと、保存はブロックされ、先に編集を終えるよう案内されます。頂点数を変える操作（頂点の削除、分離）は、キー編集の途中では保存できません。

`Esc` は進行中のストロークだけを取り消し、キー編集は破棄しません。キー編集を保存または取り消したあとは、その編集中のストローク段階が `Ctrl+Z` の一覧から整理されるので、何も変わらない空の元に戻す段階は残りません。

### 複数フレームのキー {#다중-프레임}

フレームが 2 つ以上あるキーを編集すると、警告が表示されます。編集されるのは最後のフレーム（100%）だけです。

保存すると、途中のフレームは最後のフレームの変化量に比例して更新されます。途中のフレームを個別に造形する方法はありません。→ [現在の制限](/limitations)

### 元に戻す操作がキー編集の開始より前に戻ったとき

`Ctrl+Z` がキー編集を開始した時点より前に戻ると、編集の基準が失われます。その場合、ツールは編集を自動的に取り消し、その旨を通知します。誤ったデルタが保存されるのを防ぐためです。

## 基本の形を直接編集した場合 {#기본형-직접-수정}

キーを選ばずに `形を整える` や `選択・移動` でメッシュを変えると、それは基本の形の編集です。表情キーのタブに、2 つの選択肢が表示されます。

- `新しいキーとして確定`: その変形を新しいキーにします。
- `基本の形の編集を元に戻す`: 編集前の基本の形に戻します。

この状態で `メッシュ保存` を押すと、基本の形に焼き込むか、新しいキーとして確定するかを、ウィンドウが改めて尋ねます。

## 管理 {#관리}

| ボタン | 役割 |
|---|---|
| 名前 | キーの名前を変更します |
| 複製 | 同じ内容のキーをもう 1 つ作ります（`_Copy`） |
| 反転 | 反転したキーを作ります（`_Revert`）。基本の形を変えたあとに、元の表情を取り戻すときに使います |
| 削除 | キーを削除します。`Ctrl+Z` で戻せます |
| `^` / `v` | 順番を上下に移動します |

同じ名前のキーが複数ある場合は、一覧でクリックしたものだけが編集されます。

### 適用値の結合 {#적용값-합치기}

`適用値を結合` は、いま 0 ではないキーの**見えている結果**を、1 つの新しい 100% のキーにまとめます。元になったキーの値は 0 に戻ります。フレームが複数あるキーの補間と外挿も計算されます。

### ミラーキー {#미러-키}

行の `M` を押し、ミラー軸（通常は X）を選んで実行します。反対側の表情キーが作られます。

名前は、元の名前の左右の表記を入れ替えて決まります。

| 元の名前 | ミラーの名前 |
|---|---|
| `...Left...` | `...Right...`（大文字・小文字を区別しない照合も試します） |
| `xxx_L` | `xxx_R` |
| `L_xxx` | `R_xxx` |
| `xxx.L` | `xxx.R` |
| 左右の表記がない | `xxx_Mirror` |

頂点のペアは、`形を整える` の対称と同じ空間上の対応で探します。対応する頂点がない場合は、対称面の上にある頂点だけが反転し、それ以外は動きません。法線のデルタも同じように反転し、フレームが複数ある場合はすべてのフレームを反転します。

ペアが見つからない場合は、ミラーキーは作られません。メッシュが最初から左右非対称であれば、反対側は手で造形する必要があります。

### 別のメッシュからキーを取り込む {#키-전송}

顔のメッシュの表情キーを、新しく作った髪や小物などの別のメッシュへ移すときに使います。近接マッピングで対応する点を探します。

1. `ソースメッシュ` を選びます。そのメッシュのキー一覧が表示されます。
2. 取り込むキーにチェックを入れます。`すべて選択` と `すべて解除` があります。
3. `最大距離` を設定します。この距離の範囲内で対応する点を探します。
4. `取り込み` を押します。

対応する点が見つからない頂点は、動かずにそのまま残ります。残った頂点が多い場合は、最大距離を大きくしてください。ロックされたキーは飛ばされます。同じ名前のキーがすでにある場合は、置き換えるかどうかを尋ねられます。

取り込みに失敗した場合は、すべてのメッシュを操作の前の状態に戻します。

## クイックキャプチャとメッシュ保存 {#빠른-캡처와-bake}

どちらも保存ですが、役割が異なります。

| | `新規キーとして保存` | `メッシュ保存`（Bake） |
|---|---|---|
| 保存する対象 | 基本の形に**今回追加した変形だけ**を、新しいキーとして | Work Mesh **全体**（頂点、ウェイト、キーの構造） |
| アセット | まだ変わりません | `<元の名前>_Edit.asset` を作成します |
| セッション | 続きます | 終わります |
| 基本の形 | そのまま残ります | 現在の状態のまま焼き込まれます |

`新規キーとして保存` は、表情キーの値で再生中の形を混ぜ込みません。保存したキーは 100 でオンになり、現在の見た目が保たれます。キャプチャの基準も更新されるため、同じ変形が二重に保存されることはありません。

キャプチャする変形がなければ、何も保存されません。

## 複数のメッシュの場合 {#다중-메쉬-키}

複数のメッシュを一緒に編集する場合、すべての対象が `SkinnedMeshRenderer` である必要があります。

一覧に表示されるのは、**すべての対象で名前が一致するキーだけ**です。インデックスは異なっていても構いません。値、編集、管理は、すべてのメッシュに同時に適用されます。共通のキーが 1 つもない場合は一覧は空になり、新しく作るキーは同じ名前ですべてのメッシュに追加されます。→ [複数メッシュ](/guides/multi-mesh)
