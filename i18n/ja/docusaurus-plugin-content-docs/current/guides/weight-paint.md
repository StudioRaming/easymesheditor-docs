# ウェイトペイント

**このドキュメントを読むと**、塗るボーンを選択する2つの方法、5種類のブラシと正規化ルール、左右対称ペイントの名前マッチングルール、ボーン結合と別のメッシュからウェイトを転送する方法が理解できます。

:::note[`SkinnedMeshRenderer`専用です]
通常のメッシュでは、`ウェイトペイントはSkinnedMeshRenderer専用です。`が表示されます。
:::

## ボーンを選択 {#본-고르기}

`ボーン一覧`セクションにボーン階層がツリーで表示されます。各行の左のラジオボタンが**アクティブボーン** — 今から塗るボーンです。選択後は`アクティブボーン: {0}`で表示されます。

選択しない場合は`アクティブボーンがありません — 一覧左のラジオボタンで塗るボーンを選んでください。`が表示され、シーンビューのヒントも同じことを言います。

| ツール | 動作 |
|---|---|
| `検索` | 名前でフィルタリング |
| `展開` / `折畳` | ツリー全体を展開または折り畳み |
| `シーンビューにボーン表示` | シーンビューにボーンを描画 |
| `ウェイトのあるボーンのみ` | 実際にウェイトを持つボーンのみを残す |

シーンビューからも選択できます。

- `Ctrl` + ボーンをクリック — アクティブボーンを指定/解除
- `Ctrl+Shift` + ボーンをクリック — スムーズ対象チェックをトグル

### チェック済みボーン

ラジオボタンとは別に、各行にチェックボックスがあります。チェック済みボーンは`選択ボーンのスムーズ`と`ボーンウェイトの結合`、`ウェイトを取得`の範囲指定に使用されます。数は`チェック済みボーン: {0}個`で表示されます。

### ロック {#본-잠금}

行の`L`ボタンでそのボーンのウェイトをロックします。ロック中のボーンはペイント・正規化・転送から除外されます。ロック中のボーンを塗ろうとすると、`対象ボーンがロックされているため頂点 {0}個をスキップ（ロック解除で塗れます）`と通知されます。

## ブラシ {#브러시}

| ボタン | キー | 動作 |
|---|---|---|
| `加算（1）` | `1` | アクティブボーンのウェイトを上げる |
| `減算（2）` | `2` | 下げる |
| `スムーズ（3）` | `3` | 周辺と揃える |
| `ブラー（4）` | `4` | 周辺と混ぜる |
| `平均（5）` | `5` | ブラシ領域を均等にする |

`Ctrl`は加算/減算を反転し、`Shift`は押している間、一時スムーズです。

設定は`半径` · `強度` · `フォールオフ`（`スムーズ` · `球形` · `シャープ` · `一定`）です。`[` `]`で半径、`,` `.`で強度、`F` / `Shift+F`でマウスモーダル調整です。

塗った瞬間、現在のポーズで変形がリアルタイムに反映されるため、腕を曲げた状態で塗ると結果がすぐ見えます。

## ヒートマップ {#히트맵}

`ヒートマップ`セクションの`ウェイト表示`を有効にするとウェイトが頂点色で表示されます。`表示強度`で濃さを調整します。

色は青 → 緑 → 赤の順で値が上がります。チェック済みボーンがある場合は**チェック済みボーンの合計**を、ない場合はアクティブボーンの値を表示します。

## 自動正規化と最大影響ボーン数 {#자동-정규화와-최대-영향-본-수}

`ペイント設定`セクションです。

- `自動正規化`（デフォルト有効） — 塗るたびに頂点のウェイト合計を1に再調整します。
- `最大影響ボーン数` — 1～4。1つの頂点が持つことができるボーン数を制限します。

`自動正規化`を無効にすると純粋な加減算になり、ウィンドウが警告します — `自動正規化がオフです。ウェイト合計が1にならない場合があります。作業後に下の「全体を正規化」を押してください。`

無効にして保存する場合でも最後の防御線があります。`Bake`直前に合計が1でない頂点を正規化し、`自動正規化がオフだったため、合計が1でない頂点 {0}個をベイク直前に正規化しました。`と通知されます。

`全体を正規化（N）`はメッシュ全体を一度に正規化します。どのボーンにも接続されていない頂点はここで処理されます。

| メッセージ | 意味 |
|---|---|
| `未割り当て頂点 {0}個を最近接ボーンにバインドしました。` | 最も近いボーンに接続しました |
| `未割り当て頂点 {0}個をルートボーンにバインドしました。` | 最近接が見つからずルートに接続しました |
| `ボーン情報がないため未割り当て頂点 {0}個をそのままにしました。` | 接続するボーン自体がありません |

スロットがすでに満杯の場合は、`4スロットが埋まった頂点 {0}個をスキップ（値が弱いため）`で報告されます。

## 対称ペイント {#대칭-페인트}

`対称ペイント（X）`を有効にすると、塗る時に反対側の頂点にも**左右対応ボーン**が一緒に塗られます。対応ボーンは`対称ボーン: {0}`で表示されます。

名前マッチングルールは次のとおりです。サフィックス/プリフィックス1文字形式を最初にチェックし、次に単語形式をチェックします。

| 形式 | 例 |
|---|---|
| サフィックス | `Arm_L` ↔ `Arm_R` · `Arm.L` ↔ `Arm.R` · `Arm-L` ↔ `Arm-R`（小文字`_l`/`_r`など各々） |
| プリフィックス | `L_Arm` ↔ `R_Arm` · `L.Arm` ↔ `R.Arm` · `L-Arm` ↔ `R-Arm` |
| 単語 | `Left Arm` ↔ `Right Arm` · `left`/`right` · `LEFT`/`RIGHT` |
| 日本語 | `左腕` ↔ `右腕` |

作成された名前のボーンが実際に存在する場合のみペアとして認識されます。`Hips`や`Spine`のような中央ボーンはペアがないため自分自身にフォールバックし、ウィンドウが`対称ボーンなし — 中央ボーンとして両側を同じボーンで塗ります。`と通知します。

:::caution[ラベルの`（X）`はキーガイドではありません]
現在のバージョンでは、このオプションは**ウィンドウのチェックボックスのみで**有効/無効になります。シーンビューで`X`を押してもトグルされません。
:::

## 選択ボーンのスムーズ {#선택-본-스무딩}

複数のボーンをチェックした後に使用される一括スムーズです。

- `反復` — 1～20回
- `強度`
- `スムーズを適用（K）` — シーンビューのショートカットは`K`

スライダーをドラッグする間、基準スナップショットからリアルタイムで再計算して表示し、マウスを離すときに1つの元に戻すステップとして確定します。

チェック済みボーンがない場合は、`K`は何も行いません。

## ボーンウェイトの結合 {#본-웨이트-합치기}

`ボーンウェイトの結合`セクション。説明はウィンドウにそのまま記載されています — `ボーンAのウェイトをすべてボーンBへ移します。移動後はAのウェイトが0になるため、そのボーンを安全に削除できます。`

| ボタン | 動作 |
|---|---|
| `アクティブボーンを親（{0}）へ結合` | アクティブボーンをその親へ |
| `チェック済み{0}個のボーンをアクティブボーンへ結合` | チェック済みボーンをアクティブボーンへ |
| `M`（行ボタン） | そのボーンをターゲットに指定 |

ターゲットは`親: {0}` / `他のボーン`から選択します。候補がない場合は`結合先のボーンがありません`です。

結果は`{0}個のボーンのウェイトを「{1}」へ結合しました（頂点{2}個を変更）。`で報告されます。

| ブロック時 | メッセージ |
|---|---|
| 元と先が同じ | `結合元と結合先が同じです。別のボーンを選んでください。` |
| ロック中のボーン | `ボーン「{0}」はロックされているため結合できません。ロックを解除してください。` |

衣装で使用されていない不要なボーンをクリーンアップするときに使用する機能です。→ [衣装のフィッティング](/workflow/clothing-fit)

## 別メッシュからウェイトを取得 {#다른-메쉬에서-웨이트-가져오기}

`別メッシュからウェイトを取得`セクション。ウィンドウの説明そのもの — `すでにウェイトが設定されたメッシュ（アバターボディなど）をソースに指定すると、表面上の最近接点のウェイトを現在のメッシュへ移します。衣装のフィッティングの基本的な作業です。`

1. `ソースメッシュ`に既にウェイトが設定されている`SkinnedMeshRenderer`を設定します。
2. `最大距離`を決定します。
3. `適用範囲`を選択します。
4. `ウェイトを取得`をクリックします。

| `適用範囲` | ターゲット |
|---|---|
| `メッシュ全体` | すべての頂点 |
| `チェックしたボーンのウェイトのみ` | ボーン一覧でチェック済みボーンの影響のみ |
| `ウェイトのない頂点のみ` | まだどのボーンにも接続されていない頂点のみ |

結果は`ウェイトを取得しました — 適用{0}頂点・範囲外{1}頂点・スキップ{2}頂点。`で表示されます。

| 状況 | メッセージ |
|---|---|
| ソースを選択しなかったか自分自身 | `編集中のメッシュとは別のSkinnedMeshRendererをソースに指定してください。` |
| Read/Write無効 | `ソースメッシュを読み込めません。モデルインポーターの Read/Write Enabled を有効にしてください。` |
| ソースにウェイトなし | `ソースメッシュにボーンウェイトがありません。` |
| チェック範囲だがチェックなし | `チェックされたボーンがありません。ボーン一覧で取得したいボーンをチェックしてください。` |
| 名前が対応しないソースボーン | `対応ボーンが見つからないソースボーン{0}個の影響（合計{2}）は破棄しました: {1}` |

### スペースがずれている場合 {#전송-공간}

ウェイトはバインドポーズデータなので、2つのメッシュが同じ空間にあって対応点が合致する必要があります。ソースとターゲットレンダラーのトランスフォームが異なる場合、ウィンドウが警告します。

> `ソースとターゲットのレンダラーのトランスフォームが異なります。ウェイトはバインドポーズのデータなので、両メッシュが同じ空間にある必要があります。結果がずれる場合は下のオプションを有効にしてください。`

下の`ソーストランスフォームを無視（バインドポーズのローカル空間で照合）`を有効にすると、ワールドトランスフォームの代わりにバインドポーズローカル空間で照合します。

## ウェイトが保存される方法

塗られた値は同じ位置の[ウェルドグループ](/internals/session-and-undo#웰드-그룹)全体に同一に記録され、合計は1に正規化されます。

直接ペイントはUnityのレガシー4スロット範囲で動作します。Unity 2020.1以上で**塗られていない**頂点の5つ以上のボーン影響はそのまま保存されます。→ [可変ボーンウェイト](/internals/bake#가변-본-웨이트)

影響ボーンがスロット数を超える場合は、`影響ボーンがスロット数を超えたため頂点 {0}個で弱い影響が切り捨てられました。`と通知されます。
