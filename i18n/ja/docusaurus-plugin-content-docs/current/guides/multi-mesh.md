# マルチメッシュ

**このドキュメントを読むと**、複数のメッシュを1つのセッションで一緒に処理する場合に何が一緒に適用され、何がアクティブターゲットにのみ適用されるか、共通ギズモがどのように動作するか、そして1つが失敗した場合に残りがどうなるかが理解できます。

## 一緒に開く

HierarchyでオブジェクトをいくつかのPropertiesを選択し、`Load`を押します。ウィンドウは最初に`Loadを押すと選択した{0}個のメッシュをすべて一緒に開きます。`と通知し、開くと`{0}個のメッシュを同時編集中`になります。

同じソースメッシュを共有するレンダラーは自動的にフィルタリングされます — `（同一ソースメッシュ共有のため{0}件除外）`。同じメッシュを2回編集すると互いに上書きされるためです。

トポロジーと頂点数は異なる場合があります。各メッシュは独自のデータで個別に計算されます。

## アクティブターゲット {#활성-대상}

`アクティブ対象`セレクターで現在フォーカスされているメッシュを変更します。何が一緒に適用されるか、何がアクティブターゲットにのみ適用されるかが分かれます。

> `スカルプトと編集は読み込まれたすべてのメッシュに適用されます。ブレンドシェイプとウェイトはアクティブターゲットに適用されます。`

| タブ | 範囲 |
|---|---|
| `スカルプト` | 読み込まれたすべてのメッシュ |
| `編集` | すべてのメッシュで選択を保持、共通ギズモで一緒に変形 |
| `ブレンドシェイプ` | 名前が共通のキーに限定して全メッシュに同時適用 |
| `ウェイト` | アクティブターゲット1つのみ |

## 編集タブの共通ギズモ

複数のメッシュから各要素を選択すると、ステータスが`複数メッシュ — {1}個中{0}個に選択 · 共通ギズモで同時変形（削除/分離はアクティブメッシュ対象）`に変わります。

- 変形は**ワールド空間の1つのギズモ**で全メッシュに同時適用されます。
- `G`/`R`/`S` [モーダル変形](/guides/edit#모달-변형)のローカル軸は1つに決定されないため、`複数メッシュ → ワールド軸`にフォールバックします。
- `A`（全選択）・`Alt+A`（解除）・`Ctrl+I`（反転）はすべてのターゲットに適用されます。
- **削除と分離はアクティブメッシュにのみ**適用されます。

[ピボット](/guides/edit#피벗)の`メッシュごとに均等`を有効にするとメッシュごとに独自のピボットを使用します。

対称対応点、選択、ブラシ影響は常に各メッシュで独立して計算されます。

## ブレンドシェイプの名前交集合

すべてのターゲットが`SkinnedMeshRenderer`である必要があります。リストには**すべてのターゲットで名前が同じキーのみ**が表示されます。

> `{0}個のメッシュすべてにあるキーのみ表示します。値・編集・管理はすべてのメッシュへ同時適用されます。`

インデックスは異なる場合があります — 名前のみで照合します。共通キーがない場合はリストが空になり、新規作成キーは同じ名前ですべてのメッシュに追加されます。→ [ブレンドシェイプ](/guides/blendshape#다중-메쉬-키)

## 原子的ロールバック {#원자적-롤백}

複数メッシュの構造を変更する作業（一括削除、順序変更、キー転送、分離など）は**すべて成功するか、すべてロールバックするか**です。1つが失敗するとすべてのターゲットのスナップショットを復元します。

> `一括処理に失敗したため、全メッシュを実行前の状態へ戻しました。コンソールログを確認してください。`

元に戻すも同じです。複数メッシュ作業は1つの複合元に戻すステップにまとめられます。→ [セッションと元に戻す](/internals/session-and-undo)

## Bakeはメッシュごと

`Bake`は各ターゲットで独自の`<元名>_Edit.asset`を作成します。ロールバックルールと異なり、成功したもののみが出力され、失敗したセッションは開いたままになります。

結果は`Bake結果（{0}/{1} 成功）`テーブルでウィンドウにまとめられます。→ [ウィンドウの使い方](/guides/window#상태-배지)

## パフォーマンス

高密度メッシュを複数開くとシーンビューオーバーレイ、ボックスピッキング、スキンポーズ計算、ブラシ処理コストがそれだけ増加します。顕著に重い場合は、必要なメッシュのみを選択して`読み込み候補`リストから1つずつ開いてください。→ [ウィンドウの使い方](/guides/window#불러올-후보)
