# スカルプト

**このドキュメントを読むと**、5種類のブラシがそれぞれどのような変形をもたらすのか、半径・強度・フォールオフ・筆圧をどのように調整するのか、対称を有効にして確認する方法、およびマスクで触ってはいけない場所を保護する方法が理解できます。

`スカルプト`タブはシーンビューでドラッグすると表面が追従するタブです。現在表示されているポーズに基づいて動作するため、スキンメッシュの場合はアニメーションが適用された画面上の位置がそのままキャプチャされます。

## ブラシ {#브러시}

| ブラシ | キー | 動作 |
|---|---|---|
| `エラスティック（1）` | `1` | ドラッグ方向に表面を弾性体のように引っ張ります |
| `スムーズ（2）` | `2` | 隣接頂点の平均で表面を滑らかにします |
| `フラット化（3）` | `3` | ブラシ領域の加重平面へ押して平坦にします |
| `ピンチ（4）` | `4` | ブラシの中心へ頂点を寄せます |
| `インフレート（5）` | `5` | 法線方向に膨らませます |

すべてのブラシで`Ctrl`を押すと方向が反転し（収縮、平面の反対側、絞るの代わりに広げる）、`Shift`を押すとその瞬間だけスムーズブラシになります。

### エラスティック {#엘라스틱}

ボリュームを保ちながら押して引くのに使う基本ブラシです。クリック時の影響セットを固定した後、正規化Kelvinlet変形を適用するため、ブラシ半径外でも柔らかいテールで一緒に追従します。

ウィンドウの説明そのもの — `正規化KelvinletとC2ソフトテールで境界が途切れず広がります。強度を上げると影響範囲とグラデーションも広がります。`強度を上げるとテールの影響は最大で半径の約2.5倍まで広がります。

衣装が体を貫く場所を押し込んだり、シルエット全体を膨らませたりするときにこのブラシを使用します。→ [衣装のフィッティング](/workflow/clothing-fit)

### スムーズと フラット化

`スムーズ（2）`は凹凸を取り除き、`フラット化（3）`は面を平面に近づけます。どちらもクリック1回（ドラッグなし）でその場所に1回スタンプできます。

## ブラシ設定 {#브러시-설정}

| 項目 | 範囲 | 説明 |
|---|---|---|
| `半径` | 0.001 ~ 2 | ブラシサイズ。`[` `]`でも調整できます |
| `強さ` | 0 ~ 1 | 1回の影響量。`,` `.`（= `<` `>`）でも調整できます |
| `筆圧を使用` | on/off | タブレットペンの筆圧を強度に掛けます。ストローク内で圧力が保持されます |
| `範囲表示` | 0.05 ~ 1 | シーンビューに描画されるブラシ影響表示の不透明度 |
| `フォールオフ` | `スムーズ` · `球形` · `シャープ` · `一定` | 中心から端へ向かう影響の減り方の形状 |

`F`を押すとマウスを左右に動かして半径を調整するモーダルが開きます。クリックで確定、`Esc`でキャンセルです。`Shift+F`は同じ方法で強度を調整します。

### ブラシプリセット {#브러시-프리셋}

`ブラシプリセット`セクションには3つのスロットがあります。`保存`を押すと、現在のブラシタイプ・半径・強度・フォールオフ・筆圧設定がそのスロットに保存され、スロットを押すと復元されます。まだ使用されていないスロットは`空き`と表示されます。

プリセットはエディターに保存されるため、プロジェクトを再度開いても残ります。

## 対称 {#대칭}

`対称`でX / Y / Zを組み合わせて有効にします。シーンビューのショートカットは`Shift+Alt+X` · `Shift+Alt+Y` · `Shift+Alt+Z`で、`編集`タブと同じ記法です。単独の`X` `Y` `Z`はUnityのツールハンドルショートカットとして残しており、インターセプトしません。→ [ショートカット](/reference/shortcuts#스컬프트)

:::note[対称は頂点数が正確に同じでなくても動作します]
左右のトポロジーが完全に同じである必要はありません。ローカル空間のベース位置に基づいて空間内の対応点を見つけます。ペアを見つけられない頂点は対称処理から単に除外されます。
:::

`対称平面を表示`を有効にするとシーンビューにミラー平面と反対側のブラシ位置が描画されます。対称がどの軸でキャッチされているかを視覚的に確認してから開始してください。

## マスクモード {#마스크-모드}

`M`で入ります。マスクされた頂点は暗く描画され、スカルプトブラシと`編集`タブの[プロポーショナル編集](/guides/edit#프로포셔널-편집)の両方から除外されます。

3つの方法があります。

| サブモード | 操作 |
|---|---|
| `アイランド` | クリック = その連結パーツ全体のマスクを適用/解除 |
| `ブラシ` | ドラッグ = 半径で塗画、`Ctrl` = 解除 |
| `ボックス` | 画面上で矩形ドラッグ、`Shift` = 追加、`Ctrl` = 削除 |

ホバープレビューはシアンが適用予定、赤が解除予定です。

- `Ctrl+I` — `マスク反転（Ctrl+I）`
- `Alt+M` — `マスク全解除（Alt+M）`

対称が有効な場合、アイランドマスクは対応するアイランドも処理します。マスク変更は`Ctrl+Z`で元に戻すことができます。

## X-Ray

`Alt+Z`で有効にします。無効な場合、画面で隠れた頂点はブラシでキャッチされず、有効な場合は裏側を通して遠くからキャッチします。薄い服の内側を編集するときに有効にしてください。

## スカルプト結果を保存

スカルプトはベースメッシュを直接変更します。完了したら2つの方法があります。

- **`Bake`** — 変更された形をそのままメッシュアセットとして焼き込みます。
- **`新規キーとして保存`** — 今回追加した変形だけをブレンドシェイプキーとして保存し、ベースは保持します。

ベースが変更された状態で`Bake`を押すと、ウィンドウは`キー未選択で行った編集があります。新規キーとして確定してからBakeしますか、それとも基本形に焼き込みますか？`と質問します。→ [ブレンドシェイプ](/guides/blendshape#기본형-직접-수정)
