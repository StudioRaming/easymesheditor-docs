# 形を整える

**このページを読むと** 5 種類のブラシがそれぞれどんな変形をするか、半径・強さ・減衰・筆圧をどう調整するか、対称を有効にして確認する方法、マスクで動かしてはいけない場所を守る方法がわかります。

`形を整える` タブは、シーンビューでドラッグすると表面がついてくるタブです。今見えているポーズを基準に動作するので、スキンメッシュの場合はアニメーションが適用された画面上の位置をそのまま捉えます。

## ブラシ {#브러시}

| ブラシ | キー | 役割 |
|---|---|---|
| `引っぱる（1）` | `1` | ドラッグした方向へ、表面を弾性体のように引っぱります |
| `なめらかに（2）` | `2` | 隣接する頂点の平均で、表面をやわらかくします |
| `平らに（3）` | `3` | ブラシ範囲の重み付き平面に向けて、表面を平らにします |
| `寄せる（4）` | `4` | 接平面の方向に、表面をブラシの中心へ集めます。体の中へは入りません |
| `ふくらませる（5）` | `5` | 頂点法線の方向にふくらませます |

`Ctrl` を押し続けると方向が反転します。平らには反対側へ、寄せるは外側へ広がり、ふくらませるは収縮します。`Shift` を押し続けると、その間だけなめらかにブラシになります。

なめらかに、平らに、寄せる、ふくらませるは、ドラッグせずクリックするだけで 1 回スタンプされます。引っぱるは、ドラッグしている間だけ表面が動きます。

### 引っぱる {#엘라스틱}

体積を保ちながら押したり引いたりするための基本のブラシです。ドラッグした方向へ表面を弾性的に引っぱります。強さを上げるとブラシの半径の外側にあるやわらかい尾の影響が広がり、おおよそ `半径 × 2.5` まで届きます。

衣装が体に食い込んでいる場所を押し込むときや、シルエット全体をふくらませるときに使います。→ [衣装のフィッティング](/workflow/clothing-fit)

### なめらかに と 平らに

`なめらかに（2）` は凹凸を取り除き、`平らに（3）` は面を平面に近づけます。どちらも、クリック 1 回でその場に 1 回スタンプされます。

## ブラシの設定 {#브러시-설정}

| 項目 | 範囲 | 説明 |
|---|---|---|
| `半径` | 0.001 ～ 2 | ブラシのサイズ。`[` `]` でも調整できます |
| `強さ` | 0 ～ 1 | 1 回の適用量。`,` `.`（`<` `>`）でも調整できます |
| `範囲表示` | 0.05 ～ 1 | シーンビューに描画されるブラシの影響範囲の不透明度 |
| `減衰` | `スムーズ` · `球形` · `シャープ` · `一定` | 中心から端へ向かって影響が弱まる形 |

`F` を押すと、マウスを左右に動かして半径を変えるモーダルが開きます。クリックで確定し、`Esc` で取り消します。`Shift+F` も同じ方法で強さを調整します。

### 筆圧の適用量 {#필압-적용량}

ペンタブレットを使う場合は、`詳細設定` で筆圧の掛かり方を決めます。

- **筆圧サイズ**と**筆圧の強さ**を、それぞれ `0～100%` で設定します。
- `0%` はその値を固定します。`100%` はペンの筆圧をそのまま反映します。
- サイズだけ、強さだけ、または両方を使えます。設定した**サイズ**と**強さ**の値は変わりません。
- マウスや筆圧に対応しない機器では、設定した半径と強さをそのまま使います。
- ペン入力は Unity に届いた筆圧を使うため、Windows のタブレットドライバーが筆圧を送っている必要があります。
- この適用量は `形を整える` だけに適用されます。ほかのタブの動作は従来どおりです。

### ブラシのプリセット {#브러시-프리셋}

ブラシの設定の下に、プリセットのスロットが 3 つあります。空のスロットをクリックすると、現在のブラシの種類、半径、強さ、減衰を保存します。保存済みのスロットをクリックすると、その設定をもう一度読み込みます。スロットを右クリックするか、保存トグルをオンにしてからスロットをクリックすると、保存内容を上書きします。

## 対称 {#대칭}

`対称` で X / Y / Z を組み合わせてオンにします。シーンビューのショートカットは `Alt+Shift+X` · `Alt+Shift+Y` · `Alt+Shift+Z` です。単独の `X` `Y` `Z` は Unity のツールハンドルのショートカットとして残るため、このツールは横取りしません。→ [ショートカット](/reference/shortcuts#모양-다듬기)

:::note[頂点数が完全に一致しなくても対称は動作します]
左右のトポロジーが完全に同じである必要はありません。対応する点は、空間上の位置をもとに探します。対応先が見つからない頂点は、対称の処理から外れます。
:::

`平面表示` をオンにすると、シーンビューにミラー平面と反対側のブラシのカーソルが描画されます。作業を始める前に、対称がどの軸で設定されているかを確認してください。

## マスクモード {#마스크-모드}

`M` を押すと入ります。マスクされた頂点は暗く表示され、`形を整える` のブラシと、`選択・移動` タブの[プロポーショナル編集](/guides/edit#프로포셔널-편집)のどちらからも除外されます。

方式は 3 つあります。

| 方式 | 操作 |
|---|---|
| `アイランド` | クリックすると、つながった塊全体をマスクへ入れたり外したりします |
| `ブラシ` | ドラッグすると半径で塗ります。`Ctrl` を押すと消去します |
| `ボックス` | 画面で四角形をドラッグします。`Shift` で追加、`Ctrl` で除去します |

ホバー中のプレビューは、シアンがマスクに入る範囲、赤がマスクから外れる範囲です。

- `Ctrl+I`: マスクを反転
- `Alt+M`: マスクを全解除

マスクの変更も `Ctrl+Z` で元に戻せます。

## X-Ray

`Alt+Z` で有効にします。オフのときは、隠れている頂点にブラシが当たりません。オンにすると、裏側まで通してブラシが当たります。薄い衣装の内側を触るときにオンにしてください。

## 形を整えた結果を保存する

形を整えると、基本の形（base mesh）が直接変わります。作業が終わったら、次の 2 つの方法があります。

- **`メッシュ保存`**: 変更後の形を、そのままメッシュアセットとして保存します。
- **`新規キーとして保存`**: 今回追加した変形だけを表情キーとして残し、基本の形はそのままにします。

表情キーを選ばずに基本の形を変えた状態で `メッシュ保存` を押すと、ウィンドウが新規キーとして確定するか、基本の形に焼き込むかを尋ねます。→ [表情キー](/guides/blendshape#기본형-직접-수정)
