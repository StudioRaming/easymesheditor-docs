# 選択・移動

**このページを読むと** 頂点・エッジ・フェイスの選び方、ギズモと Blender 方式の G/R/S 変形の違い、Alt+クリックでエッジループを選ぶ規則、塗った領域の処理方法、そして非表示・ピボット・法線・結合・分離まで、`選択・移動` タブの動作がわかります。

## 要素モード {#요소-모드}

| ボタン | キー |
|---|---|
| 頂点 | `1` |
| エッジ | `2` |
| フェイス | `3` |

## 選択 {#선택}

| 操作 | 結果 |
|---|---|
| クリック | 選択を置き換えます |
| `Shift` または `Ctrl` + クリック | 追加または解除（トグル） |
| ダブルクリックまたは `L` | カーソル下の連結要素を全部選択 |
| `Shift+L` | 連結要素の選択を解除 |
| `B` または空いている場所をドラッグ | ボックス選択（`Shift` で追加、`Ctrl` で除外） |
| `A` / `Alt+A` | すべて選択 / 選択解除 |
| `Ctrl+I` | 選択を反転 |
| `Esc` | 選択を解除 |

:::note[UV のシーム上の頂点は一緒に選ばれます]
Unity のメッシュは UV の境界で頂点が分かれているため、同じ位置に複数の頂点があります。選択は同じ位置にあるグループ全体をまとめて選びます。画面では 1 点を選んでいても、実際には 2～4 個の頂点が一緒に動きます。→ [ウェルドグループ](/internals/session-and-undo#웰드-그룹)
:::

X-Ray（`Alt+Z`）がオフのとき、隠れた要素は表示も選択もされません。オンにすると、裏側まで透過して選択します。

### エッジループとエッジリング {#엣지-루프와-엣지-링}

- `Alt+クリック`（押した位置から動かさずに離す）: エッジループ
- `Ctrl+Alt+クリック`: エッジリング
- どちらも `Shift` を併用すると、既存の選択に追加します

:::caution[`Alt+ドラッグ` は従来どおりシーンの回転です]
Unity のシーン回転を奪わないよう、ループ選択は 3px 未満しか動かなかったクリックでのみ行われます。`Alt` を押したまま、それより大きく動かすと、通常どおりカメラが回転します。
:::

### 選択の拡張と縮小

- `Ctrl` + `+`: 選択を拡張
- `Ctrl` + `-`: 選択を縮小

テンキーの `+` `-` も同じように動作します。

## ギズモ {#기즈모}

| ツール | キー |
|---|---|
| 表示 | `Q` |
| 移動 | `W` |
| 回転 | `E` |
| スケール | `R` |

Unity の標準のツール配置と同じです。ボーンのあるスキンメッシュでも、ポーズを反映した状態でドラッグすると、画面に見えるとおりに動きます。

複数のメッシュで要素を選んでいる場合は、ワールド空間の共通ギズモ 1 つで、まとめて変形します。→ [複数メッシュ](/guides/multi-mesh)

## モーダル変形（G / R / S） {#모달-변형}

Blender 方式の `G`（移動）、`R`（回転）、`S`（スケール）です。選択がある状態で、シーンビューにカーソルを置いてキーを押すと、マウスだけで変形が始まります。

モーダル中の操作は次のとおりです。

- `X` / `Y` / `Z`: 軸で拘束します。同じキーをもう一度押すと、ローカル軸からワールド軸に切り替わります。
- `Shift` + 軸: その軸を除いた平面で拘束します。
- 数字の入力: 正確な値を入力します。回転は度数です。
- `Enter` または左クリック: 確定
- `Esc` または右クリック: 取り消し

モーダル 1 回が元に戻す 1 段階です。複数のメッシュをまとめて扱う場合は、ローカル軸を 1 つに決められないため、ワールド軸を使います。

:::note[`R` は 2 つの役割を持ちます]
`R` は**選択があり、カーソルがシーンビューの上にあるときだけ**回転のモーダルになります。それ以外では、Unity 標準の `R`（スケールギズモ）として動作します。
:::

## プロポーショナル編集 {#프로포셔널-편집}

`O` を押すと、プロポーショナル編集が有効になります。選択していない周囲の頂点が、半径の範囲内でなめらかについてきます。

- `連結のみ` オン: トポロジー上の距離で計算します。重なっている別のパーツはついてきません。
- `連結のみ` オフ: 空間上の距離で計算します。

半径は `[` `]` で調整します。`連結のみ` の設定は、シーンビューのオーバーレイと、かんたんに始めるの `詳しい設定` にもあります。

[マスクモード](/guides/sculpt#마스크-모드)でマスクした頂点は、プロポーショナルの影響から除外されます。

## 対称

`対称` で X / Y / Z を組み合わせます。シーンビューのショートカットは `Alt+Shift+X` · `Alt+Shift+Y` · `Alt+Shift+Z` です。

このタブの対称は、**選択を増やしません。** 選択した要素を変形した結果を、ローカル軸の反対側にそのまま適用します。対称面の上にある中央の頂点は、その平面に固定されます。

## ピボット {#피벗}

回転とスケールの基準点を選びます。ギズモと `G` / `R` / `S` のモーダルの両方に適用されます。

| モード | 基準 |
|---|---|
| 中央点 | 選択した要素の平均位置 |
| 個別の原点 | 各要素が自分の位置を基準にします |
| アクティブ要素 | 最後に選んだ要素 |
| バウンディングボックスの中心 | 選択を囲む箱の中心 |

複数のメッシュをまとめて扱うときに `メッシュごとに均等` をオンにすると、共通ピボットを頂点数ではなくメッシュごとに同じ比重で計算します。

## 非表示 {#숨기기}

| ボタン | キー |
|---|---|
| 選択を非表示 | `H` |
| 選択外を非表示 | `Shift+H` |
| すべて表示 | `Alt+H` |

:::note[非表示は元に戻す対象ではありません]
非表示はメッシュデータではなく、編集セッションの表示状態です。`Ctrl+Z` の対象ではありません。構造が変わる（削除、分離、結合）と自動的に解除されます。
:::

## 法線 {#노멀}

| 項目 | 役割 |
|---|---|
| 法線を表示 | シーンビューに法線の向きを描画します。長さを変えられます |
| 法線を反転 | 選択したフェイスの巻き順を反転します |
| 法線を再計算 | 選択した頂点の法線を計算し直します |

反転は、ブレンドシェイプの法線・接線のデルタも一緒に反転します。そのため、表情キーのあるメッシュでも内側の面がずれません。

## 削除 {#삭제}

`X` または `Delete` で、選択したフェイスを削除します。そのフェイスだけで使われていた頂点はバッファーに残り、`メッシュ保存` のときに 1 回まとめて整理されます。→ [使われていない頂点の整理](/internals/bake#고아-정점-정리)

### 選択を分離・選択削除のボタン {#선택-분리-선택-삭제-버튼}

面を選ぶと、選択ツールの下にも `選択を分離（P）` と `選択削除（X · Nフェイス）` のボタンが表示されます。折りたたまれた `メッシュ操作` セクション（かんたんに始めるでは `詳しい設定` の中）と同じコマンドで、押した結果はボタンの下にしばらく表示されます。

拡張・縮小・連結選択・グループ割り当てが何も変えないときは、理由を案内します。例: `すべて選択済みです。` · `縮小できる選択がありません。` · `選択はすでに連結されています。` · `選択した面はすでにG{n}にあります。変更はありません。`

## 分離 {#분리}

| 操作 | キー | 結果 |
|---|---|---|
| 選択を分離 | `P` | 選択した要素を切り離します |
| アイランドを分離 | `Shift+P` | 選択範囲を連結の塊ごとに切り離します |
| グループごとに分離 | グループ G0～G9 | フェイスをグループに割り当て、まとめて分けます |

グループごとに分離すると、G0 は元のメッシュに残り、G1～G9 はそれぞれ別のパーツになります。

切り離したパーツは、シーン上で**未保存のパーツ**として表示されます。`メッシュ保存` のときに、元のメッシュの隣へ `<名前>_Part….asset` として保存されます。保存する前に `編集を破棄` を押すと、元のメッシュに戻り、未保存のパーツは削除されます。

保持されるもの: 頂点、法線、接線、UV0～UV3、カラー、サブメッシュとマテリアルの対応、bindpose、頂点ごとのボーン影響数と値そのままのボーンウェイト（4 つを超える影響も含む）、ブレンドシェイプのフレーム。

分離の操作全体が、元に戻す 1 段階になります。途中で失敗した場合は、元の状態に戻り、作りかけの `_Part.asset` も削除されます。

:::caution[切り離したパーツのボーン影響]
切り離した `_Part` パーツは、元のメッシュのボーン影響の数をそのまま引き継ぎ、4 スロットには縮めません。元のメッシュ側は従来どおりです。→ [現在の制限](/limitations)
:::

`Ctrl` や `Cmd` を含む組み合わせ（`Ctrl+P`、`Ctrl+R`、`Ctrl+X` など）は Unity のショートカットとして残り、選択・移動の操作は実行されません。例外は `Ctrl+A`、`Ctrl+I`、`Ctrl` + `+` / `-` です。

## 距離でマージ {#거리로-병합}

`距離でマージ` は、`マージ距離` の範囲内にある重複した頂点を 1 つにまとめます。削除や分離のあとに残った重複を整理するときに使います。

:::note[UV が異なる頂点は結合しません]
位置が同じでも UV が異なる頂点は、結合しません。UV のシームが残り、テクスチャが崩れないようにするためです。同じ理由で、ブレンドシェイプのデルタが大きく異なる頂点も結合しません。
:::

ボーンウェイトとブレンドシェイプは保持されます。

## 塗った領域の処理 {#칠한-영역-정리}

`選択・移動` の **塗った領域の処理** を開くと、選択した対象すべてに適用されます。パネルの上部に、適用対象の一覧が表示されます。

1. 変更する領域または保護する領域を塗るか、既存の頂点・エッジ・フェイスの選択に強さを適用します。
2. 青は処理する領域、緑は保護する領域です。削除モードでは、オレンジのフェイスが実際に削除されるフェイスです。
3. `Ctrl` を押すと消去、`Shift` を押すと領域の強さをなめらかにします。`Esc` は現在のストロークを取り消します。

塗った領域でできることは 3 つあります。

- **塗った面を削除**: 塗った三角形を削除し、使われなくなった頂点を整理します。
- **塗った部分を Shrink キーで隠す**: 服や髪の内側へ入れる新しい表情キーを作ります。基本の頂点はそのまま残り、キー 100% でプレビューされます。
- **部分的な簡略化**: 塗った強さと保護の強さを反映して、頂点を減らします。`削減結果を計算` で結果を先に計算し、`プレビュー結果を適用` で適用します。減らしたあと、同じ領域に Shrink キーを作ることもできます。

次の点に注意してください。

- 既存の表情で動く頂点を保護するオプションは別にあり、既定でオンです。顔の名前や頭のボーンでは、保護も除外もしません。
- UV のシーム、マテリアルの境界、開いた境界、大きなボーンウェイトの差は保持されます。そのため、目標より減らない場合があります。目標と実際の頂点数の両方を確認してください。
- 残るすべての頂点は、元の UV8、カラー、法線、接線、任意のボーン影響、すべてのシェイプフレームを保持します。
- 塗った領域はセッションの編集状態です。メッシュのカラーチャンネルは上書きしません。結果は `メッシュ保存` で保管します。
