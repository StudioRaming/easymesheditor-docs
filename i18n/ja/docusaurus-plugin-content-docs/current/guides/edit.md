# 編集

**このドキュメントを読むと**、頂点・エッジ・フェイスを選択する方法、ギズモとBlender式モーダル変形の違い、Altクリックでエッジループをキャプチャするルール、そして隠す・ピボット・法線・マージ・分離まで`編集`タブのすべての動作が理解できます。

## 要素モード {#요소-모드}

| ボタン | キー |
|---|---|
| `頂点（1）` | `1` |
| `エッジ（2）` | `2` |
| `フェイス（3）` | `3` |

選択状態は`選択 — 頂点 {0} · エッジ {1} · フェイス {2}`で表示されます。

## 選択 {#선택}

| 操作 | 結果 |
|---|---|
| クリック | 置換選択 |
| `Shift`+クリックまたは`Ctrl`+クリック | 切替 |
| ダブルクリックまたは`L` | カーソル下の連結要素全体を選択（`リンク選択（L）`） |
| `Shift+L` | 連結要素を解除 |
| `B`または空きスペースドラッグ | ボックス選択（`Shift`=追加、`Ctrl`=削除） |
| `A` / `Alt+A` | `全選択（A）` / `選択解除（Esc）` |
| `Ctrl+I` | `反転（Ctrl+I）` |

`B`を押すとウィンドウは`ボックス選択待機 — シーンビューでドラッグ · Shift=追加 · Ctrl/Cmd=削除 · Esc/B=取消`と通知します。ボックス選択は三角形のエッジが矩形を横切る場合もキャッチします。

:::note[UVシーム頂点は一緒にキャッチされます]
Unityメッシュは紫外線の境界で同じ位置の頂点が複数に分割されます。選択は位置に基づいてそのグループ全体を一緒にキャッチするため、画面上で1点を選んでも、実際には後ろで数個が一緒に動きます。→ [ウェルドグループ](/internals/session-and-undo#웰드-그룹)
:::

X-Ray（`Alt+Z`）が無効の場合、隠れた要素は描画も選択もされず、有効な場合は裏側を透過して選択します。

### エッジループとエッジリング {#엣지-루프와-엣지-링}

- `Alt+クリック`（押したままドラッグしない） — エッジループ
- `Ctrl+Alt+クリック` — エッジリング
- 両方`Shift`を一緒に押すと既存選択に追加

:::caution[`Alt+ドラッグ`はシーン回転のままです]
Unityのシーン回転を奪わないために、ループ選択は**ドラッグしなかったクリック**でのみ発生します。`Alt`を押したまま少しでもドラッグするとカメラが通常通り回転します。
:::

ループとリングはポールと境界で停止します。

### 選択の拡張と縮小

- `Ctrl` + `+` — `選択拡張（Ctrl++）`
- `Ctrl` + `-` — `選択縮小（Ctrl+-）`

テンキーの`+` `-`も動作します。

## ギズモ {#기즈모}

| ボタン | キー |
|---|---|
| `ビュー（Q）` | `Q` |
| `移動（W）` | `W` |
| `回転（E）` | `E` |
| `スケール（R）` | `R` |

Unityのデフォルトツール配置と同じです。ボーンのあるスキンメッシュでも逆スキニングを安全に適用して変形するため、ポーズが固定された状態で画面に見える通りドラッグできます。

複数のメッシュから各要素を選択した場合、ワールド空間の共通ギズモで一緒に変形します。→ [マルチメッシュ](/guides/multi-mesh)

## モーダル変形 {#모달-변형}

Blender式の`G` / `R` / `S`です。選択がある状態でシーンビューで押すとマウスだけで変形が開始されます。

| キー | 動作 |
|---|---|
| `G` | `移動（G）` |
| `R` | `回転（R）` |
| `S` | `スケール（S）` |

モーダル中は`X/Y/Z=軸（2回=ワールド）· Shift+軸=平面 · 数字=数値入力 · Enter/左クリック=確定 · Esc/右クリック=取消`で操作します

- 同じ軸キーをもう一度押すとローカル軸からワールド軸に変わります（`ローカル` / `ワールド`で表示）。
- `Shift+X`はXを除く平面で拘束します（`{0}を除く平面（{1}）`）。
- 数字を入力すると正確な値が入ります。回転は`度`単位です。
- 複数のメッシュを一緒に処理する場合、ローカル軸が1つに決定されないため`複数メッシュ → ワールド軸`にフォールバックします。

:::note[`R`は2つのことをします]
`R`は**選択があり、カーソルがシーンビュー上にある場合のみ**回転モーダルです。それ以外は、従来通りUnity式`R` = スケールギズモとして動作します。
:::

モーダル1回が元に戻す1ステップです。対称とプロポーショナル編集はギズモと完全に同じように適用されます。

## プロポーショナル編集 {#프로포셔널-편집}

`プロポーショナル編集（O）`を有効にすると、選択されていない周辺頂点が`半径`内で滑らかに追従します。フォールオフはスムーズ曲線です。

- `連結のみ`**有効** — トポロジー距離で計算します。重なっている別のパーツは引っ張られません。
- `連結のみ`**無効** — 空間距離で計算します。

半径は`[` `]`で調整します（プロポーショナルが無効な場合、同じキーが頂点表示サイズを調整します）。

[マスクモード](/guides/sculpt#마스크-모드)で暗くされた頂点はプロポーショナル影響から除外されます。

## 対称

`対称`X / Y / Zを組み合わせます。シーンビュートグルは`Shift+Alt+X` · `Shift+Alt+Y` · `Shift+Alt+Z`です。

編集タブの対称は**選択を拡大しません。**選択要素の変形結果をローカル軸の反対側にそのまま適用する方法です。対称平面上の中央頂点は平面に固定されます。

## ピボット {#피벗}

`ピボット`で回転・スケールの基準点を選びます。ギズモと`G`/`R`/`S`モーダル両方に適用されます。

| モード | 基準 |
|---|---|
| `中心点` | 選択要素の平均位置 |
| `個別原点` | 各要素が自分の位置を基準として |
| `アクティブ要素` | 最後に選択した要素 |
| `バウンディングボックス中心` | 選択を包囲するボックスの中央 |

複数のメッシュを一緒に処理するとき、`メッシュごとに均等`を有効にするとメッシュごとに独自のピボットを使用します。

## 隠す {#숨기기}

| ボタン | キー |
|---|---|
| `隠す（H）` | `H` |
| `選択以外を隠す（Shift+H）` | `Shift+H` |
| `全表示（Alt+H）` | `Alt+H` |

隠されたカウントは`非表示 {0}個 — Alt+Hで全表示`で表示されます。

:::note[隠すことは元に戻す対象ではありません]
隠すことはメッシュデータではなく、編集セッションの表示状態です。Blenderと同様に`Ctrl+Z`対象ではなく、構造が変わると（削除・分離・マージ）自動的に解除されます。
:::

## 法線 {#노멀}

| 項目 | 動作 |
|---|---|
| `法線を表示` | シーンビューに法線方向を描画します。`法線の長さ`で長さを調整 |
| `法線を反転` | 選択フェイスのwindingを反転します |
| `法線を再計算` | 選択頂点の法線をスムーズに再計算します |

結果は`フェイス {0}個の法線を反転しました` · `頂点グループ {0}個の法線を再計算しました`で報告されます。

反転はブレンドシェイプの法線・接線デルタも一緒に反転するため、表情キーのあるメッシュでも内側の面がずれません。

## 削除 {#삭제}

`選択削除（X · {0}フェイス）` — `X`、`Delete`、`Backspace`すべて動作します。選択されたフェイスを削除します。

削除後も、そのフェイスのみが使う頂点は頂点バッファに残ります。これらの孤立頂点は`Bake`時に1回整理されます。→ [孤立頂点の整理](/internals/bake#고아-정점-정리)

## 分離 {#분리}

| ボタン | キー | 結果 |
|---|---|---|
| `選択を分離（P）` | `P` | 選択要素を新しいオブジェクトに分割します |
| `アイランド分離（Shift+P）` | `Shift+P` | 選択領域を連結パーツごとに分割して分離します |

分離されたオブジェクトと共に、元の横に`<元名>_Part.asset`が作成されます。→ [生成されるファイル](/reference/output-files)

保存されるもの：頂点、法線、接線、UV0～UV3、カラー、サブメッシュ・マテリアル対応、bindpose、ボーンウェイト、ブレンドシェイプフレーム。

分離全体が1つの元に戻すステップです。途中で失敗すると、`分離に失敗したため元に戻しました: {0}`と共に元の状態にロールバックされ、作成途中の`_Part.asset`も削除されます。

:::caution[分離されたパーツのボーン影響は4つに制限されます]
Unity 2020.1以上で、頂点あたり4つ以上のボーン影響を持つメッシュを分離する場合、**分離されたパーツ側はレガシー4スロットに制限されます**。元のメッシュはそのままです。→ [制限事項](/limitations)
:::

## 距離でマージ {#거리로-병합}

`頂点マージ`セクションの`距離でマージ`は、`マージ距離`内の重複頂点を1つに合わせます。削除・分離後に残った重複をクリーンアップするときに使用します。

結果は`頂点 {0}個をマージしました` · `マージ対象の頂点がありません` · `頂点マージに失敗したためメッシュはそのままです`のいずれかで報告されます。

:::note[UVが異なる場合、マージされません]
位置が同じでもUV0が異なる場合、マージ候補から除外されます。これにより紫外線シームが保存され、テクスチャが破損しません。同様に、ブレンドシェイプデルタがメッシュサイズに比べて大きく異なる頂点もマージされません。
:::

ボーンウェイトとブレンドシェイプは保持されます。マージされたグループの属性は、最も小さいインデックスを持つ頂点の属性を使用します。
