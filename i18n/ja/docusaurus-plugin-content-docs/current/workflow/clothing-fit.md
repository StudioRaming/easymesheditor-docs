# 衣装のフィッティング

**このドキュメントを読むと**、異なるアバター用に作られた衣装を現在のアバターに着せるための完全な順序を — ウェイト転送から`Bake`まで — 一度に理解できます。

前提条件：アバターに衣装オブジェクトを取り付け、アバターボーンがすでに移植されています。衣装がボディを貫いたり、ポーズに追従しなかったり、表情キーがない状態です。

## 順序

1. [ウェイト転送](#1-웨이트-전송)
2. [対称ペイントで調整](#2-대칭-페인트로-보정)
3. [未使用ボーン結合](#3-안-쓰는-본-합치기)
4. [表情キーをインポート](#4-표정-키-가져오기)
5. [形状を調整](#5-형태-다듬기)
6. [Bake](#6-bake)

## 1. ウェイト転送 {#1-웨이트-전송}

衣装オブジェクトを選択して`Load` → `ウェイト`タブ。

`別メッシュからウェイトを取得`で：

- `ソースメッシュ` = アバターボディの`SkinnedMeshRenderer`
- `適用範囲` = `メッシュ全体`
- `最大距離` = デフォルト値から開始し、`範囲外`頂点が多く報告される場合は少しずつ上げます

`ウェイトを取得`をクリックして結果を確認します。

> `ウェイトを取得しました — 適用{0}頂点・範囲外{1}頂点・スキップ{2}頂点。`

`範囲外`が0になるまで距離を上げるより、残った少数を次のステップで手で塗る方が結果が良いです。距離を過度に増やすと無関係なボーンがついてきます。

:::caution[結果全体がずれている場合は空間の問題です]
ソースとターゲットレンダラーのトランスフォームが異なる場合、ウィンドウが警告を表示します。その時は`ソーストランスフォームを無視（バインドポーズのローカル空間で照合）`を有効にして再実行してください。→ [ウェイトペイント](/guides/weight-paint#전송-공간)
:::

名前が対応していないソースボーンがある場合は、`対応ボーンが見つからないソースボーン{0}個の影響（合計{2}）は破棄しました: {1}`で一覧が表示されます。これらのボーンが実際に必要な場合は、ボーン移植ステップに戻って名前を合わせる方が速いです。

## 2. 対称ペイントで調整 {#2-대칭-페인트로-보정}

転送は表面近接マッピングなため、袖の先端、襟、スカートの裾のような体から離れた部分が不自然に見えます。

1. `ウェイト表示`を有効にしてヒートマップで何が異常かを確認します。
2. `対称ペイント`を有効にします。`対称ボーン: {0}`が正しくキャッチされているか確認してください。
3. 腕や脚を曲げたポーズで`加算（1）` · `減算（2）` · `スムーズ（3）`で塗ります。
4. 広い面を均等にするときは`ブラー（4）` · `平均（5）`が速いです。

`対称ボーンなし — 中央ボーンとして両側を同じボーンで塗ります。`が表示される場合、そのボーンは中央ボーンとして扱われます。左右ボーンなのにこのメッセージが表示される場合は、リグの名前規則がサポートされている形式と異なります。→ [名前マッチングルール](/guides/weight-paint#대칭-페인트)

複数ボーンをチェックして`選択ボーンのスムーズ`を使用すれば、関節周辺の境界が一度に整理されます。

## 3. 未使用ボーン結合 {#3-안-쓰는-본-합치기}

衣装が元々のアバターで使用していない不要なボーンが残っている場合、削除する前にウェイトを親に移す必要があります。

`ボーンウェイトの結合`で`アクティブボーンを親（{0}）へ結合`を使用します。移動後、そのボーンのウェイトが0になり、階層から安全に削除できます。

複数ボーンを一度にクリーンアップするときはターゲットボーンをアクティブにし、削除するボーンをチェックして`チェック済み{0}個のボーンをアクティブボーンへ結合`をクリックします。

## 4. 表情キーをインポート {#4-표정-키-가져오기}

衣装にフードやマスクのように顔を覆う部分がある場合、表情キーが必要です。

`ブレンドシェイプ`タブ → `別メッシュからキーを取り込む`。

- `ソースメッシュ` = アバター顔メッシュ
- 必要なキーのみをチェックします（`全選択`は通常過剰です）
- `最大距離`を決定して`転送`

対応点が見つからない頂点は動きません — `対応点が見つからなかった頂点 {1}個は動きません — 最大距離を大きくしてみてください。`

同じ名前のキーが既に存在する場合、置き換えるか確認されます。保護したいキーは事前に`L`でロックしてください。ロック中のキーは転送ではスキップされます。

## 5. 形状を調整 {#5-형태-다듬기}

ここまでで動きは正しくなります。残りはボディを貫く部分です。

`スカルプト`タブで：

- `エラスティック（1）`で貫いている部分を内側に押し込みます。
- 対称を有効にして`対称平面を表示`で軸が合っているか確認します。
- 触ってはいけない部位は`マスクモード（M）`の`アイランド`でクリックしてロックします。

ボディ側を削除する方法もあります。`編集`タブで衣装で完全に隠れるフェイスを選択して`選択削除（X · {0}フェイス）`で削除すればポリゴン数も減ります。削除後に残る孤立頂点は`Bake`時に自動的に整理されます。

`Alt+Z`X-Rayを有効にして衣装の内側のボディ表面を透視しながら選択できます。

## 6. Bake {#6-bake}

衣装とボディを一緒に`Load`した場合、`Bake`1回で各々の`_Edit.asset`が作成されます。結果テーブルですべてが`成功`であることを確認してください。

`Bake`前にバッジが`編集確定待ち`の場合、ブレンドシェイプ編集を先に確定またはキャンセルする必要があります。

## 後で再編集が必要な場合

`_Edit.asset`を使用しているレンダラーを再度`Load`して続行します。同じソースから出力されたアセットの場合、`Bake`は**同じファイルをGUIDを保持したまま更新**するため、プリファブやアニメーションの参照が切れません。→ [生成されるファイル](/reference/output-files)
