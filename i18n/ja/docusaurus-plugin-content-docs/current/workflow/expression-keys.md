# 表情キーを作る

**このページを読むと** 新しい表情キーを造形し、ミラーキーで左右に広げ、グループとロックで一覧を整理し、キーが正しく作られたかを確認する手順がわかります。

前提: `SkinnedMeshRenderer` を `読み込み` していて、`表情キー` タブを開いていること。

## 手順

1. [基準の状態を作る](#1-기준-상태-만들기)
2. [片側だけを造形する](#2-한쪽만-조형)
3. [ミラーキーで反対側を作る](#3-미러-키로-반대쪽-만들기)
4. [グループとロックで整理する](#4-그룹과-잠금으로-정리)
5. [確認する](#5-확인)
6. [保存する](#6-저장)

## 1. 基準の状態を作る {#1-기준-상태-만들기}

新しいキーは、**いま画面に見えている絶対的な形**を基準に始まります。ほかのキーがオンになっていると、その形の上に造形することになります。

始める前に `全て0にリセット` を押して、すべてのキーを 0 に下げておきましょう。特定の表情の上に重ねるキーを作るときだけ、意図的にキーをオンにしておきます。

## 2. 片側だけを造形する {#2-한쪽만-조형}

新規キーのボタン、またはシーンビューで `N` を押します。

造形中であることを示すバーが表示されたら、造形が始まっています。

- ドラッグ: つかんで動かす（グラブ）
- `Shift`: なめらかに
- `F`: 半径、`Shift+F`: 強さ

`キー名` の欄に、左右がはっきりわかる名前を入力します。次の手順のミラーは、この名前を反転させて使います。

| 名前の例 | ミラーの結果 |
|---|---|
| `eye_close_L` | `eye_close_R` |
| `L_brow_up` | `R_brow_up` |
| `smileLeft` | `smileRight` |
| `cheek_puff` | `cheek_puff_Mirror` |

`Enter` で新しいキーを確定します。気に入らなければ `Esc` で取り消します。

:::note[確定しても、アセットはまだ変わりません]
ここでの確定は、**セッション内での確定**です。メッシュアセットに反映されるのは `メッシュ保存` のときです。→ [表情キー](/guides/blendshape#기존-키-편집)
:::

造形がしっくりこなければ、後から手を入れ直せます。一覧でそのキーの編集ボタンを押すと、100% の形が読み込まれ、続きを造形できます。このとき `形を整える` や `選択・移動` のタブに移って作業することもできます（複数タブ編集）。戻ってきたら `保存` で終えます。頂点数が変わる操作（削除、分離）は、キー編集中には保存できません。

## 3. ミラーキーで反対側を作る {#3-미러-키로-반대쪽-만들기}

直前に作ったキーの行で `M` を押します。ミラー軸は通常 X です。

左右のトポロジーが完全に一致している必要はありません。空間上の対応で対になる点を探します。対になる点がない頂点は、対称面の上にある場合にのみ反転されます。

ミラーキーが作られない場合は、対称のペアが見つからなかったということです。メッシュが最初から左右非対称であれば、反対側は手で造形するしかありません。

## 4. グループとロックで整理する {#4-그룹과-잠금으로-정리}

キーが 20 個を超えると、一覧が長くなります。

- `グループ` をオンにすると、名前の接頭辞で一覧が折りたたまれます。`eye_`、`mouth_`、`brow_` のような接頭辞を決めておくと、管理が楽になります。
- 完成したキーは、行の `L` でロックします。ロックしたキーは、一括の値変更、削除、別のメッシュからのキーの取り込みの対象から外れます。

`Ctrl` や `Shift` を押しながらクリックして複数のキーを選び、まとめてロックすることもできます。

順番を整えるときは、キーを選んでから `^` / `v` を使います。複数のキーを移動するのも、元に戻す操作 1 回として扱われます。

## 5. 確認する {#5-확인}

作ったキーが、意図した場所だけを動かしているかを確認します。

1. 行の `S` を押して[ソロプレビュー](/guides/blendshape#솔로-프리뷰)をオンにします。そのキーだけが 100 で表示されます。
2. `ヒートマップ` をオンにして、そのキーをクリックします。実際に動く頂点が色で表示されます。
3. 関係のない場所が色づいていれば、造形したときのブラシの半径が広すぎたということです。編集に戻って整えてください。
4. `Esc` でソロを解除します。

`拡張範囲` をオンにすると、スライダーを `-100～200` まで動かせます。誇張したときに形が崩れないかを確認する用途です。その極端な値のまま保存しないでください。

## 6. 保存する {#6-저장}

保存の方法は 2 つあります。

- **`メッシュ保存`**: キーの構造を含むメッシュ全体を、`<元の名前>_Edit.asset` に焼き込み、セッションを終わらせます。
- **`新規キーとして保存`**: 基本の形に今回追加した変形だけを新しいキーとして残し、セッションは続けます。

キーを作る作業であれば、ふつうは `メッシュ保存` を押します。`新規キーとして保存` は、「`形を整える` で形を変えたけれど、基本の形はそのままにして、この変形だけをキーとして残したい」という場合に使います。→ [クイックキャプチャとメッシュ保存](/guides/blendshape#빠른-캡처와-bake)

## 既存の表情を取り戻す

基本の形を変えたあとで、元の顔が必要になることがあります。そのキーの行にある `反転` を押すと、反転したキー（`_Revert`）が作られます。

今の見た目を 1 つのキーに固めたい場合は、`適用値を結合` を使います。0 ではないキーの結果が、新しい 100% のキーになり、元になったキーの値は 0 に戻ります。
