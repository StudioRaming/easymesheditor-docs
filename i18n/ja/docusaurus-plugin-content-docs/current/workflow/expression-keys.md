# 表情キーの作成

**このドキュメントを読むと**、新しい表情キーを造形して左右対称に広げ、グループとロックでリストを管理し、実際に正しく作成されたかを確認する順序が理解できます。

前提条件：`SkinnedMeshRenderer`を`Load`して`ブレンドシェイプ`タブにいます。

## 順序

1. [ベース状態を作成](#1-기준-상태-만들기)
2. [片側だけ造形](#2-한쪽만-조형)
3. [ミラーキーで反対側作成](#3-미러-키로-반대쪽-만들기)
4. [グループとロックで整理](#4-그룹과-잠금으로-정리)
5. [確認](#5-확인)
6. [保存](#6-저장)

## 1. ベース状態を作成 {#1-기준-상태-만들기}

新しいキーは**現在画面に表示される絶対的な形態**を基準に開始します。他のキーが有効な場合、その形態上で造形することになります。

`全て0にリセット`を押して全キーを0にして開始してください。特定の表情上に重ねるキーを作成するときだけ意図的に有効にしておきます。

## 2. 片側だけ造形 {#2-한쪽만-조형}

`+ 新規シェイプ（N）`またはシーンビューで`N`。

シーンビューに`新規シェイプ造形中: {0}`バナーが表示されたら造形を開始します。

- ドラッグ = グラブ、`Shift` = スムーズ
- `F` = 半径、`Shift+F` = 強度

`名前`フィールドに左右が明確な名前を入力します。次のステップのミラーがこの名前を反転します。

| 名前の例 | ミラー結果 |
|---|---|
| `eye_close_L` | `eye_close_R` |
| `L_brow_up` | `R_brow_up` |
| `smileLeft` | `smileRight` |
| `cheek_puff` | `cheek_puff_Mirror` |

`Enter`で`新規キーを確定（Enter）`、気に入らなければ`Esc`。

:::note[確定してもまだアセットは変わりません]
ここでの確定は**セッションへの確定**です。メッシュアセットに入るのは`Bake`時です。→ [ブレンドシェイプ](/guides/blendshape#기존-키-편집)
:::

造形が気に入らなければ再編集できます。リストからそのキーの編集ボタンをクリックすると100%形態が読み込まれて続けて造形します。この際`スカルプト`・`編集`タブに移動して作業してもいいし（`マルチタブ編集`）、戻ってきて`現在のキーを確定（Enter）`で終了します。ただし**頂点数が変わる作業（削除・分離）は保存できません。**

## 3. ミラーキーで反対側作成 {#3-미러-키로-반대쪽-만들기}

作成したばかりのキー行の`M`をクリックします。`ミラー軸`は通常Xです。

> `ミラーキー「{0}」を{1}軸基準で作成しました。`

左右トポロジーが完全に同じである必要はありません。空間マッチングでペアを見つけ、ペアなし頂点は対称平面上にあるときのみ反射されます。

作成されない場合は対称ペアが見つからなかったためです — `「{0}」のミラーキーを作成できませんでした。`メッシュが元々左右非対称な場合は反対側を手で造形する必要があります。

## 4. グループとロックで整理 {#4-그룹과-잠금으로-정리}

キーが20個を超えるとリストが長くなります。

- `グループ`を有効にすると名前プリフィックスで折り畳まれます。`eye_`、`mouth_`、`brow_`のようにプリフィックスを決めておくと管理が容易になります。
- 完成したキーは行の`L`でロックします。ロック中のキーは一括値変更、削除、別メッシュからの転送から除外されます。

複数キーを`Ctrl`・`Shift`クリックで選択して`ロック`を一括適用できます — `キー {0}個をロックしました。`

順序を整理するときは選択後`^` / `v`を使用します。複数キーの移動も1つの元に戻すステップです。

## 5. 確認 {#5-확인}

作成したキーが意図した場所のみを動かすか確認します。

1. 行の`S`で[ソロプレビュー](/guides/blendshape#솔로-프리뷰)を有効にします。そのキーのみが100で表示されます。
2. `ヒートマップ`を有効にしてそのキーをクリックします。実際にデルタがある頂点が色で表示されます — `ヒートマップ: 「{0}」・最大移動量 {1}`
3. おかしな場所が色付けされた場合、造形時のブラシ半径が大きかったものです。編集に戻ってチューニングしてください。
4. `Esc`でソロを解除します。

`拡張範囲`を有効にして`-100～200`まで押して、大げさにしたときに形状が崩れないかを確認できます。そのままの値で保存しないでください。

## 6. 保存 {#6-저장}

2つの方法があります。

- **`Bake`** — キー構造を含むメッシュ全体を`<元名>_Edit.asset`に保存してセッションを終了します。
- **`新規キーとして保存`** — ベースに追加した変形のみを新しいキーとして保存し、セッションを続行します。

キー作成作業の場合は通常`Bake`です。`新規キーとして保存`は「スカルプトで形状を変更したが、ベースは保持してこの変形だけをキーにしたい」という状況用です。→ [クイックキャプチャとBake](/guides/blendshape#빠른-캡처와-bake)

## 既存表情を復元

ベースメッシュを変更した後に元の顔が必要になることがあります。そのキー行の`リバート`が反転キー（`_Revert`）を作成します。

複数キーが有効な現在の状態を1つの状態として固めたい場合は`適用値を結合`を使用します。現在0以外のキーの結果が新しい100%キーになり、素材として使用されたキーの値は0にリセットされます。
