# Easy Mesh Editor

**Unity のシーンビューの中でメッシュを直接編集するツール**です。

:::info[0.1.x をお持ちの方は無料でアップデートできます]
更新の前に、開いている編集を `メッシュ保存` で保存するか `編集を破棄` で捨て、Easy Mesh Editor のウィンドウを閉じてください。ソース（.cs）版を以前に入れていた場合は、先に削除してください。そのうえで、新しい `.unitypackage` を既存の `Assets/StudioRaming/EasyMeshEditor` フォルダーの上にそのままインポートしてください。0.1.x で保存した `_Edit.asset` はそのまま残り、引き続き動作します。1.0 で同じメッシュをもう一度保存すると、`<元の名前>_Edit 1.asset` が新しく作られます。→ [0.1.x からの更新](/getting-started/installation#0-1x에서-올리기)
:::

メッシュを直すためにプロジェクトの外へ出る必要はありません。アバターを着せたままの状態で、いま見ているポーズの上から表面を押し、頂点を動かし、表情キーを作り、スキンウェイトを塗れます。FBX を書き出して再インポートし、マテリアル・物理・プレハブの参照を組み直す往復作業がなくなります。

VRChat や WARUDO のアバターと衣装を作る人のためのツールです。衣装が体に食い込む場所を押し込み、新しいパーツにウェイトを移し、表情キーを左右対称に作る、時間のかかる作業をこの 1 つのウィンドウでまとめて行えます。

Unity Editor 専用です。プレイヤービルドに入るランタイム機能ではありません。

## 4 つの作業タブ

| タブ | 役割 | 対象 |
|---|---|---|
| `形を整える` | ブラシ 5 種で表面を引っぱり、整え、ふくらませます | SkinnedMeshRenderer · MeshRenderer |
| `選択・移動` | 頂点・エッジ・フェイスを選び、動かし、削除し、分離し、結合します | SkinnedMeshRenderer · MeshRenderer |
| `表情キー` | 表情キーを作成・編集し、ミラーキーを作り、別のメッシュから取り込みます | SkinnedMeshRenderer 専用 |
| `ボーン接続` | ボーンウェイトを塗り、結合し、別のメッシュから取り込みます | SkinnedMeshRenderer 専用 |

4 つのタブは 1 つの編集セッションを共有します。タブを切り替えても、選択・マスク・元に戻す履歴はそのまま残ります。

## 元のアセットは変更しません

このツールの安全の仕組みは 1 文で言えます。**`メッシュ保存`（Bake）を押すまで、元のメッシュアセットは変わりません。**

1. `読み込み` を押すと、元のメッシュを複製した一時メッシュ（Work Mesh）ができ、レンダラーがそれを使います。
2. すべての編集は Work Mesh の上で行われます。
3. `メッシュ保存` を押すと、元のアセットの隣に `<元の名前>_Edit.asset` ができ、レンダラーがそのアセットを使うようになります。
4. `編集を破棄` を押すと編集内容を捨て、レンダラーは元のメッシュに戻ります。

スクリプトの再コンパイルやプレイモードへの移行で作業が消えることはありません。編集中の Work Mesh は `Library/EmeAutoSave/` に保存され、編集モードに戻ると復元されます。→ [セッションと元に戻す](/internals/session-and-undo)

:::note[`メッシュ保存` でセッションは終わります]
作業の途中で何度も押すボタンではありません。すべて終えてから 1 回押すボタンです。編集中に表情を 1 つだけ残したいときは `新規キーとして保存` を使ってください。こちらはアセットをまだ変更しません。→ [クイックキャプチャと Bake](/guides/blendshape#빠른-캡처와-bake)
:::

## ドキュメントの構成

**タブ別の使い方**は、ウィンドウの 4 つのタブと 1 対 1 で対応しています。画面に表示されたタブ名で目的のページを探せます。

| ウィンドウのタブ | ページ |
|---|---|
| ウィンドウ共通（ヘッダー・対象・保存） | [ウィンドウの使い方](/guides/window) |
| `形を整える` | [形を整える](/guides/sculpt) |
| `選択・移動` | [選択・移動](/guides/edit) |
| `表情キー` | [表情キー](/guides/blendshape) |
| `ボーン接続` | [ボーン接続](/guides/weight-paint) |

:::note[ラベルは画面に表示される文言です]
このドキュメントでバッククォートで囲んだ文言（`読み込み`、`自動正規化`、`距離でマージ` など）は、UI に**実際に表示されるラベル**です。英語や日本語でウィンドウを使っている場合は、その言語版のドキュメントを見てください。
:::

## 不具合の報告

バグ・質問・フィードバック: `studioraming@gmail.com`

報告するときに次の内容を添えていただくと、再現が早くなります。

1. Unity のバージョン（例: `2022.3.22f1`）
2. レンダーパイプライン（BRP / URP）
3. Easy Mesh Editor のバージョン（ウィンドウのヘッダーのバージョンバッジ、またはこのサイト上部のバッジ）
4. Console のログ全文
5. 再現手順: どのメッシュを読み込み、どのタブで何を押したか
