# Easy Mesh Editor

**Unityシーンビュー内のミニBlender**です。

メッシュを修正するためにプロジェクト外に出ます必要がありません。アバターを着せたまま、今見ているポーズの上で表面を押し、頂点を削除し、表情キーを作成し、スキンウェイトを塗ります。FBXを再度エクスポートして再度インポートし、マテリアル・物理・プリファブ参照を再度設定する往復がなくなります。

VRChat・WARUDOアバターと衣装を作成する人向けのツールです。衣装が体を貫く部分を押し込み、新しいパーツにウェイトを移し、表情キーを左右対称で作成する — 実際に時間を費やす作業がこのウィンドウ1つに含まれています。

UnityEditor専用です。プレイヤービルドに入るランタイム機能ではありません。

## 4つのタブ

| タブ | 処理内容 | 対象 |
|---|---|---|
| `スカルプト` | 5種類のブラシで表面を押して引いて調整します | SkinnedMeshRenderer · MeshRenderer |
| `編集` | 頂点・エッジ・フェイス選択、ギズモとモーダル変形、削除・分離・マージ | SkinnedMeshRenderer · MeshRenderer |
| `ブレンドシェイプ` | 表情キーを作成、修正、ミラー、別のメッシュからインポート | SkinnedMeshRenderer専用 |
| `ウェイト` | ボーンウェイトを塗画、結合、別のメッシュからインポート | SkinnedMeshRenderer専用 |

4つのタブは1つの編集セッションを共有します。タブを切り替えても選択・マスク・元に戻す履歴がそのまま残ります。

## 元データには手を加えません

このツールのセーフティモデルは1文です。**`Bake`を押すまで、元のメッシュアセットは変更されません。**

1. `Load`を押すと、元データのコピーである一時メッシュ（Work Mesh）が作成され、レンダラーがそれを使用します。
2. すべての編集はWork Mesh上で行われます。
3. `Bake`を押すと、元の横に`<元名>_Edit.asset`が作成され、レンダラーがそのアセットを使用するようになります。
4. `Revert`を押すか、ウィンドウを閉じるとレンダラーは元のメッシュに戻ります。

エディターがスクリプトを再度コンパイルしたり、プレイモードに入っても、作業が消えることはありません。リロード直前にWork Meshが`Library/EmeAutoSave/`に直列化され、リロード後に自動的に復元されます。→ [セッションと元に戻す](/internals/session-and-undo)

:::note[`Bake`はセッションを終了します]
作業中に繰り返し押すボタンではありません。すべての作業が終わった後に1回押すボタンです。編集中に表情キーだけ1つ保存したい場合は`新規キーとして保存`を使用してください — こちらはまだアセットを変更しません。→ [クイックキャプチャとBake](/guides/blendshape#빠른-캡처와-bake)
:::

## ドキュメント構造

**タブ別の使い方**はウィンドウの4つのタブと1対1で対応しています。画面上で見たタブ名そのままでドキュメントを見つけることができます。

| ウィンドウのタブ | ドキュメント |
|---|---|
| ウィンドウ共通（ヘッダー・ターゲット・保存） | [ウィンドウの使い方](/guides/window) |
| `スカルプト` | [スカルプト](/guides/sculpt) |
| `編集` | [編集](/guides/edit) |
| `ブレンドシェイプ` | [ブレンドシェイプ](/guides/blendshape) |
| `ウェイト` | [ウェイトペイント](/guides/weight-paint) |

:::note[ラベルは画面に表示されるテキストそのものです]
このドキュメントでバッククォートで囲まれたテキスト（`Load`、`自動正規化`、`距離でマージ` …）は、日本語UIに**実際に表示されるラベル**です。英語・日本語でウィンドウを使用している場合は、その言語のドキュメントを参照してください。
:::
