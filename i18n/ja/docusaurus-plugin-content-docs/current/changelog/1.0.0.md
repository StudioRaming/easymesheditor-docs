## アップグレード時に確認すること

:::caution[編集セッションを開いたままアップデートしないでください]
開いている編集は `メッシュ保存` で保存するか `編集を破棄` で捨て、ウィンドウを閉じてからアップデートしてください。ソース（`.cs`）版を入れていたプロジェクトは、先にソース版を削除します。→ [インストール](/getting-started/installation#0-1x에서-올리기)
:::

:::caution[タブとボタンの名前が変わりました]
ウィンドウのタブは `形を整える` · `選択・移動` · `表情キー` · `ボーン接続` です。ボタンは `読み込み` · `メッシュ保存` · `編集を破棄` で、新しいキーの保存は `新規キーとして保存` です。以前のページの名前は、ここで対応する名前として読み替えてください。→ [ウィンドウの使い方](/guides/window)
:::

:::caution[同じ元のメッシュを使うレンダラーは、それぞれ別に編集します]
0.1.x では、同じ元のメッシュを使うレンダラーのうち 1 つだけが開きました。1.0.0 では、それぞれ別々に読み込み、別々に編集し、結果もそれぞれ別に保存されます。→ [複数メッシュ](/guides/multi-mesh)
:::

:::caution[破棄の確認ダイアログでは Enter と Esc が作業を残します]
作業を破棄する確認ダイアログでは、`Enter` は `そのままにする`、`Esc` は `取消` です。どちらのキーも作業は残ります。実行するには、操作名の書かれたボタンを押してください。
:::

## 新機能

- **Unity 6 対応**: Unity 6000.0 と 6000.3 (LTS) に対応しました。対応範囲は Unity 2019.4、2021.3、2022.3、6000.0、6000.3 (LTS) です。→ [インストール](/getting-started/installation)
- **複数のメッシュを同時に編集**: MeshRenderer と SkinnedMeshRenderer を、Hierarchy または候補の一覧から選んで一緒に編集できます。→ [複数メッシュ](/guides/multi-mesh)
- **塗った領域の整理**: 塗ったフェイスを削除する、塗った部分を Shrink キーで隠す、部分的な簡略化で頂点を減らす、の 3 つができます。既存の表情で動く頂点を保護するオプションは、既定でオンです。→ [選択・移動](/guides/edit#칠한-영역-정리)
- **ペンの筆圧を、サイズと強さに別々に適用**: `筆圧サイズ` と `筆圧の強さ` を、それぞれ 0～100% で設定できます。→ [形を整える](/guides/sculpt#필압-적용량)
- **メッシュの分離**: 選択、連結アイランド、グループ（G0～G9）ごとに分離できます。パーツは `メッシュ保存` のときにファイルとして保存されます。分離のとき、UV、ブレンドシェイプのフレーム、頂点ごとの影響ボーン数はそのまま引き継がれます。→ [選択・移動](/guides/edit#분리)
- **ボーン接続タブの作り直し**: ボーンのツリー、ヒートマップ、自動正規化、最大影響ボーン数、対称ペイント、ボーンのロック、ボーンウェイトの結合、別のメッシュからのウェイトの取り込みを、1 つのタブで行えます。→ [ボーン接続](/guides/weight-paint)
- **表情キーの機能拡張**: ミラーキーの自動作成、デルタヒートマップ、別のメッシュからのキーの取り込み、キーのロック、適用値の結合、複数キーの一括操作ができます。→ [表情キー](/guides/blendshape)
- **シーンビューのオーバーレイ**: Unity 2021.2 以降では、シーンビューのヒント、ツールのパネル、ショートカットシートが、Unity 標準のシーンビューのオーバーレイの上に描画されます。2019.4 と 2020 では従来の方法で描画されます。
- **Connected Only を置く場所を追加**: `連結のみ` オプションを、シーンビューのオーバーレイと、かんたんに始めるの `詳しい設定` からもオンにできます。
- **編集内容の保持**: 編集中のメッシュは、Play モードへの移行、ウィンドウやシーンを閉じるとき、スクリプトのリロード、エディター終了のときに、確認なしで保持され、戻ると復元されます。保存していない編集がある間は、少なくとも 60 秒ごとにチェックポイントが保存されます。予期せず終了した後は、復元バナーで復元を選べます。→ [セッションと元に戻す](/internals/session-and-undo#자동-보존과-복원)
- **編集中のシーン保存**: 編集中にシーンやプレハブを保存すると、元のメッシュが記録され、編集セッションはそのまま続きます。
- **出力名**: `メッシュ保存` の結果は、元のメッシュの隣に `<元の名前>_Edit.asset` として保存されます。ほかの作者のアセットは上書きされません。→ [生成されるファイル](/reference/output-files)

## 変更点

- 元に戻せる操作は、確認ダイアログなしで実行されます。アセットを書き込む操作や作業を破棄する操作だけが、先に確認を求めます。→ [セッションと元に戻す](/internals/session-and-undo)
- `Esc` は、進行中のストロークやサイズ変更だけを取り消します。表情キーの編集は破棄しません。
- 保存していない編集がある場合、別の対象は読み込まず、案内を表示します。
- 同じ名前の表情キーを作るときと、キー編集を取り消すときは、確認を求めます。これらのダイアログでの `Enter` と `Esc` の動作は、上の `アップグレード時に確認すること` を参照してください。
