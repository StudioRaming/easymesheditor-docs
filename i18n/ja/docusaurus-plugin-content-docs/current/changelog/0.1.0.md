*リリース：2026-07-14*

Easy Mesh Editorの初リリースです。Unityシーンビュー内でメッシュを造形し、編集し、ブレンドシェイプとスキンウェイトを扱う4つのタブが含まれています。

## 新機能

- **`スカルプト`タブ** — エラスティック・スムーズ・フラット化ブラシで表面を直接造形します。→ [ドキュメント](/guides/sculpt#브러시)
- **`編集`タブ** — 頂点・エッジ・フェイス選択とギズモ変形、削除と分離。→ [ドキュメント](/guides/edit#요소-모드)
- **`ブレンドシェイプ`タブ** — 表情キーを作成、修正、名前変更、順序変更します。→ [ドキュメント](/guides/blendshape#목록)
- **`ウェイト`タブ** — ボーンツリーからボーンを選び、シーンビューでウェイトをペイントします。→ [ドキュメント](/guides/weight-paint#본-고르기)
- **Work Meshセーフティモデル** — `Bake`前は元のメッシュアセットは変更されません。→ [ドキュメント](/internals/session-and-undo#work-mesh)
- **マルチメッシュセッション** — トポロジーが異なるターゲットを一緒に開き、共有ギズモで変形します。→ [ドキュメント](/guides/multi-mesh#활성-대상)
- **プロポーショナル編集** — 選択していない周辺頂点が半径内でスムーズに追従します。→ [ドキュメント](/guides/edit#프로포셔널-편집)
- **空間ベース対称** — 左右頂点数が正確に同じでなくても対応点を見つけます。→ [ドキュメント](/guides/sculpt#대칭)
- **アイランドマスク** — タッチすべきでないクラスターをクリックでロックします。→ [ドキュメント](/guides/sculpt#마스크-모드)
- **provenance ベース保存** — 同じソースからの出力はGUIDを保持しながら更新し、他人のアセットは上書きしません。→ [ドキュメント](/reference/output-files#provenance와-owner)
- **3言語** — 日本語・English・日本語 UIとタブ別内蔵ガイド。

## ドキュメント

- サポート範囲はUnity 2019.4.31f1～2022.3.22f1です。→ [ドキュメント](/getting-started/installation)
