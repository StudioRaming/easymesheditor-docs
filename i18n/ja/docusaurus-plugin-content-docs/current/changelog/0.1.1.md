## アップグレード時の確認事項

:::caution[`Bake`時に未使用頂点が整理されます]
フェイスを削除した後に残っていた未使用頂点が`Bake`出力から削除されます。頂点インデックスが変わるため、頂点インデックスに依存する外部ツールがあれば再確認してください。→ [ドキュメント](/internals/bake#고아-정점-정리)
:::

:::caution[`ウェイト`タブに`自動正規化`オプションが追加されました]
デフォルトはオンなので既存の動作と同じです。オフにすると純加減算になり、ウェイト合計が1でない状態で残る可能性があります。→ [ドキュメント](/guides/weight-paint#자동-정규화와-최대-영향-본-수)
:::

:::caution[`編集`タブで`Alt+クリック`がエッジループを選択します]
ドラッグしない`Alt+クリック`にのみ反応するため`Alt+ドラッグ`シーン回転はそのままです。`Alt`を押したまままクリックする習慣があれば選択が変わる可能性があります。→ [ドキュメント](/guides/edit#엣지-루프와-엣지-링)
:::

:::caution[`Bake`出力のメッシュ名がファイル名と同じになります]
アセット内のメッシュオブジェクト名をファイル名に合わせます。メッシュ名文字列でアセットを見つけるスクリプトがあれば確認してください。→ [ドキュメント](/internals/bake)
:::

## 新機能

- **`G` / `R` / `S`モーダル変形** — 軸拘束と数値入力ができるBlender式移動·回転·スケール。→ [ドキュメント](/guides/edit#모달-변형)
- **エッジループとエッジリング** — `Alt+クリック`でループ、`Ctrl+Alt+クリック`でリングをつかみます。→ [ドキュメント](/guides/edit#엣지-루프와-엣지-링)
- **選択の拡張/縮小** — `Ctrl`+`+` / `-` 。→ [ドキュメント](/guides/edit#엣지-루프와-엣지-링)
- **隠す** — `H` · `Shift+H` · `Alt+H` 。元に戻す対象ではなく、構造が変わると自動解除されます。→ [ドキュメント](/guides/edit#숨기기)
- **ピボットモード4種** — `中心点`·`個別原点`·`アクティブ要素`·`バウンディングボックス中心`。→ [ドキュメント](/guides/edit#피벗)
- **法線表示·反転·再計算** — 反転はブレンドシェイプ法線·接線デルタまで一緒に反転されます。→ [ドキュメント](/guides/edit#노멀)
- **`距離でマージ`** — UVが異なれば結合されず、UVシームが保存されます。→ [ドキュメント](/guides/edit#거리로-병합)
- **`ピンチ（4）`·`インフレート（5）`ブラシ** 追加。→ [ドキュメント](/guides/sculpt#브러시)
- **ブラシマスクとボックスマスク** — アイランドクリックに加えて、半径でペイントと画面矩形選択。→ [ドキュメント](/guides/sculpt#마스크-모드)
- **`対称平面を表示`** — ミラー平面と反対側ブラシ位置をシーンビューに描画します。→ [ドキュメント](/guides/sculpt#대칭)
- **`ブラシプリセット`3スロット** — よく使うブラシ設定を保存して読み込みます。→ [ドキュメント](/guides/sculpt#브러시-프리셋)
- **ミラーキー生成** — 名前の左右表記を反転して反対側の表情キーを作成します。→ [ドキュメント](/guides/blendshape#미러-키)
- **別のメッシュからキーをインポート** — 顔メッシュの表情キーを近接マッピングで移動させます。→ [ドキュメント](/guides/blendshape#키-전송)
- **ソロプレビュー·キーロック·プリフィックスグループ·デルタヒートマップ·`拡張範囲`** — リストが長くても扱えるように。→ [ドキュメント](/guides/blendshape#솔로-프리뷰)
- **複数キー一括処理** — `Ctrl` · `Shift`クリックで選んで値·ロック·順序·削除を一度に。→ [ドキュメント](/guides/blendshape#다중-선택)
- **別のメッシュからウェイトをインポート** — アバタボディのウェイトを衣装に移す衣装フィッティングの基本操作。→ [ドキュメント](/guides/weight-paint#다른-메쉬에서-웨이트-가져오기)
- **`対称ペイント`** — 反対側頂点に左右対応ボーンを一緒にペイントします。→ [ドキュメント](/guides/weight-paint#대칭-페인트)
- **`ボーンウェイト結合`** — ボーンを削除する前にウェイトを親または別のボーンに移動します。→ [ドキュメント](/guides/weight-paint#본-웨이트-합치기)
- **`ブラー（4）`·`平均（5）`ウェイトブラシ** とボーンロック。→ [ドキュメント](/guides/weight-paint#브러시)
- **`最大影響ボーン数`** — 1つの頂点が持つボーン数を1～4で制限します。→ [ドキュメント](/guides/weight-paint#자동-정규화와-최대-영향-본-수)
- **未保存バッジ** — `保存済み`·`変更あり`·`トランザクション中`。→ [ドキュメント](/guides/window#상태-배지)
- **`ロード候補`リスト** — `Load`前に頂点数と重複·Read/Write警告を確認します。→ [ドキュメント](/guides/window#불러올-후보)
- **`Keys`ショートカットシート** — 現在のタブのショートカットをシーンビューから直接見ます。→ [ドキュメント](/guides/window#단축키-시트)
- **コンパクトモード** — ウィンドウを狭くドッキングするとヘッダーとガイドが折りたたまれて本体が広くなります。→ [ドキュメント](/guides/window#컴팩트-모드)
- **Bake結果テーブル** — 複数メッシュをベイクしたときの成功·失敗を1つのテーブルでまとめます。→ [ドキュメント](/guides/window)

## 変更

- 軸対称ショートカットが`Shift+Alt+X` / `Y` / `Z`に統一されました。単独の`X` `Y` `Z`と`Alt+Z`はUnityツールハンドルとX-Rayのために予約しています。→ [ドキュメント](/reference/shortcuts#스컬프트)
- `R`は選択があり、カーソルがシーンビューの上にあるときだけ回転モーダルであり、その他はレガシスケールギズモです。→ [ドキュメント](/reference/shortcuts#편집)
- シーンビューステータス表示が上部ターゲット行と重ならないよう整理されました。→ [ドキュメント](/guides/window)
- 構造元に戻すスナップショットにメモリ上限が加わり、超過すると古い記録から削除されて通知されます。→ [ドキュメント](/internals/session-and-undo#되돌리기)

## 改善

- 複数メッシュの削除·分離·一括キー作業が1つの元に戻すステップにまとめられ、1つでも失敗すればすべて巻き戻ります。→ [ドキュメント](/guides/multi-mesh#원자적-롤백)
- ウェイト転送でソースとターゲットの変換が異なれば警告し、バインドポーズローカル空間で合わせるオプションを提供します。→ [ドキュメント](/guides/weight-paint#전송-공간)
- フレームが複数あるキーを編集すれば警告し、保存時に中間フレームを変化量に比例して更新します。→ [ドキュメント](/guides/blendshape#다중-프레임)
- 同じソースメッシュを使うレンダラーが複数あっても出力ファイルが互いに上書きしません。→ [ドキュメント](/reference/output-files#provenance와-owner)
- 名前に使えない文字を含むブレンドシェイプキーは保存時に自動的にクリーンアップされます。→ [ドキュメント](/guides/blendshape#새-쉐이프-조형)
- シーンビューピッキングとオーバーレイが画面外要素をスキップして、高密度メッシュが軽くなりました。→ [ドキュメント](/limitations)
- `Bake`に進捗表示が付きました。→ [ドキュメント](/internals/bake)
- ブラシ筆圧が1ストローク中維持され、値が跳びません。→ [ドキュメント](/guides/sculpt#브러시-설정)

## 修正

- **ウェイトを1回ペイントするとメッシュ全体のボーン影響が4個に切り詰められていた問題**を修正しました。ペイントしていない頂点の5個以上の影響はそのまま保存されます。→ [ドキュメント](/internals/bake#가변-본-웨이트)
- **スクリプトを保存してエディタが再コンパイルされると編集が警告なしに消滅していた問題**を修正しました。リロード直前に自動保存し、完了後に復元します。→ [ドキュメント](/internals/session-and-undo#자동-저장과-복원)
- **削除·分離を元に戻すと5個以上のボーン影響とUV4～UV7が消滅していた問題**を修正しました。→ [ドキュメント](/internals/session-and-undo#되돌리기)
- **Read/Writeがオフのメッシュを`Load`するとレンダラーが壊れた状態で残っていた問題**を修正しました。ガイドと一緒に`Read/Write有効化`ボタンを表示し、元に戻します。→ [ドキュメント](/getting-started/installation)
- **既存キーを編集してもそのキーの法線デルタが更新されていなかった問題**を修正しました。→ [ドキュメント](/internals/bake)
- 元に戻す動作がブレンドシェイプ編集開始時点より前に戻ると、編集を静かに続行せず、キャンセルします。→ [ドキュメント](/internals/session-and-undo#트랜잭션)
- カラーチャネルが8ビットのメッシュにfloatカラーを書き込んでいたランタイムエラーを修正しました。→ [ドキュメント](/internals/bake)
- 分離に失敗すると作成中の`_Part.asset`を削除して、元の状態に戻します。→ [ドキュメント](/guides/edit#분리)
- 削除·分離後に隠す状態が残っていた問題を修正しました。→ [ドキュメント](/guides/edit#숨기기)
- 法線を反転するときブレンドシェイプの法線·接線デルタが一緒に反転されていなかった問題を修正しました。→ [ドキュメント](/guides/edit#노멀)
