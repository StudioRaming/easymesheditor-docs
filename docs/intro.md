# Easy Mesh Editor

**Unity 씬뷰 안에서 메쉬를 직접 다루는 편집 도구**입니다.

메쉬를 고치려고 프로젝트 밖으로 나갈 필요가 없습니다. 아바타를 입혀 둔 그대로, 지금 보고 있는 포즈 위에서 표면을 밀고, 정점을 옮기고, 표정 키를 만들고, 스킨 웨이트를 칠합니다. FBX를 다시 내보내고 다시 임포트하고 머티리얼·물리·프리팹 참조를 다시 잡는 왕복이 사라집니다.

VRChat·WARUDO 아바타와 의상을 만드는 사람을 위한 도구입니다. 의상이 몸을 뚫는 자리를 눌러 넣고, 새 파츠에 웨이트를 옮기고, 표정 키를 좌우 대칭으로 만드는 작업을 이 창 하나에서 합니다.

Unity Editor 전용입니다. 플레이어 빌드에 들어가는 런타임 기능이 아닙니다.

## 4개의 작업 탭

| 탭 | 하는 일 | 대상 |
|---|---|---|
| `모양 다듬기` | 브러시 5종으로 표면을 당기고, 다듬고, 부풀립니다 | SkinnedMeshRenderer · MeshRenderer |
| `선택·이동` | 정점·엣지·페이스를 고르고 옮기고, 지우고, 나누고, 합칩니다 | SkinnedMeshRenderer · MeshRenderer |
| `표정 키` | 표정 키를 만들고 고치고, 미러 키를 만들고, 다른 메쉬에서 가져옵니다 | SkinnedMeshRenderer 전용 |
| `뼈 연결` | 본 웨이트를 칠하고, 합치고, 다른 메쉬에서 가져옵니다 | SkinnedMeshRenderer 전용 |

네 탭은 하나의 편집 세션을 공유합니다. 탭을 옮겨도 선택·마스크·되돌리기 기록이 그대로 남습니다.

## 원본은 건드리지 않습니다

이 도구의 안전 모델은 한 문장입니다. **`메쉬 저장`(Bake)을 누르기 전까지 원본 메쉬 에셋은 바뀌지 않습니다.**

1. `불러오기`를 누르면 원본을 복제한 임시 메쉬(Work Mesh)가 만들어지고 렌더러가 그것을 씁니다.
2. 모든 편집은 Work Mesh 위에서 일어납니다.
3. `메쉬 저장`을 누르면 원본 옆에 `<원본명>_Edit.asset`이 생기고 렌더러가 그 에셋을 쓰게 됩니다.
4. `편집 버리기`를 누르면 편집 내용을 버리고 렌더러는 원본으로 돌아갑니다.

에디터가 스크립트를 다시 컴파일하거나 플레이모드에 들어가도 작업이 그냥 사라지지 않습니다. 편집 중인 Work Mesh는 `Library/EmeAutoSave/`에 보존되고, 편집 모드로 돌아오면 복원됩니다. → [세션과 되돌리기](/internals/session-and-undo)

:::note[`메쉬 저장`은 세션을 끝냅니다]
작업 도중에 계속 누르는 버튼이 아닙니다. 다 끝낸 뒤 한 번 누르는 버튼입니다. 편집 중에 표정 키만 하나 남기고 싶으면 `새 키로 저장`을 쓰세요. 이쪽은 에셋을 아직 바꾸지 않습니다. → [빠른 캡처와 메쉬 저장](/guides/blendshape#빠른-캡처와-bake)
:::
