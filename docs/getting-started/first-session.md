# 첫 편집 세션

**이 문서를 읽으면** 대상을 고르고 `메쉬 저장`까지 한 바퀴를 돌 수 있고, `Tab`으로 편집 입력을 잠시 끄는 법과 `편집 버리기`로 전부 되돌리는 법을 알 수 있습니다.

## 1. 선택하고 `불러오기`

1. Hierarchy에서 편집할 오브젝트를 하나 이상 고릅니다. 자식에 붙은 `SkinnedMeshRenderer`와 `MeshFilter + MeshRenderer`도 함께 찾습니다.
2. `StudioRaming > Easy Mesh Editor`를 엽니다.
3. 창의 시작 카드가 `대상 고르기 → 불러오기 → 모드 선택 → 메쉬 저장` 순서를 보여 줍니다. 대상 행에 잡힌 렌더러 수가 나오면 `불러오기`를 누릅니다.

`불러오기` 전에 어떤 렌더러가 잡혔는지 보고 싶으면 `불러올 후보` 목록을 펼치세요. 이름, 정점 수, 키 수, 그리고 경고가 행마다 표시됩니다. 행 하나를 클릭하면 그 렌더러만 불러오고, 선택을 비우면 후보 전체를 불러옵니다. → [창 사용법](/guides/window#불러올-후보)

`불러오기`가 끝나면 편집 상태가 시작됩니다. 이 순간부터 렌더러는 원본이 아니라 Work Mesh를 쓰고 있습니다.

## 2. 편집

탭을 골라 작업합니다.

| 하고 싶은 것 | 탭 |
|---|---|
| 표면을 당기거나 부풀린다 | `모양 다듬기` → [문서](/guides/sculpt) |
| 정점을 옮기거나 페이스를 지운다 | `선택·이동` → [문서](/guides/edit) |
| 표정 키를 만든다 | `표정 키` → [문서](/guides/blendshape) |
| 본 웨이트를 칠한다 | `뼈 연결` → [문서](/guides/weight-paint) |

탭은 자유롭게 오갈 수 있습니다. `Ctrl+Tab`으로 다음 탭, `Ctrl+Shift+Tab`으로 이전 탭으로 옮깁니다. 선택, 마스크, 되돌리기 기록은 탭을 옮겨도 유지됩니다.

되돌리기는 `Ctrl+Z`입니다. 브러시 한 획, 기즈모 한 번의 변형, 웨이트 작업 하나, 구조 변경 하나가 각각 한 단계입니다. → [세션과 되돌리기](/internals/session-and-undo)

## 3. `Tab`: 편집을 잠시 끄기

씬뷰에서 카메라만 돌리고 싶은데 클릭이 자꾸 선택으로 먹힐 때가 있습니다. `Tab`을 누르면 편집 입력만 꺼집니다. 세션은 그대로 살아 있습니다.

다시 켜려면 `Tab`을 한 번 더 누르거나 씬뷰 안내의 편집 시작 버튼을 누릅니다.

:::note[`Tab`은 세션을 버리지 않습니다]
편집을 끝내는 것은 `메쉬 저장`이나 `편집 버리기`뿐입니다. `Tab`은 입력 스위치입니다.
:::

## 4. 미저장 배지 확인

대상 행의 배지가 지금 상태를 말해 줍니다.

| 배지 | 뜻 |
|---|---|
| `저장됨` | `불러오기` 이후 바뀐 것이 없습니다 |
| `변경 있음` | 저장되지 않은 편집이 있습니다 |
| `트랜잭션 중` | 표정 키 편집이 아직 확정되지 않았습니다 |

`트랜잭션 중`이면 `메쉬 저장`이 막힙니다. 창 상단에 고정된 바에서 `저장`(키 편집 확정) 또는 `키 편집 취소`를 먼저 누르세요. → [표정 키](/guides/blendshape#기존-키-편집)

## 5. `메쉬 저장`으로 마무리

모든 작업을 끝낸 뒤 `메쉬 저장`을 누릅니다.

- 원본 옆에 `<원본명>_Edit.asset`이 만들어지고 렌더러가 그 에셋을 쓰게 됩니다.
- 사용되지 않는 정점이 남아 있으면 이때 한 번 정리됩니다.
- 세션이 끝납니다. 이어서 작업하려면 다시 `불러오기` 합니다.

여러 메쉬를 함께 편집했다면 대상별 결과표가 뜹니다. 실패한 대상의 세션은 유지되므로 원인을 고치고 다시 시도할 수 있습니다. → [생성되는 파일](/reference/output-files)

:::caution[`메쉬 저장`은 마지막에 한 번]
중간 저장이 필요하면 `새 키로 저장`을 쓰세요. 이쪽은 세션을 끝내지 않고 에셋도 아직 바꾸지 않습니다. → [표정 키의 빠른 캡처](/guides/blendshape#빠른-캡처와-bake)
:::

## 6. `편집 버리기`: 전부 버리기

`편집 버리기`는 현재 편집 전체를 버리고 렌더러를 원본 메쉬로 되돌립니다. 버리기 전에 한 번 확인합니다. 확인창에서 `Enter`와 `Esc`는 작업을 그대로 둡니다. 동작 이름이 적힌 버튼을 눌러야만 버려집니다. 이미 `메쉬 저장`으로 만든 에셋은 지우지 않습니다.

창을 닫거나 플레이모드에 들어가도 저장하지 않은 편집은 묻지 않고 보존됩니다. 플레이모드 중에는 원본 메쉬가 보이고, 편집 모드로 돌아오면 편집 내용이 그대로 복원됩니다. → [세션과 되돌리기](/internals/session-and-undo#자동-보존과-복원)
