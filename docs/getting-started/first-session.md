# 첫 편집 세션

**이 문서를 읽으면** 선택부터 `Bake`까지 한 바퀴를 돌 수 있고, `Tab`으로 편집을 잠시 끄는 법과 `Revert`로 전부 되돌리는 법을 알 수 있습니다.

## 1. 선택하고 `Load`

1. Hierarchy에서 편집할 오브젝트를 하나 이상 고릅니다. 자식에 붙은 `SkinnedMeshRenderer`와 `MeshFilter + MeshRenderer`도 함께 찾습니다.
2. `StudioRaming > Easy Mesh Editor`를 엽니다.
3. 대상 행에 `선택: {0}개 렌더러 (Load를 누르세요)` 가 뜨는지 확인하고 `Load`를 누릅니다.

`Load` 전에 어떤 렌더러가 잡혔는지 보고 싶으면 `불러올 후보` 목록을 펼치세요. 정점 수, 블렌드쉐이프 수, `[원본 중복]`·`[Read/Write 꺼짐]` 경고가 행마다 표시됩니다. 행 하나를 클릭하면 그 렌더러만 불러옵니다. → [창 사용법](/guides/window#불러올-후보)

`Load`가 끝나면 헤더 아래 상태가 `편집 중: {0}` 으로 바뀝니다. 이 순간부터 렌더러는 원본이 아니라 Work Mesh를 쓰고 있습니다.

## 2. 편집

탭을 골라 작업합니다.

| 하고 싶은 것 | 탭 |
|---|---|
| 표면을 밀거나 부풀린다 | `스컬프트` → [문서](/guides/sculpt) |
| 정점을 옮기거나 페이스를 지운다 | `편집` → [문서](/guides/edit) |
| 표정 키를 만든다 | `블렌드쉐이프` → [문서](/guides/blendshape) |
| 본 웨이트를 칠한다 | `웨이트` → [문서](/guides/weight-paint) |

탭은 자유롭게 오갈 수 있습니다. 선택, 마스크, 되돌리기 기록은 탭을 옮겨도 유지됩니다.

되돌리기는 Unity의 `Ctrl+Z` 그대로입니다. 브러시 한 스트로크, 기즈모 한 번의 변형, 웨이트 작업 하나, 구조 변경 하나가 각각 한 단계입니다. → [세션과 되돌리기](/internals/session-and-undo)

## 3. `Tab` — 편집을 잠시 끄기

씬뷰에서 카메라만 돌리고 싶은데 클릭이 자꾸 선택으로 먹힐 때가 있습니다. `Tab`을 누르면 편집 입력만 꺼집니다. 세션은 그대로 살아 있습니다.

편집이 꺼진 동안 창은 이렇게 알려 줍니다.

> `편집이 잠시 꺼져 있습니다. 작업 내용은 유지 중 — '편집' 토글이나 씬뷰의 '편집 켜기'로 이어서 작업하세요.`

다시 켜려면 `Tab`을 한 번 더 누르거나, 씬뷰의 `편집 켜기` 버튼 또는 창의 `편집 (Tab)` 토글을 누릅니다.

:::note[`Tab`은 세션을 버리지 않습니다]
편집을 끝내는 건 `Bake`나 `Revert`뿐입니다. `Tab`은 입력 스위치입니다.
:::

## 4. 미저장 배지 확인

헤더의 배지가 지금 상태를 말해 줍니다.

| 배지 | 뜻 |
|---|---|
| `저장됨` | `Load` 이후 바뀐 것이 없습니다 |
| `변경 있음` | 저장되지 않은 편집이 있습니다 |
| `트랜잭션 중` | 블렌드쉐이프 편집이 아직 확정되지 않았습니다 |

`트랜잭션 중`이면 `Bake`가 막힙니다. 화면에 고정된 바에서 `Enter`(저장) 또는 `Esc`(취소)로 먼저 끝내세요. → [블렌드쉐이프](/guides/blendshape#기존-키-편집)

## 5. `Bake`로 저장

`최종 에셋 저장` 섹션의 `Bake`를 누릅니다.

- 원본 옆에 `<원본명>_Edit.asset`이 만들어지고 렌더러가 그 에셋을 쓰게 됩니다.
- 어떤 삼각형도 참조하지 않는 정점이 남아 있으면 이때 한 번 정리됩니다.
- 세션이 끝납니다. 이어서 작업하려면 다시 `Load`해야 합니다.

여러 메쉬를 함께 편집했다면 `Bake 결과 ({0}/{1} 성공)` 표가 뜹니다. 실패한 세션은 유지되므로 원인을 고치고 다시 시도할 수 있습니다. → [생성되는 파일](/reference/output-files)

:::caution[`Bake`는 마지막에 한 번]
창은 `작업을 모두 마친 뒤 한 번만 실행하세요.` 라고 안내합니다. 중간 저장이 필요하면 `새 쉐이프로 저장`(빠른 블렌드쉐이프 캡처)을 쓰세요 — 이쪽은 세션을 끝내지 않고 에셋도 아직 바꾸지 않습니다.
:::

## 6. `Revert` — 전부 버리기

`Revert`는 `모든 편집을 버리고 원본으로 되돌립니다. 계속할까요?` 를 물은 뒤 렌더러를 원본 메쉬로 되돌립니다. `Bake`로 이미 만든 에셋은 지우지 않습니다.

창을 그냥 닫거나 플레이모드에 들어가려 할 때도, 저장하지 않은 편집이 있으면 `Bake` / `버리기`(플레이모드는 `취소`까지) 를 묻습니다.
