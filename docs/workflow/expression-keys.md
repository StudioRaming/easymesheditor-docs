# 표정 키 만들기

**이 문서를 읽으면** 새 표정 키를 조형해 좌우 대칭으로 늘리고, 그룹과 잠금으로 목록을 관리하고, 실제로 잘 만들어졌는지 확인하는 순서를 따라갈 수 있습니다.

전제: `SkinnedMeshRenderer` 를 `Load` 했고 `블렌드쉐이프` 탭에 있습니다.

## 1. 기준 상태 만들기 {#1-기준-상태-만들기}

새 키는 **지금 화면에 보이는 절대 형태**를 기준으로 시작합니다. 다른 키가 켜져 있으면 그 모양 위에서 조형하게 됩니다.

`전체 값 0으로` 를 눌러 모든 키를 0으로 내려 놓고 시작하세요. 특정 표정 위에 얹는 키를 만들 때만 일부러 켜 둡니다.

## 2. 한쪽만 조형 {#2-한쪽만-조형}

`+ 새 쉐이프 (N)` 또는 씬뷰에서 `N`.

씬뷰에 `새 쉐이프 조형 중: {0}` 배너가 뜨면 조형을 시작합니다.

- 드래그 = 그랩, `Shift` = 스무딩
- `F` = 반경, `Shift+F` = 강도

`이름` 필드에 좌우가 드러나는 이름을 넣습니다. 다음 단계의 미러가 이 이름을 뒤집어 씁니다.

| 이름 예 | 미러 결과 |
|---|---|
| `eye_close_L` | `eye_close_R` |
| `L_brow_up` | `R_brow_up` |
| `smileLeft` | `smileRight` |
| `cheek_puff` | `cheek_puff_Mirror` |

`Enter` 로 `새 키 변경 확정 (Enter)`, 마음에 안 들면 `Esc`.

:::note[확정해도 아직 에셋은 안 바뀝니다]
여기서의 확정은 **세션에 확정**입니다. 메쉬 에셋에 들어가는 것은 `Bake` 때입니다. → [블렌드쉐이프](/guides/blendshape#기존-키-편집)
:::

조형이 마음에 안 들면 다시 손보면 됩니다. 목록에서 그 키의 편집 버튼을 누르면 100% 형태를 불러와 이어서 조형합니다. 이때 `스컬프트`·`편집` 탭으로 옮겨 가서 작업해도 되고(`멀티탭 편집`), 돌아와 `현재 키 변경 확정 (Enter)` 로 끝냅니다. 단, **정점 수가 바뀌는 작업(삭제·분리)은 저장할 수 없습니다.**

## 3. 미러 키로 반대쪽 만들기 {#3-미러-키로-반대쪽-만들기}

방금 만든 키 행의 `M` 을 누릅니다. `미러 축` 은 보통 X입니다.

> `미러 키 '{0}' 을(를) {1}축 기준으로 만들었습니다.`

좌우 토폴로지가 완전히 같지 않아도 됩니다. 공간 대응으로 짝을 찾고, 짝이 없는 정점은 대칭 평면 위에 있을 때만 반사됩니다.

만들어지지 않는다면 대칭 짝을 못 찾은 것입니다 — `'{0}' 의 미러 키를 만들지 못했습니다.` 메쉬가 애초에 좌우 비대칭이면 반대쪽은 손으로 조형해야 합니다.

## 4. 그룹과 잠금으로 정리 {#4-그룹과-잠금으로-정리}

키가 스무 개를 넘어가면 목록이 길어집니다.

- `그룹` 을 켜면 이름 접두사로 접힙니다. `eye_`, `mouth_`, `brow_` 처럼 접두사를 정해 두면 관리가 쉬워집니다.
- 완성된 키는 행의 `L` 로 잠급니다. 잠긴 키는 일괄 값 변경, 삭제, 다른 메쉬에서의 전송에서 모두 제외됩니다.

여러 키를 `Ctrl`·`Shift` 클릭으로 골라 `잠금` 을 한 번에 걸 수도 있습니다 — `키 {0}개를 잠갔습니다.`

순서를 정리할 때는 고른 뒤 `^` / `v` 를 씁니다. 여러 키의 이동도 한 번의 되돌리기 단계입니다.

## 5. 확인 {#5-확인}

만든 키가 의도한 곳만 움직이는지 봅니다.

1. 행의 `S` 로 [솔로 프리뷰](/guides/blendshape#솔로-프리뷰)를 켭니다. 그 키만 100으로 보입니다.
2. `히트맵` 을 켜고 그 키를 클릭합니다. 실제로 델타가 있는 정점이 색으로 나옵니다 — `히트맵: '{0}' · 최대 이동량 {1}`
3. 엉뚱한 곳이 물들었다면 조형할 때 브러시 반경이 넓었던 것입니다. 편집으로 돌아가 다듬으세요.
4. `Esc` 로 솔로를 풉니다.

`확장 범위` 를 켜면 `-100~200` 까지 밀어 볼 수 있습니다. 과장했을 때 형태가 무너지지 않는지 보는 용도이고, 그 값 그대로 저장하지는 마세요.

## 6. 저장 {#6-저장}

두 갈래가 있습니다.

- **`Bake`** — 키 구조를 포함한 메쉬 전체를 `<원본명>_Edit.asset` 으로 굽고 세션을 끝냅니다.
- **`새 쉐이프로 저장`** — 기본형에 이번에 더한 변형만 새 키로 남기고 세션을 이어 갑니다.

키를 만드는 작업이라면 대개 `Bake` 입니다. `새 쉐이프로 저장` 은 "스컬프트로 형태를 바꿔 놨는데, 기본형은 그대로 두고 이 변형만 키로 남기고 싶다" 는 상황을 위한 것입니다. → [빠른 캡처와 Bake](/guides/blendshape#빠른-캡처와-bake)

## 이미 있는 표정을 되살리기

기본형을 바꾼 뒤 원래 얼굴이 필요할 때가 있습니다. 그 키 행의 `리버트` 가 반전 키(`_Revert`)를 만들어 줍니다.

여러 키를 켠 지금 모습을 하나로 굳히고 싶으면 `적용값 합치기` 를 씁니다. 지금 0이 아닌 키들의 결과가 새 100% 키가 되고, 재료로 쓴 키들의 값은 0으로 돌아갑니다.
