# 생성되는 파일

**이 문서를 읽으면** 이 도구가 프로젝트에 무엇을 만드는지, 왜 어떤 경우엔 기존 파일을 갱신하고 어떤 경우엔 새 파일을 만드는지, 그리고 남의 에셋을 절대 덮어쓰지 않는 이유를 알 수 있습니다.

## 세 종류

| 경로 | 언제 | 버전 관리 |
|---|---|---|
| `<원본명>_Edit.asset` | `Bake` | 커밋 대상 |
| `<원본명>_Part.asset` | `선택 분리 (P)` · `아일랜드 분리 (Shift+P)` | 커밋 대상 |
| `Library/EmeAutoSave/<id>.asset` | 도메인 리로드 직전 자동 저장 | 커밋 대상 아님 |

앞의 둘은 **원본 메쉬 에셋 옆**에 만들어집니다. 세 번째는 `Library/` 아래이므로 Unity가 캐시로 취급하고 버전 관리에서도 제외됩니다.

## `_Edit.asset`

`Bake`가 만드는 최종 메쉬 에셋입니다. 만들어지는 즉시 렌더러가 이 에셋을 쓰게 됩니다.

담기는 것: 정점, 노멀, 탄젠트, UV0~UV7, 컬러, 서브메쉬·재질 대응, bindpose, 본 웨이트(2020.1+의 가변 본 웨이트 포함), 블렌드쉐이프 전 프레임.

`Bake` 과정에서 어떤 삼각형도 참조하지 않는 정점은 한 번 정리됩니다 — `사용되지 않는 정점 {0}개를 정리했습니다`. → [Bake 내부](/internals/bake)

에셋 안의 메쉬 오브젝트 이름은 파일 이름과 같게 맞춰집니다.

## `_Part.asset`

`편집` 탭에서 분리할 때 만들어집니다. 새 GameObject가 씬에 생기고, 그 렌더러가 이 에셋을 씁니다.

분리가 도중에 실패하면 만들다 만 `_Part.asset` 은 삭제되고 원본은 그대로 남습니다 — `분리에 실패해 되돌렸습니다: {0}`

## provenance와 owner {#provenance와-owner}

출력 에셋에는 **어디서 나왔는지**를 적어 둔 표식이 함께 저장됩니다. 이 표식이 다음 두 가지를 결정합니다.

1. 다시 `Bake` 했을 때 **같은 파일을 갱신할지, 새 파일을 만들지**
2. 이름이 겹치는 **남의 에셋을 절대 건드리지 않을 것**

표식은 `<원본 메쉬 GUID>:<localId>@<렌더러 owner 토큰>` 형태입니다.

| 상황 | 결과 |
|---|---|
| 같은 원본, 같은 렌더러에서 다시 `Bake` | 기존 `_Edit.asset` 을 **GUID를 유지한 채로 갱신** |
| 같은 원본 메쉬를 쓰는 다른 렌더러 | 별도의 출력 파일을 만듭니다 |
| 같은 이름의 남의 에셋이 이미 있음 | 덮어쓰지 않고 고유한 경로를 새로 만듭니다 |

GUID가 유지된다는 것이 중요합니다. 프리팹·애니메이션·다른 씬이 그 메쉬를 참조하고 있어도 참조가 끊어지지 않습니다.

이미 `Bake`한 에셋을 쓰는 렌더러를 다시 `Load`해서 이어 작업하면, 그 출력을 갱신하고 같은 에셋을 쓰는 다른 로드된 렌더러도 새 데이터로 동기화합니다.

:::caution[씬을 저장하지 않으면 렌더러를 구분할 수 없습니다]
owner 토큰은 렌더러의 전역 ID에서 나옵니다. 씬이 저장된 적이 없으면 그 ID가 없으므로 창이 알려 줍니다.

> `씬이 저장되지 않아 렌더러를 식별할 수 없습니다. 같은 원본 메쉬를 쓰는 렌더러가 여러 개라면 씬을 저장하기 전까지 같은 출력 파일을 공유합니다.`

같은 메쉬를 공유하는 렌더러가 여럿이라면 작업 전에 씬을 한 번 저장하세요.
:::

## `Library/EmeAutoSave/` {#자동-저장-폴더}

에디터가 스크립트를 다시 컴파일하기 직전에 Work Mesh가 여기로 직렬화되고, 리로드가 끝나면 자동으로 복원됩니다.

- 복원되면 `Easy Mesh Editor: 자동 저장된 편집 세션을 복원했습니다 ({0})`
- 실패하면 `Easy Mesh Editor: 자동 저장본 {0}개를 복원하지 못했습니다. 파일은 그대로 두었습니다: {1}` — 파일은 지우지 않으므로 원인을 확인할 수 있습니다.

이것은 **작업 결과물이 아니라 안전망**입니다. 최종 저장은 언제나 `Bake` 입니다. → [세션과 되돌리기](/internals/session-and-undo#자동-저장과-복원)

## 저장 전에 막히는 것

잘못된 데이터는 파일로 나가기 전에 걸러집니다.

- NaN / Infinity 좌표
- 토폴로지 불일치
- 웨이트 배열 길이 불일치

실패한 세션은 **닫히지 않고 유지**되므로, 원인을 고치고 다시 `Bake` 할 수 있습니다.

## 지워도 되는 것

| 파일 | 지워도 되나 |
|---|---|
| `_Edit.asset` | 렌더러가 쓰고 있다면 안 됩니다. 원본으로 되돌린 뒤 지우세요 |
| `_Part.asset` | 그 파트 오브젝트를 지운 뒤라면 됩니다 |
| `Library/EmeAutoSave/` | 언제든 됩니다. 복원할 세션이 없어질 뿐입니다 |
