# 단축키

**이 문서를 읽으면** 탭별로 어떤 키가 무슨 일을 하는지 한 표에서 찾을 수 있습니다. 창 안에서 같은 내용을 보려면 씬뷰 힌트바의 `Keys` 버튼을 누르세요. → [단축키 시트](/guides/window#단축키-시트)

:::note[씬뷰에서만 동작합니다]
여기 적힌 키는 씬뷰에 마우스가 있을 때 처리됩니다. 텍스트 입력 중에는 가로채지 않으며, Unity의 전역 Shortcut 프로필도 바꾸지 않습니다.
:::

## 공통 {#공통}

모든 탭에서 동작합니다.

| 키 | 하는 일 |
|---|---|
| `Tab` | `편집 켜기/끄기` |
| `Ctrl+Tab` | `도구 탭 순환` (다음 탭) |
| `Ctrl+Shift+Tab` | 이전 탭 |
| `Ctrl+Z` / `Ctrl+Y` | `실행 취소 / 다시 실행` |
| `Enter` / `Esc` | `트랜잭션 확정 / 취소` |
| `[` / `]` | `브러시 크기` |
| `<` `>` `,` `.` | `브러시 강도` |
| `Alt+Z` | X-Ray 켜기/끄기 |

`<` `>` 는 `,` `.` 와 같은 키입니다. `Shift`를 눌러도 같게 동작합니다.

## 스컬프트 {#스컬프트}

| 키 | 하는 일 |
|---|---|
| `1` / `2` / `3` | `브러시 엘라스틱 / 스무스 / 평탄화` |
| `4` / `5` | `브러시 핀치 / 인플레이트` |
| `[` / `]` | `브러시 반경 줄이기 / 키우기` |
| `,` / `.` | `브러시 강도 낮추기 / 높이기` |
| `F` / `Shift+F` | `마우스로 반경 / 강도 조절 (클릭 확정, Esc 취소)` |
| `Shift` (누르는 동안) | `누르는 동안 스무스 브러시` |
| `Ctrl` (누르는 동안) | `누르는 동안 브러시 방향 반전` |
| `Shift+Alt+X` / `Y` / `Z` | 축 대칭 토글 |
| `M` | `마스크 모드 켜기 / 끄기` |
| `Ctrl+I` | `마스크 반전` |
| `Alt+M` | `마스크 전체 해제` |
| `Alt+Z` | `X-Ray 켜기 / 끄기` |

:::caution[`Keys` 시트의 대칭 표기가 실제와 다릅니다]
0.1.1의 `Keys` 시트는 대칭을 `X / Y / Z` · `Alt+X / Y / Z` 로 적어 두었지만, 실제로 동작하는 것은 `편집` 탭과 같은 `Shift+Alt+X` / `Y` / `Z` 입니다. 단독 `X` `Y` `Z` 와 `Alt+Z` 는 각각 Unity의 툴 핸들 단축키와 X-Ray로 남겨 두었기 때문에 가로채지 않습니다. 창의 `대칭` 체크박스로도 켤 수 있습니다.
:::

## 편집 {#편집}

| 키 | 하는 일 |
|---|---|
| `1` / `2` / `3` | `정점 / 엣지 / 페이스 모드` |
| `Q` / `W` / `E` / `R` | `보기 / 이동 / 회전 / 스케일 기즈모` |
| `G` / `R` / `S` | `마우스 모달 변형 (선택 필요)` |
| `X` / `Y` / `Z` (모달 중) | `모달 중 축 구속 (두 번=월드, Shift+축=평면, 숫자=수치)` |
| `Alt+클릭` (드래그 없이) | `엣지 루프` |
| `Ctrl+Alt+클릭` | 엣지 링 (`Shift` 함께 = 추가) |
| `Ctrl` + `+` / `-` | `선택 확장 / 축소` |
| `H` / `Alt+H` / `Shift+H` | `숨기기 / 모두 표시 / 선택 외 숨기기` |
| `A` / `Alt+A` / `Ctrl+I` | `전체 선택 / 해제 / 반전` |
| `B` / `L` / `O` | `박스 선택 / 링크드 선택 / 프로포셔널` |
| `Shift+L` | 링크드 선택 해제 |
| `X` / `Delete` / `Backspace` | 선택 삭제 |
| `P` / `Shift+P` | `선택 분리 / 아일랜드 분리` |
| `Esc` | 박스 선택 준비 해제, 또는 선택 해제 |
| `Alt+Z` | X-Ray |
| `Shift+Alt+X` / `Y` / `Z` | 축 대칭 토글 |
| `[` / `]` | 프로포셔널이 켜져 있으면 반경, 정점 모드면 정점 표시 크기 |

:::caution[`R` 은 상황에 따라 둘 중 하나입니다]
`R` 은 **선택이 있고 커서가 씬뷰 위일 때만** 회전 모달입니다. 그 밖에는 Unity식 `R` = 스케일 기즈모입니다.
:::

:::caution[`Alt+드래그` 는 씬 회전 그대로입니다]
엣지 루프 선택은 `Alt`를 누른 채 **움직이지 않고** 클릭했을 때만 일어납니다. 조금이라도 끌면 평소처럼 카메라가 돕니다.
:::

## 블렌드쉐이프 {#블렌드쉐이프}

이 탭은 `Keys` 시트에 자체 목록을 등록하지 않아 `이 탭에 등록된 단축키가 없습니다.` 가 표시됩니다. 실제로 동작하는 키는 아래와 같습니다.

| 키 | 하는 일 | 조건 |
|---|---|---|
| `N` | 새 쉐이프 조형 시작 | 조형·편집 중이 아닐 때 |
| `Esc` | 솔로 프리뷰 해제 | 트랜잭션이 없고 솔로가 켜져 있을 때 |
| `Enter` | 조형 저장 | 조형 중 |
| `Esc` | 조형 취소 | 조형 중 |
| `F` / `Shift+F` | 반경 / 강도 모달 | 조형 중 |
| `[` / `]` · `,` / `.` | 반경 / 강도 | 조형 중 |
| `Shift` (누르는 동안) | 스무딩 브러시 | 조형 중 |
| `Alt+Z` | X-Ray | |

## 웨이트 {#웨이트}

| 키 | 하는 일 |
|---|---|
| `1` / `2` / `3` | `브러시 추가 / 빼기 / 스무스` |
| `4` / `5` | `브러시 블러 / 평균` |
| `[` / `]` | `브러시 반경 줄이기 / 키우기` |
| `,` / `.` | `브러시 강도 낮추기 / 높이기` |
| `F` / `Shift+F` | `마우스로 반경 / 강도 조절 (클릭 확정, Esc 취소)` |
| `Shift` (누르는 동안) | `누르는 동안 스무스 브러시` |
| `Ctrl` (누르는 동안) | `누르는 동안 추가 / 빼기 반전` |
| `N` | `전체 정규화` |
| `K` | `체크된 본 스무딩 적용` |
| `Ctrl+클릭` | `씬에서 활성 본 지정 / 해제` |
| `Ctrl+Shift+클릭` | `씬에서 스무딩 대상 체크 토글` |
| `Alt+Z` | `X-Ray 켜기 / 끄기` |

:::note[`대칭 페인트 (X)` 는 키가 아닙니다]
라벨에 `(X)` 가 붙어 있지만 현재 버전에서 이 옵션은 창의 체크박스로만 켜고 끕니다. → [대칭 페인트](/guides/weight-paint#대칭-페인트)
:::

`K` 는 체크된 본이 하나도 없으면 아무 일도 하지 않습니다.
