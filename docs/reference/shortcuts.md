# 단축키

**이 문서를 읽으면** 탭별로 어떤 키가 무슨 일을 하는지 한 표에서 찾을 수 있습니다. 창 안에서 같은 내용을 보려면 씬뷰 힌트바의 `Keys` 버튼을 누르세요. → [단축키 시트](/guides/window#단축키-시트)

:::note[씬뷰에서만 동작합니다]
여기 적힌 키는 씬뷰에 마우스가 있을 때 처리됩니다. 텍스트 입력 중에는 가로채지 않으며, Unity의 전역 Shortcut 프로필도 바꾸지 않습니다.
:::

## 공통 {#공통}

모든 탭에서 동작합니다.

| 키 | 하는 일 |
|---|---|
| `Tab` | 편집 입력 켜기 / 끄기. 세션은 유지됩니다 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 다음 / 이전 탭 |
| `Ctrl+Z` / `Ctrl+Y` | 실행 취소 / 다시 실행 |
| `Enter` | 표정 키 편집 저장 (취소는 고정 바의 버튼) |
| `Alt+Z` | X-Ray 켜기 / 끄기 |

## 모양 다듬기 {#모양-다듬기}

| 키 | 하는 일 |
|---|---|
| `1` / `2` / `3` / `4` / `5` | 잡아당기기 / 매끈하게 / 평평하게 / 모으기 / 부풀리기 |
| `[` / `]` | 브러시 반경 줄이기 / 키우기 (×0.9) |
| `,` / `.` (`<` / `>`) | 브러시 강도 낮추기 / 높이기 (±0.05) |
| `F` / `Shift+F` | 마우스로 반경 / 강도 조절 (클릭 확정, `Esc` 취소) |
| `Shift` (누르는 동안) | 임시 매끈하게 |
| `Ctrl` (누르는 동안) | 브러시 방향 반전 |
| 숫자패드 `.` | 선택 영역 보기 (편집 중인 메쉬를 화면에 맞춤) |
| `Alt+Shift+X` / `Y` / `Z` | 축 대칭 켜기 / 끄기 |
| `M` | 마스크 모드 |
| `Ctrl+I` | 마스크 반전 |
| `Alt+M` | 마스크 전체 해제 |

:::caution[`X` `Y` `Z`를 단독으로 누르면 대칭이 켜지지 않습니다]
대칭 단축키는 `Alt+Shift+X` / `Y` / `Z`입니다. 단독 `X` `Y` `Z`는 Unity의 툴 핸들 단축키로 남아 있어서 가로채지 않습니다. 창의 `대칭` 체크박스로도 켤 수 있습니다.
:::

## 선택·이동 {#선택-이동}

| 키 | 하는 일 |
|---|---|
| `1` / `2` / `3` | 정점 / 엣지 / 페이스 모드 |
| `A` / `Alt+A` / `Ctrl+I` | 전체 선택 / 선택 해제 / 반전 |
| `B` | 박스 선택 (`Shift` 추가, `Ctrl` 제거) |
| `L` / `Shift+L` | 연결 요소 선택 / 해제 |
| `Alt+클릭` | 엣지 루프 (드래그하지 않은 클릭에서만) |
| `Ctrl+Alt+클릭` | 엣지 링 (`Shift` 함께 누르면 추가) |
| `Ctrl` + `+` / `-` | 선택 확장 / 축소 |
| `Esc` | 선택 해제 |
| `Q` / `W` / `E` / `R` | 보기 / 이동 / 회전 / 스케일 기즈모 |
| `G` / `R` / `S` | 마우스 모달 이동 / 회전 / 스케일 (선택이 있어야 합니다) |
| 모달 중 `X` `Y` `Z` | 축 구속. 한 번 더 누르면 월드 축 |
| 모달 중 `Shift` + 축 | 평면 구속 |
| 모달 중 숫자 / `Enter` / `Esc` | 수치 입력 / 확정 / 취소 |
| `O` | 프로포셔널 편집 켜기 / 끄기 |
| `[` / `]` | 프로포셔널 반경 (프로포셔널이 꺼져 있으면 정점 표시 크기) |
| `Alt+Shift+X` / `Y` / `Z` | 축 대칭 켜기 / 끄기 |
| `H` / `Shift+H` / `Alt+H` | 선택 숨기기 / 선택 외 숨기기 / 모두 표시 |
| `P` / `Shift+P` | 선택 분리 / 아일랜드 분리 |
| `X` 또는 `Delete` | 선택 삭제 |

:::caution[`R`은 상황에 따라 둘 중 하나입니다]
`R`은 **선택이 있고 커서가 씬뷰 위에 있을 때만** 회전 모달입니다. 그 밖에는 Unity식 `R` 스케일 기즈모입니다.
:::

:::caution[`Alt+드래그`는 씬 회전 그대로입니다]
엣지 루프 선택은 `Alt`를 누른 채 3px 미만으로만 움직인 클릭에서만 일어납니다. 조금이라도 많이 끌면 평소처럼 카메라가 돕니다.
:::

Ctrl이나 Cmd가 함께 눌린 조합(`Ctrl+P`, `Ctrl+R`, `Ctrl+X` 등)은 Unity 단축키로 남으며, 선택·이동 동작을 실행하지 않습니다. 예외는 `Ctrl+A`, `Ctrl+I`, `Ctrl` + `+`/`-`입니다.

## 표정 키 {#표정-키}

| 키 | 하는 일 |
|---|---|
| `N` | 새 키 조형 시작 |
| `Enter` | 키 편집 저장 |
| `Esc` | 스트로크 취소 또는 솔로 해제. 키 편집은 버리지 않습니다 |
| `F` / `Shift+F` / `[` / `]` / `,` / `.` | 조형 중 반경과 강도 조절 |
| `Shift` (누르는 동안) | 임시 매끈하게 |

## 뼈 연결 {#뼈-연결}

| 키 | 하는 일 |
|---|---|
| `1` / `2` / `3` / `4` / `5` | 더하기 / 빼기 / 스무딩 / 블러 / 평균 |
| `N` | 전체 정규화 |
| `K` | 체크한 본 스무딩 (체크한 본가 없으면 아무 일도 하지 않습니다) |
| `Ctrl+클릭` | 씬뷰에서 활성 본 지정 / 해제 |
| `Ctrl+Shift+클릭` | 씬뷰에서 스무딩 대상 체크 켜기 / 끄기 |
| `[` / `]` / `,` / `.` / `F` / `Shift+F` | 반경과 강도 조절 (모양 다듬기와 같습니다) |
| `Shift` (누르는 동안) | 임시 스무딩 |
| `Ctrl` (누르는 동안) | 더하기와 빼기 반전 |

:::note[`대칭 페인트`에는 키가 없습니다]
라벨에 `(X)`가 붙어 있지만, 현재 버전에서 이 옵션은 창의 체크박스로만 켜고 끕니다. → [대칭 페인트](/guides/weight-paint#대칭-페인트)
:::
