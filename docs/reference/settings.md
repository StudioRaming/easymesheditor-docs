# 설정 항목

**이 문서를 읽으면** 창의 어떤 값이 다음에 열 때까지 기억되는지, 어떤 것이 세션과 함께 사라지는지, 처음 설치했을 때 각 값이 어떤 상태인지 알 수 있습니다.

기본값은 1.0 소스의 초기값입니다. 값이 저장되어 있지 않을 때 쓰는 값입니다.

## 기억되는 값과 사라지는 값

창의 조작 설정 대부분은 **Unity 에디터의 EditorPrefs**에 저장됩니다. 프로젝트를 닫았다 열어도, 다른 프로젝트를 열어도 그대로 남습니다.

예외로 **키 잠금 상태**는 프로젝트의 EditorUserSettings에 메쉬 GUID별로 저장됩니다.

반대로 **편집 상태**(선택, 마스크, 숨김, 되돌리기 기록, 표정 키 값, 칠한 영역)는 세션에 속합니다. `메쉬 저장`이나 `편집 버리기`로 세션이 끝나면 사라집니다. → [세션과 되돌리기](/internals/session-and-undo)

## 창 공통

| 항목 | 설명 | 기본값 |
|---|---|---|
| 언어 | 한국어 / English / 日本語. 처음에는 Unity 에디터의 시스템 언어를 따릅니다 | 시스템 언어 |
| 쉽게 시작 / 전문가 | 창의 보기 방식입니다. 편집 값은 바뀌지 않습니다 | 쉽게 시작 |
| 활성 탭 | 마지막에 쓰던 탭을 기억합니다 | 첫 번째 탭 |
| 단축키 시트 (`Keys`) | 펼쳐 둔 상태를 기억합니다 | 접힘 |

## 모양 다듬기

| 항목 | 범위 | 기본값 |
|---|---|---|
| 브러시 | 잡아당기기 · 매끈하게 · 평평하게 · 모으기 · 부풀리기 | 잡아당기기 |
| `반경` | 0.001 ~ 2 | 0.05 |
| `강도` | 0 ~ 1 | 0.5 |
| `감쇠` | `스무스` · `구형` · `샤프` · `일정` | 스무스 |
| `범위 표시` | 0.05 ~ 1 | 0.9 |
| 필압 크기 / 필압 세기 | 각각 0 ~ 100% | 0% / 100% |
| `대칭` X / Y / Z | 켜기 / 끄기 | 끄기 |
| `대칭 평면 표시` | 켜기 / 끄기 | 켜기 |
| 마스크 방식 | `아일랜드` · `브러시` · `박스` | 아일랜드 |
| 브러시 프리셋 | 3칸 | 빈 칸 |
| X-Ray | 켜기 / 끄기 | 끄기 |

## 선택·이동

| 항목 | 범위 | 기본값 |
|---|---|---|
| 요소 모드 | 정점 · 엣지 · 페이스 | 정점 |
| 기즈모 | 보기 · 이동 · 회전 · 스케일 | 이동 |
| `프로포셔널 편집` | 켜기 / 끄기 | 끄기 |
| 프로포셔널 `반경` | 값으로 기억 | 0.2 |
| `연결된 것만` | 켜기 / 끄기 | 켜기 |
| `대칭` X / Y / Z | 켜기 / 끄기 | 끄기 |
| `피벗` | 중앙점 · 개별 원점 · 활성 요소 · 바운딩 박스 중심 | 중앙점 |
| `메쉬별 균등 피벗` | 켜기 / 끄기 | 끄기 |
| `노멀 표시`, `노멀 길이` | 켜기 / 끄기, 길이 값 | 끄기, 0.02 |
| `병합 거리` | 0 이상 | 0.0001 |
| X-Ray | 켜기 / 끄기 | 끄기 |

## 표정 키

| 항목 | 설명 | 기본값 |
|---|---|---|
| `그룹` | 접두사로 목록을 접습니다 | 켜기 |
| `확장 범위` (-100 ~ 200) | 슬라이더 범위를 넓힙니다 | 끄기 |
| `히트맵` | 델타 히트맵을 켭니다 | 끄기 |
| `미러 축` | 미러 키를 만들 때 쓰는 축 | X |
| 키 잠금 (`L`) | 메쉬 GUID별로 프로젝트에 저장됩니다 | 잠금 없음 |

## 설정을 초기화하려면

개별 항목은 창에서 되돌리면 됩니다. 전부 한 번에 초기화하는 버튼은 없습니다. 꼭 필요하면 Unity의 EditorPrefs에서 `StudioRaming.EasyMeshEditor.`로 시작하는 키를 지우세요.
