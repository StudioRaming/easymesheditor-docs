# 설정 항목

**이 문서를 읽으면** 창의 어떤 값이 다음에 열 때까지 기억되는지, 어떤 것이 세션과 함께 사라지는지 알 수 있습니다.

## 기억되는 값과 사라지는 값

거의 모든 조작 설정은 **Unity 에디터의 EditorPrefs**에 저장됩니다. 프로젝트를 닫았다 열어도, 다른 프로젝트를 열어도 그대로 남습니다.

반대로 **편집 상태**(선택, 마스크, 숨김, 되돌리기 기록, 블렌드쉐이프 값)는 세션에 속합니다. `Bake`나 `Revert`로 세션이 끝나면 사라집니다. → [세션과 되돌리기](/internals/session-and-undo)

키 잠금 상태는 예외적으로 프로젝트 단위(EditorUserSettings)에 저장됩니다.

## 창 공통

| 항목 | 기본값 |
|---|---|
| 언어 | 에디터 시스템 언어 (한국어/일본어면 그 언어, 그 밖에는 English) |
| `Keys` 시트 열림 | 닫힘 |
| 활성 탭 | 스컬프트 |

## 스컬프트

| 항목 | 범위 | 기본값 |
|---|---|---|
| 브러시 | 엘라스틱 · 스무딩 · 평탄화 · 핀치 · 인플레이트 | `엘라스틱 (1)` |
| `반경` | 0.001 ~ 2 | 0.05 |
| `강도` | 0 ~ 1 | 0.5 |
| `감쇠` | `스무스` · `구형` · `샤프` · `일정` | `스무스` |
| `필압 사용` | on/off | 켜짐 |
| `범위 표시` | 0.05 ~ 1 | 0.9 |
| `대칭` X / Y / Z | on/off | 모두 꺼짐 |
| `대칭 평면 표시` | on/off | 켜짐 |
| 마스크 서브모드 | `아일랜드` · `브러시` · `박스` | `아일랜드` |
| `브러시 프리셋` 슬롯 1~3 | — | `비어 있음` |
| X-Ray | on/off | 꺼짐 |

| `프로포셔널 편집 (O)` | on/off | 꺼짐 |

## 설정을 초기화하려면

개별 항목은 창에서 되돌리면 됩니다. 전부 초기값으로 돌리는 버튼은 없습니다. 필요하면 Unity의 EditorPrefs에서 `StudioRaming.EasyMeshEditor.` 로 시작하는 키를 지우세요.
