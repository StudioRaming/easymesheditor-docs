# 현재 제한

Easy Mesh Editor `1.0.0` 기준입니다. 여기 적힌 것은 버그가 아니라 **이번 버전에서 아직 하지 않는 일**입니다.

## 없는 기능

| 기능 | 상태 |
|---|---|
| 압출 (Extrude) | 미구현 |
| 인셋 (Inset) | 미구현 |
| 베벨 (Bevel) | 미구현 |

셋 다 새 면을 만들어 내는 위상 편집이라 아직 구현하지 않았습니다. 이번 버전의 `선택·이동` 탭은 기존 면을 고르고, 옮기고, 지우고, 떼어내고, 합치는 데까지입니다. 위상 편집은 삭제, 분리, 거리로 병합까지입니다. → [선택·이동](/guides/edit)

## 대상 제한

- `표정 키`와 `뼈 연결` 탭은 **`SkinnedMeshRenderer` 전용**입니다. 일반 `MeshRenderer`는 `모양 다듬기`, `선택·이동`, 메쉬 저장까지만 됩니다.
- 여러 메쉬를 함께 다룰 때 `표정 키`는 대상이 **전부** SMR이어야 합니다.
- 읽기/쓰기가 불가능한 메쉬, 삼각형이 아닌 토폴로지, 손상된 메쉬 데이터는 정상 편집을 보장하지 않습니다.

## 본 웨이트

- 직접 칠하기는 Unity의 레거시 **4슬롯** 범위에서 동작합니다.
- **칠하지 않은** 정점의 5개 이상 본 영향은 보존됩니다. → [가변 본 웨이트](/internals/bake#가변-본-웨이트)

## 표정 키

- 프레임이 여러 개인 키는 **마지막 프레임(100%)만 편집**됩니다. 저장하면 중간 프레임이 그 변화량에 비례해 갱신됩니다. 중간 프레임을 따로 조형하는 방법은 없습니다.
- 키 이름이 같은 것이 여러 개 있으면 목록에서 클릭한 항목만 편집됩니다.
- 표정 키 편집 중에는 정점 수가 바뀌는 작업(삭제, 분리)을 키로 저장할 수 없습니다.

## 씬뷰 조작

- `Alt+클릭` 엣지 루프는 **움직이지 않은 클릭**에서만 동작합니다. Unity의 `Alt+드래그` 씬 회전을 빼앗지 않기 위한 규칙입니다. → [선택·이동](/guides/edit#엣지-루프와-엣지-링)
- 축 대칭 단축키는 `Alt+Shift+X` / `Y` / `Z`입니다. 단독 `X` `Y` `Z`와 `Alt+Z`는 각각 Unity 툴 핸들과 X-Ray로 남겨 두어 가로채지 않습니다.
- 씬뷰 단축키는 텍스트 입력 중에는 동작하지 않으며, Unity의 전역 Shortcut 프로필을 수정하지 않습니다.
- `뼈 연결` 탭의 `대칭 페인트 (X)`는 라벨에 `(X)`가 붙어 있지만 **창의 체크박스로만** 켜고 끕니다.

## 창과 자동 보존

- 창을 **두 개 이상** 열어 두고 스크립트가 다시 컴파일되면 자동 보존은 하나만 복원합니다.
- 자동 보존에는 변경 여부 판정이 없습니다. `불러오기`만 하고 아무것도 안 했어도 보존과 복원 대상입니다.
- 에디터가 비정상 종료하면 자동 보존이 실행되지 않습니다. 대신 미저장 편집이 있을 때 최소 60초 간격의 체크포인트를 남기고, 다음 실행 때 복구 배너로 복원 여부를 묻습니다.

## 성능

- 고밀도 메쉬는 씬뷰 오버레이, 정확한 박스 피킹, 스킨 포즈 계산과 브러시 처리 비용이 그만큼 늘어납니다.
- 여러 메쉬를 함께 열면 그 비용이 더해집니다. 필요한 것만 골라 여세요. → [다중 메쉬](/guides/multi-mesh)
- 구조 되돌리기 스냅샷은 메모리 상한이 있습니다. 넘으면 오래된 기록부터 버립니다.

## 실행 환경

- **Unity Editor 전용**입니다. 플레이어 빌드용 런타임 기능이 아닙니다.
- 지원 범위는 **Unity 2019.4, 2021.3, 2022.3, 6000.0, 6000.3 (LTS)**입니다.
- DLL판과 소스판을 같은 프로젝트에 함께 넣으면 컴파일 오류가 납니다.

## 권장 사항

중요한 프로젝트는 버전 관리나 별도 백업을 두세요. `메쉬 저장`은 원본 에셋을 덮어쓰지 않지만, 렌더러가 가리키는 메쉬는 바뀝니다.
