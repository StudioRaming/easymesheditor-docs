# 표정 키

**이 문서를 읽으면** 표정 키 목록을 다루는 법, 새 키를 조형하는 법과 기존 키를 다시 손보는 편집, 미러 키·키 가져오기·적용값 합치기 같은 관리 기능, 그리고 `새 키로 저장`과 `메쉬 저장`의 차이를 알 수 있습니다.

:::note[`SkinnedMeshRenderer` 전용입니다]
일반 `MeshRenderer` 대상에서는 이 탭을 쓸 수 없습니다. 안내가 대신 표시됩니다.
:::

## 목록 {#목록}

각 행에 이름, 값 슬라이더, 숫자 입력이 있습니다.

- 값은 `0~100`이며 실시간으로 미리보기에 반영됩니다.
- 이름이나 값을 좌우로 드래그해도 값이 바뀝니다. `Shift`를 함께 누르면 미세 조절입니다.
- `전체 값 0으로`로 모든 키를 한 번에 0으로 내립니다.

목록 위의 검색 상자로 이름을 걸러냅니다.

### 행의 버튼

| 버튼 | 하는 일 |
|---|---|
| `S` | 그 키만 100으로 보는 솔로 프리뷰입니다. `Esc`로 해제합니다 |
| `L` | 실수를 막는 잠금입니다 |
| `M` | 미러 키를 만듭니다 |

### 접두사 그룹 {#접두사-그룹}

`그룹`을 켜면 이름의 접두사로 목록이 접힙니다. `eye_blink`와 `eye_wide`는 `eye` 그룹으로 묶입니다. `vrc.v_`, `mouth_` 같은 접두사도 자동으로 인식합니다.

### 확장 범위 {#확장-범위}

`확장 범위`를 켜면 슬라이더가 `-100~200`까지 열립니다. 외삽이므로 형태가 깨질 수 있습니다. 과장했을 때 무너지지 않는지 확인하는 용도로 쓰고, 그 값 그대로 저장하지는 마세요.

### 델타 히트맵 {#델타-히트맵}

`히트맵`을 켜고 목록에서 키 이름을 클릭하면, 그 키가 실제로 움직이는 정점이 색으로 표시됩니다. 키를 고르지 않았다면 안내가 나옵니다.

### 솔로 프리뷰 {#솔로-프리뷰}

행의 `S`를 누르면 그 키만 100으로 켠 상태로 봅니다. 다른 키의 값은 화면에서만 잠시 물러납니다. `Esc`로 해제합니다.

솔로 중에는 여러 키의 값을 한꺼번에 바꿀 수 없습니다. 먼저 솔로를 해제하세요.

### 잠금 {#잠금}

행의 `L`로 키를 잠급니다. 잠긴 키는 편집, 값 변경, 일괄 작업, 키 가져오기에서 제외됩니다. 바꾸려면 `L`을 다시 눌러 잠금을 풀어야 합니다. 잠금 상태는 프로젝트마다 기억됩니다.

## 여러 키를 한 번에 {#다중-선택}

이름을 클릭하면 선택되고, `Ctrl`이나 `Shift`를 누른 채 클릭하면 여러 개를 고를 수 있습니다. 선택한 키에 대해 다음 일괄 작업을 한 번에 할 수 있습니다.

- 같은 값 넣기, 0으로 내리기
- 잠그기와 잠금 풀기
- 순서 옮기기
- 삭제

일괄 작업은 Unity의 되돌리기 한 단계입니다. 잘못 눌렀다면 `Ctrl+Z`로 전부 되돌릴 수 있습니다. 선택한 키가 모두 잠겨 있으면 아무것도 바꾸지 않습니다.

## 새 키 조형 {#새-쉐이프-조형}

표정 키 탭의 새 키 버튼 또는 씬뷰에서 `N`을 누르면 지금 보이는 절대 형태를 기준으로 조형을 시작합니다. 씬뷰에 조형 중이라는 바가 뜹니다.

- 드래그: 그랩(잡아당기기)
- `Shift`: 매끈하게
- `F`: 반경, `Shift+F`: 강도
- `Enter`: 새 키 저장, `Esc`: 스트로크 취소

이름은 키 이름 칸에서 정합니다. 키 이름의 `/`와 줄바꿈은 자동으로 `_`로 바뀌어 저장됩니다.

## 기존 키 편집 {#기존-키-편집}

키 목록에서 그 키를 편집하면, 그 키의 **마지막 프레임 100% 형태**를 단독으로 불러옵니다. 편집이 시작되면 창의 배지가 `키 편집 중`이 되고, 고정 바가 나타납니다.

편집 중에도 `모양 다듬기`와 `선택·이동` 탭으로 옮겨 작업할 수 있습니다. 끝나면 고정 바에서 둘 중 하나를 고릅니다.

- `저장`: 키 편집을 세션에 확정합니다.
- `키 편집 취소`: 편집을 버립니다. 조형한 내용이 있으면 한 번 더 확인합니다.

:::caution[여기서 확정해도 아직 에셋은 바뀌지 않습니다]
키 편집을 저장해도 세션 안에서만 확정됩니다. 메쉬 에셋에 들어가는 것은 `메쉬 저장` 때입니다.
:::

확정하지 않은 채 `메쉬 저장`이나 `새 키로 저장`을 누르면 저장이 막히고 편집을 먼저 마치라는 안내가 나옵니다. 정점 수가 바뀌는 작업(정점 삭제, 분리)은 키 편집 중에는 저장할 수 없습니다.

`Esc`는 진행 중인 스트로크만 취소하고 키 편집은 버리지 않습니다. 키 편집을 저장하거나 취소하면, 그 편집 중의 스트로크 단계는 `Ctrl+Z` 목록에서 정리되어 아무것도 바꾸지 않는 빈 되돌리기 단계가 남지 않습니다.

### 프레임이 여러 개인 키 {#다중-프레임}

프레임이 둘 이상인 키를 편집하면 경고가 뜹니다. 마지막 프레임(100%)만 편집됩니다.

저장하면 중간 프레임은 마지막 프레임의 변화량에 비례해 함께 갱신됩니다. 중간 프레임을 따로 손보는 기능은 없습니다. → [현재 제한](/limitations)

### 되돌리기가 편집 시작 이전으로 갔을 때

`Ctrl+Z`가 키 편집을 시작한 시점보다 앞으로 가면 편집의 기준이 사라집니다. 이때는 편집을 자동으로 취소하고 알려 줍니다. 잘못된 델타가 저장되는 것을 막기 위해서입니다.

## 기본형 직접 수정 {#기본형-직접-수정}

키를 고르지 않은 채 `모양 다듬기`나 `선택·이동`에서 메쉬를 바꾸면 기본형을 수정한 것입니다. 표정 키 탭이 두 가지 선택을 줍니다.

- `신규 키로 확정`: 그 변형을 새 키로 만듭니다.
- `기본형 수정 되돌리기`: 기본형을 수정하기 전 상태로 되돌립니다.

이 상태로 `메쉬 저장`을 누르면 창이 기본형에 구울지, 신규 키로 확정할지 다시 묻습니다.

## 관리 {#관리}

| 버튼 | 하는 일 |
|---|---|
| 이름 | 이름을 바꿉니다 |
| 복제 | 같은 내용의 키를 하나 더 만듭니다 (`_Copy`) |
| 반전 | 반전 키를 만듭니다 (`_Revert`). 기본형을 바꾼 뒤 원래 표정을 되찾을 때 씁니다 |
| 삭제 | 키를 지웁니다. `Ctrl+Z`로 되돌릴 수 있습니다 |
| `^` / `v` | 순서를 옮깁니다 |

키 이름이 같은 것이 여러 개 있으면 목록에서 클릭한 항목만 편집됩니다.

### 적용값 합치기 {#적용값-합치기}

`적용값 합치기`는 지금 0이 아닌 키들의 **보이는 결과**를 하나의 새 100% 키로 합칩니다. 재료로 쓴 키들의 값은 0으로 돌아갑니다. 프레임이 여러 개인 키의 보간과 외삽도 계산합니다.

### 미러 키 {#미러-키}

행의 `M`을 누르고 미러 축(보통 X)을 고르면 반대쪽 표정 키를 만듭니다.

이름은 원래 이름의 좌우 표기를 뒤집어 정합니다.

| 원본 이름 | 미러 이름 |
|---|---|
| `...Left...` | `...Right...` (대소문자를 무시한 매칭도 시도합니다) |
| `xxx_L` | `xxx_R` |
| `L_xxx` | `R_xxx` |
| `xxx.L` | `xxx.R` |
| 좌우 표기가 없음 | `xxx_Mirror` |

정점 짝은 `모양 다듬기`와 같은 공간 대응으로 찾습니다. 짝이 없는 정점은 대칭 평면 위에 있을 때만 반사되고, 나머지는 움직이지 않습니다. 노멀 델타도 같게 반사되며, 프레임이 여러 개면 모든 프레임을 미러합니다.

짝을 찾지 못하면 미러 키를 만들지 않습니다. 메쉬가 애초에 좌우 비대칭이라면 반대쪽은 손으로 조형해야 합니다.

### 다른 메쉬에서 키 가져오기 {#키-전송}

얼굴 메쉬의 표정 키를 헤어나 소품 같은 다른 메쉬로 옮길 때 씁니다. 근접 매핑으로 대응점을 찾습니다.

1. `소스 메쉬`를 고릅니다. 그 메쉬의 키 목록이 나타납니다.
2. 가져올 키를 체크합니다. `전체 선택`과 `전체 해제`가 있습니다.
3. `최대 거리`를 정합니다. 이 거리 안에서 대응점을 찾습니다.
4. `가져오기`를 누릅니다.

대응점을 찾지 못한 정점은 움직이지 않습니다. 결과가 많이 빠졌다면 최대 거리를 늘려 보세요. 잠긴 키는 건너뜁니다. 같은 이름의 키가 이미 있으면 교체할지 묻습니다.

실패하면 모든 메쉬를 작업 전 상태로 되돌립니다.

## 빠른 캡처와 메쉬 저장 {#빠른-캡처와-bake}

둘 다 저장이지만 하는 일이 다릅니다.

| | `새 키로 저장` | `메쉬 저장` (Bake) |
|---|---|---|
| 저장 대상 | 기본형에 **이번에 더한 변형만** 새 키로 | Work Mesh **전체** (정점, 웨이트, 키 구조) |
| 에셋 | 아직 바뀌지 않습니다 | `<원본명>_Edit.asset`을 만듭니다 |
| 세션 | 계속됩니다 | 끝납니다 |
| 기본형 | 그대로 둡니다 | 지금 상태 그대로 굽습니다 |

`새 키로 저장`은 표정 키 값으로 재생 중인 모양을 섞지 않습니다. 저장한 키는 100으로 켜져 현재 모습이 유지되고, 다음 캡처의 기준이 갱신되어 같은 변형이 두 번 저장되지 않습니다.

캡처할 변형이 없으면 아무것도 저장하지 않습니다.

## 여러 메쉬에서 {#다중-메쉬-키}

여러 메쉬를 함께 편집할 때는 모든 대상이 `SkinnedMeshRenderer`여야 합니다.

목록에는 **모든 대상에 이름이 같은 키만** 나옵니다. 인덱스가 서로 달라도 됩니다. 값, 편집, 관리는 모든 메쉬에 동시에 적용됩니다. 공통 키가 하나도 없으면 목록이 비고, 새로 만드는 키는 같은 이름으로 모든 메쉬에 추가됩니다. → [다중 메쉬](/guides/multi-mesh)

## MingToon 페이스 프록시 {#mingtoon-페이스-프록시}

이 연동에는 MingToon 최신 버전이 필요합니다. MingToon에서 페이스 프록시 소스 편집을 열면 Easy Mesh Editor가 그 소스 메쉬로 세션을 시작합니다. 편집하는 동안 얼굴 렌더러는 숨겨지고, `모양 다듬기` 탭과 `선택·이동` 탭(정점 이동)만 쓸 수 있습니다. 삭제·분리·병합·노멀 변경·새 키처럼 메쉬 구조를 바꾸는 작업은 잠깁니다. `메쉬 저장`을 누르면 결과를 MingToon에 넘기고, `편집 버리기`를 누르면 소스는 그대로 남습니다.
