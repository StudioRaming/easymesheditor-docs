# 창 사용법

**이 문서를 읽으면** 창의 각 부분이 무엇을 하는지, 상태 배지가 뜻하는 것, 불러올 후보 목록을 쓰는 법, 씬뷰 힌트와 단축키 시트를 여는 법, 그리고 저장 결과표를 읽는 법을 알 수 있습니다.


창은 위에서 아래로 **헤더, 탭, 대상 행, 저장 행, 탭 본문** 순서입니다. 어느 탭에 있든 이 본대는 그대로입니다.

## 헤더와 언어

헤더에 제품 이름과 버전 배지가 있습니다. 제보할 때 이 버전 숫자를 적어 주세요.

언어는 한국어 / English / 日本語 셋 중에서 고릅니다. 바꾸면 창과 씬뷰 힌트, 툴팁까지 새 언어로 다시 그립니다. 처음 열 때는 Unity 에디터의 시스템 언어를 따릅니다.

## 탭

네 개의 탭이 있습니다. 탭 이름은 화면에 나오는 그대로 씁니다.

| 탭 | 문서 |
|---|---|
| `모양 다듬기` | [모양 다듬기](/guides/sculpt) |
| `선택·이동` | [선택·이동](/guides/edit) |
| `표정 키` | [표정 키](/guides/blendshape) |
| `뼈 연결` | [뼈 연결](/guides/weight-paint) |

`Ctrl+Tab`으로 다음 탭, `Ctrl+Shift+Tab`으로 이전 탭으로 갑니다.

`표정 키`와 `뼈 연결`은 `SkinnedMeshRenderer`에서만 동작합니다. 일반 `MeshRenderer`만 불러온 상태에서 들어가면 그 탭은 쓸 수 없다는 안내를 보여 줍니다.

## 시작 카드

편집을 시작하기 전에 창에 시작 카드가 나옵니다. 네 단계를 보여 줍니다.

1. 대상 고르기 (Hierarchy에서 오브젝트 선택)
2. 불러오기
3. 모드 선택 (탭 고르기)
4. 메쉬 저장

## 쉽게 시작 / 전문가 보기

창에는 **쉽게 시작**과 **전문가** 두 가지 보기가 있습니다. 쉽게 시작은 자주 쓰는 설정을 먼저 보여 주고, 전문가는 세부 설정까지 펼칩니다. 어느 쪽을 골라도 편집 값과 작업은 그대로 유지됩니다. 세부 설정은 `자세한 설정`에서 펼칠 수 있습니다.

창을 처음 열면 **쉽게 시작**이 보입니다.

## 대상 행과 불러올 후보 {#불러올-후보}

Hierarchy에서 고른 오브젝트 안의 `SkinnedMeshRenderer`와 `MeshFilter + MeshRenderer`가 **불러올 후보**로 잡힙니다. 후보 목록에서 행마다 이름, 정점 수, 키 수, 그리고 경고가 보입니다.

- 행 하나를 클릭하면 그 렌더러만 불러옵니다.
- 선택을 비우고 `불러오기`를 누르면 후보 전체를 불러옵니다.
- Read/Write가 꺼진 메쉬는 후보 행에서 비활성으로 표시됩니다. 상태줄의 `Read/Write 켜기` 버튼으로 임포터 설정을 켠 뒤 `불러오기`를 누르세요. → [설치](/getting-started/installation#7-메쉬가-readwrite-꺼짐이라면)
- 같은 원본 메쉬를 쓰는 렌더러는 각각 따로 불러와 따로 편집합니다. 편집 결과도 렌더러마다 따로 저장됩니다.

여러 메쉬를 불러왔다면 `활성 대상` 선택기로 `표정 키`와 `뼈 연결`이 적용될 대상을 고릅니다. → [다중 메쉬](/guides/multi-mesh#활성-대상)

## 상태 배지 {#상태-배지}

| 배지 | 뜻 |
|---|---|
| `저장됨` | `불러오기` 이후 바뀐 것이 없습니다 |
| `변경 있음` | 저장되지 않은 편집이 있습니다 |
| `트랜잭션 중` | 표정 키 편집이 진행 중이며 아직 확정되지 않았습니다 |

좁은 창에서는 배지가 짧게 줄어들고, 전체 문구는 툴팁에 남습니다.

## 저장 행

저장 행에는 두 가지 저장이 있습니다. 하는 일이 다릅니다.

| 버튼 | 하는 일 |
|---|---|
| `새 키로 저장` | 기본형에 이번에 더한 변형만 새 표정 키로 남깁니다. 세션은 계속됩니다. 키 이름은 `표정으로 남길 이름 (선택)` 칸에 적습니다 |
| `메쉬 저장` | 지금의 Work Mesh 전체를 메쉬 에셋으로 저장하고 세션을 끝냅니다 |

`메쉬 저장`은 모든 작업을 마친 뒤 한 번 누르는 버튼입니다. `새 키로 저장`은 에셋을 아직 바꾸지 않습니다. 두 버튼 모두 표정 키 편집이 확정되지 않은 동안에는 눌리지 않습니다. → [표정 키](/guides/blendshape#빠른-캡처와-bake)

표정 키가 없는 일반 메쉬에서는 키 이름 칸과 `새 키로 저장` 버튼이 보이지 않습니다.

## 표정 키 편집 바

표정 키를 만들거나 편집하는 동안에는 창 상단에 고정된 바가 나타납니다. 여기서 `저장`(키 편집 확정) 또는 `키 편집 취소`를 누릅니다. 이 바는 어느 탭에 있어도 보입니다.

- `Enter`는 키 편집을 저장합니다. 단, 키를 만든 탭이 활성일 때만 동작합니다.
- `Esc`는 진행 중인 스트로크나 크기 조절만 취소하고, 키 편집은 버리지 않습니다.
- `키 편집 취소`는 조형한 내용이 있을 때 한 번 더 확인합니다.

## 상태줄

창 아래 상태줄에 방금 한 작업의 결과와 안내가 나옵니다. Read/Write 켜기 버튼도 여기에 나옵니다.

## 복구 배너

Unity가 비정상 종료된 뒤 다시 열면 창 위에 복구 배너가 나옵니다. `복원`을 누르면 체크포인트에서 세션을 되돌립니다. `버리기`는 5초 안에 두 번 눌러야 실행됩니다. 복원하지 못한 파일은 지우지 않습니다. → [세션과 되돌리기](/internals/session-and-undo#크래시-대비)

## 저장 안내 버튼

편집 중인 씬이 한 번도 저장되지 않았으면 창이 안내를 띄웁니다. 안내 아래의 `씬 저장`을 누르면 씬을 저장하고, `편집 버리기`를 누르면 편집을 버립니다. 저장한 적 없는 씬의 오브젝트는 편집 내용을 보존할 수 없습니다. → [세션과 되돌리기](/internals/session-and-undo#자동-보존과-복원)

## 씬뷰 힌트와 단축키 시트 {#단축키-시트}

씬뷰 위쪽에 지금 탭에서 쓸 수 있는 조작 힌트가 한 줄로 떠 있습니다. 힌트바 오른쪽의 `Keys` 버튼을 누르면 현재 탭의 단축키와 공통 단축키 전체 표가 씬뷰에 펼쳐집니다. 다시 누르면 닫힙니다. 창 안에도 같은 단축키 시트를 여는 버튼이 있습니다.

단축키는 텍스트 입력 중에는 동작하지 않으며, Unity의 전역 Shortcut 프로필을 바꾸지 않습니다. 전체 목록은 [단축키](/reference/shortcuts)에 있습니다.

씬뷰의 힌트, 도구 패널, 단축키 시트는 Unity 2021.2 이상의 씬뷰 오버레이 위에 그려집니다. 2021.2 미만(2019.4 포함)에서는 기존 방식으로 그립니다.

## 저장 결과표 {#저장-결과표}

여러 메쉬를 함께 `메쉬 저장`하면 대상마다 성공과 실패, 저장 경로가 접이식 결과표로 나옵니다. 실패한 대상의 세션은 열린 채로 남아 다시 시도할 수 있습니다. 성공한 대상만 에셋으로 나갑니다.

## 씬뷰 브러시 프리셋과 선택 영역 보기

`모양 다듬기`와 `뼈 연결` 탭의 브러시 설정 아래에는 프리셋 슬롯이 있습니다. 빈 칸을 클릭하면 현재 브러시를 저장하고, 저장된 칸을 클릭하면 불러옵니다. `선택 영역 보기`(숫자패드 `.`)는 편집 중인 메쉬를 씬뷰 화면에 맞춥니다.
