# 다중 메쉬

**이 문서를 읽으면** 여러 메쉬를 한 세션에서 함께 다룰 때 무엇이 모든 메쉬에 적용되고 무엇이 활성 대상에만 적용되는지, 공용 기즈모가 어떻게 동작하는지, 하나가 실패했을 때 어떻게 되는지 알 수 있습니다.

## 함께 불러오기

Hierarchy에서 여러 오브젝트를 고르고 `불러오기`를 누르면 됩니다. 같은 세션에 여러 메쉬가 올라옵니다.

같은 원본 메쉬를 쓰는 렌더러도 **각각 따로** 불러와 따로 편집합니다. 예전 버전처럼 중복을 제외하지 않습니다. 각 렌더러의 결과는 따로 저장됩니다. 저장 시 파일이 서로 덮어쓰지 않도록 렌더러마다 출력을 나눕니다. → [생성되는 파일](/reference/output-files#provenance와-owner)

토폴로지와 정점 수가 서로 달라도 됩니다. 각 메쉬는 자기 데이터로 따로 계산됩니다.

## 활성 대상 {#활성-대상}

`활성 대상` 선택기로 지금 초점이 맞춰진 메쉬를 바꿉니다. 어떤 작업이 모든 메쉬에 적용되고, 어떤 작업이 활성 대상에만 적용되는지가 나뉩니다.

| 탭 | 범위 |
|---|---|
| `모양 다듬기` | 불러온 모든 메쉬 |
| `선택·이동` | 모든 메쉬에서 선택을 유지하고, 공용 기즈모로 함께 변형 |
| `표정 키` | 이름이 같은 키에 한해 모든 메쉬에 동시에 적용 |
| `뼈 연결` | 활성 대상 하나 |

삭제와 분리는 활성 메쉬에만 적용됩니다.

## 선택·이동 탭의 공용 기즈모

여러 메쉬에서 각각 요소를 고르면 **월드 공간의 공용 기즈모 하나**로 모든 메쉬를 함께 변형합니다.

- `G` / `R` / `S` [모달 변형](/guides/edit#모달-변형)의 축은 월드 축으로 적용됩니다. 여러 메쉬의 로컬 축은 하나로 정해지지 않기 때문입니다.
- `A`(전체 선택), `Alt+A`(해제), `Ctrl+I`(반전)는 모든 대상에 적용됩니다.

[피벗](/guides/edit#피벗)에서 `메쉬별 균등 피벗`을 켜면 메쉬마다 자기 피벗을 씁니다.

대칭 대응점, 선택, 브러시 영향은 항상 각 메쉬에서 따로 계산됩니다.

## 표정 키의 이름 교집합 {#표정-키}

여러 메쉬의 표정 키를 함께 다루려면 모든 대상이 `SkinnedMeshRenderer`여야 합니다. 목록에는 **모든 대상에 이름이 같은 키만** 나옵니다.

인덱스가 서로 달라도 됩니다. 이름으로만 맞춥니다. 값, 편집, 관리는 모든 메쉬에 동시에 적용됩니다. 공통 키가 없으면 목록이 비고, 새로 만드는 키는 같은 이름으로 모든 메쉬에 추가됩니다. → [표정 키](/guides/blendshape#다중-메쉬-키)

## 원자적 롤백 {#원자적-롤백}

여러 메쉬의 구조를 바꾸는 작업(일괄 삭제, 순서 변경, 키 가져오기, 분리 등)은 **전부 성공하거나 전부 되돌아갑니다.** 하나라도 실패하면 모든 대상을 작업 전 상태로 되돌립니다.

되돌리기도 마찬가지입니다. 다중 메쉬 작업은 하나의 되돌리기 단계로 묶입니다. → [세션과 되돌리기](/internals/session-and-undo)

## 메쉬 저장은 메쉬마다 따로입니다

`메쉬 저장`은 대상마다 각각의 `<원본명>_Edit.asset`을 만듭니다. 롤백 규칙과 달리 여기서는 성공한 것만 나가고, 실패한 대상의 세션은 열린 채로 남습니다.

결과는 대상별 성공과 실패를 보여 주는 접이식 결과표로 나옵니다. → [창 사용법](/guides/window#저장-결과표)

## 성능

고밀도 메쉬를 여러 개 열면 씬뷰 오버레이, 박스 피킹, 스킨 포즈 계산과 브러시 처리 비용이 그만큼 늘어납니다. 느껴질 정도로 무거우면 필요한 메쉬만 골라 불러오세요. 후보 목록에서 한 행씩 불러올 수 있습니다. → [창 사용법](/guides/window#불러올-후보)
