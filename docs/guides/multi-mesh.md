# 다중 메쉬

**이 문서를 읽으면** 여러 메쉬를 한 세션에서 함께 다룰 때 무엇이 함께 적용되고 무엇이 활성 대상에만 적용되는지, 공용 기즈모가 어떻게 동작하는지, 그리고 하나가 실패했을 때 나머지가 어떻게 되는지 알 수 있습니다.

## 함께 열기

Hierarchy에서 여러 오브젝트를 고르고 `Load`를 누르면 됩니다. 창은 먼저 `Load를 누르면 선택한 {0}개 메쉬를 모두 함께 엽니다.` 로 알려 주고, 열고 나면 `{0}개 메쉬 함께 편집 중` 이 됩니다.

같은 원본 메쉬를 공유하는 렌더러는 자동으로 걸러집니다 — ` (동일 원본 메쉬 공유로 {0}개 제외)`. 같은 메쉬를 두 번 편집하면 서로 덮어쓰기 때문입니다.

토폴로지와 정점 수가 서로 달라도 됩니다. 각 메쉬는 자기 데이터로 따로 계산됩니다.

## 활성 대상 {#활성-대상}

`활성 대상` 선택기로 지금 초점이 맞춰진 메쉬를 바꿉니다. 무엇이 함께 적용되고 무엇이 활성 대상에만 적용되는지가 나뉩니다.

> `스컬프트와 편집은 로드된 모든 메쉬에 적용됩니다. 블렌드쉐이프와 웨이트는 활성 대상에 적용됩니다.`

| 탭 | 범위 |
|---|---|
| `스컬프트` | 로드된 모든 메쉬 |
| `편집` | 모든 메쉬에서 선택을 유지, 공용 기즈모로 함께 변형 |
| `블렌드쉐이프` | 이름이 공통인 키에 한해 모든 메쉬에 동시 적용 |
| `웨이트` | 활성 대상 하나 |

## 편집 탭의 공용 기즈모

여러 메쉬에서 각각 요소를 고르면 상태가 `다중 메쉬 — {1}개 중 {0}개에 선택됨 · 공용 기즈모로 함께 변형 (삭제/분리는 활성 메쉬 기준)` 으로 바뀝니다.

- 변형은 **월드 공간의 기즈모 하나**로 모든 메쉬에 함께 적용됩니다.
- `G`/`R`/`S` [모달 변형](/guides/edit#모달-변형)의 로컬 축은 하나로 정해지지 않으므로 `여러 메쉬 → 월드 축` 으로 폴백합니다.
- `A`(전체 선택)·`Alt+A`(해제)·`Ctrl+I`(반전)는 모든 대상에 적용됩니다.
- **삭제와 분리는 활성 메쉬에만** 적용됩니다.

[피벗](/guides/edit#피벗)의 `메쉬별 균등 피벗` 을 켜면 메쉬마다 자기 피벗을 씁니다.

대칭 대응점, 선택, 브러시 영향은 언제나 각 메쉬에서 독립적으로 계산됩니다.

## 블렌드쉐이프의 이름 교집합

모든 대상이 `SkinnedMeshRenderer` 여야 합니다. 목록에는 **모든 대상에 이름이 같은 키만** 나옵니다.

> `{0}개 메쉬에 모두 있는 키만 표시합니다. 값·편집·관리는 모든 메쉬에 동시에 적용됩니다.`

인덱스는 서로 달라도 상관없습니다 — 이름으로만 맞춥니다. 공통 키가 없으면 목록이 비고, 새로 만드는 키는 같은 이름으로 모든 메쉬에 추가됩니다. → [블렌드쉐이프](/guides/blendshape#다중-메쉬-키)

## 원자적 롤백 {#원자적-롤백}

여러 메쉬의 구조를 바꾸는 작업(일괄 삭제, 순서 변경, 키 전송, 분리 …)은 **전부 성공하거나 전부 되돌아갑니다.** 하나가 실패하면 모든 대상의 스냅샷을 복원합니다.

> `일괄 작업에 실패해 모든 메쉬를 작업 전 상태로 되돌렸습니다. 콘솔 로그를 확인하세요.`

되돌리기 쪽도 마찬가지입니다. 다중 메쉬 작업은 하나의 복합 되돌리기 단계로 묶입니다. → [세션과 되돌리기](/internals/session-and-undo)

## Bake는 메쉬마다 따로입니다

`Bake`는 대상마다 각각의 `<원본명>_Edit.asset` 을 만듭니다. 롤백 규칙과 달리 여기서는 성공한 것만 나가고 실패한 세션은 열린 채로 남습니다.

결과는 `Bake 결과 ({0}/{1} 성공)` 표로 창에 정리됩니다. → [창 사용법](/guides/window#상태-배지)

## 성능

고밀도 메쉬를 여러 개 열면 씬뷰 오버레이, 박스 피킹, 스킨 포즈 계산과 브러시 처리 비용이 그만큼 늘어납니다. 느껴질 정도로 무거우면 필요한 메쉬만 골라 `불러올 후보` 목록에서 하나씩 여세요. → [창 사용법](/guides/window#불러올-후보)
