# 선택·이동

**이 문서를 읽으면** 정점·엣지·페이스를 고르는 법, 기즈모와 블렌더식 G/R/S 변형의 차이, 엣지 루프를 Alt 클릭으로 잡는 규칙, 칠한 영역 정리, 숨기기·피벗·노멀·병합·분리까지 `선택·이동` 탭의 동작을 알 수 있습니다.

## 요소 모드 {#요소-모드}

| 버튼 | 키 |
|---|---|
| 정점 | `1` |
| 엣지 | `2` |
| 페이스 | `3` |

## 선택 {#선택}

| 조작 | 결과 |
|---|---|
| 클릭 | 교체 선택 |
| `Shift` 또는 `Ctrl`+클릭 | 추가 또는 제거 (토글) |
| 더블클릭 또는 `L` | 커서 아래 연결 요소 전체 선택 |
| `Shift+L` | 연결 요소 선택 해제 |
| `B` 또는 빈 공간 드래그 | 박스 선택 (`Shift`는 추가, `Ctrl`은 제거) |
| `A` / `Alt+A` | 전체 선택 / 선택 해제 |
| `Ctrl+I` | 선택 반전 |
| `Esc` | 선택 해제 |

:::note[UV 심 정점은 함께 잡힙니다]
Unity 메쉬는 UV 경계에서 같은 위치의 정점이 여러 개로 쪼개져 있습니다. 선택은 위치를 기준으로 그 무리 전체를 함께 잡습니다. 화면에서 점 하나를 골랐는데 실제로는 서너 개가 함께 움직입니다. → [웰드 그룹](/internals/session-and-undo#웰드-그룹)
:::

X-Ray(`Alt+Z`)가 꺼져 있으면 가려진 요소는 표시되지도, 선택되지도 않습니다. 켜면 뒷면까지 투과해 선택합니다.

### 엣지 루프와 엣지 링 {#엣지-루프와-엣지-링}

- `Alt+클릭` (누른 자리에서 움직이지 않고 떼기): 엣지 루프
- `Ctrl+Alt+클릭`: 엣지 링
- 둘 다 `Shift`를 함께 누르면 기존 선택에 추가합니다

:::caution[`Alt+드래그`는 씬 회전 그대로입니다]
Unity의 씬 회전을 빼앗지 않도록, 루프 선택은 3px 미만으로만 움직인 클릭에서만 일어납니다. `Alt`를 누른 채 조금이라도 끌면 평소처럼 카메라가 돕니다.
:::

### 선택 확장과 축소

- `Ctrl` + `+`: 선택 확장
- `Ctrl` + `-`: 선택 축소

숫자패드의 `+` `-`도 같게 동작합니다.

## 기즈모 {#기즈모}

| 도구 | 키 |
|---|---|
| 보기 | `Q` |
| 이동 | `W` |
| 회전 | `E` |
| 스케일 | `R` |

Unity의 기본 도구 배치와 같습니다. 본이 있는 스킨드 메쉬에서도 포즈가 잡힌 상태에서 화면에 보이는 대로 끌면 됩니다.

여러 메쉬에서 각각 요소를 골랐다면 월드 공간의 공용 기즈모 하나로 함께 변형합니다. → [다중 메쉬](/guides/multi-mesh)

## 모달 변형 (G / R / S) {#모달-변형}

블렌더식 `G`(이동), `R`(회전), `S`(스케일)입니다. 선택이 있는 상태에서 씬뷰에 커서를 두고 누르면 마우스만으로 변형이 시작됩니다.

모달 중에는 이렇게 조작합니다.

- `X` / `Y` / `Z`: 축 구속. 같은 키를 한 번 더 누르면 로컬 축에서 월드 축으로 바뀝니다.
- `Shift` + 축: 그 축을 뺀 평면으로 구속합니다.
- 숫자 입력: 정확한 값을 넣습니다. 회전은 도 단위입니다.
- `Enter` 또는 좌클릭: 확정
- `Esc` 또는 우클릭: 취소

모달 한 번이 되돌리기 한 단계입니다. 여러 메쉬를 함께 다루면 로컬 축이 하나로 정해지지 않으므로 월드 축을 씁니다.

:::note[`R`은 두 가지 일을 합니다]
`R`은 **선택이 있고 커서가 씬뷰 위에 있을 때만** 회전 모달입니다. 그 밖에는 Unity식 `R` 스케일 기즈모로 동작합니다.
:::

## 프로포셔널 편집 {#프로포셔널-편집}

`O`를 누르면 프로포셔널 편집이 켜집니다. 선택하지 않은 주변 정점이 반경 안에서 부드럽게 따라옵니다.

- `연결된 것만` 켜짐: 토폴로지 거리로 계산합니다. 겹쳐 있는 다른 파츠가 딸려오지 않습니다.
- `연결된 것만` 꺼짐: 공간 거리로 계산합니다.

반경은 `[` `]`로 조절합니다. `연결된 것만` 설정은 씬뷰 오버레이와 쉽게 시작 보기의 `자세한 설정`에도 있습니다.

[마스크 모드](/guides/sculpt#마스크-모드)로 마스크한 정점은 프로포셔널 영향에서 제외됩니다.

## 대칭

`대칭`에서 X / Y / Z를 조합합니다. 씬뷰 단축키는 `Alt+Shift+X` · `Alt+Shift+Y` · `Alt+Shift+Z`입니다.

`선택·이동` 탭의 대칭은 **선택을 늘리지 않습니다.** 선택한 요소를 변형한 결과를 로컬 축 반대편에 그대로 적용합니다. 대칭면 위의 중앙 정점은 평면에 고정됩니다.

## 피벗 {#피벗}

회전과 스케일의 기준점을 고릅니다. 기즈모와 `G`/`R`/`S` 모달 양쪽에 함께 적용됩니다.

| 모드 | 기준 |
|---|---|
| 중앙점 | 선택 요소의 평균 위치 |
| 개별 원점 | 각 요소가 자기 자리를 기준으로 |
| 활성 요소 | 마지막에 고른 요소 |
| 바운딩 박스 중심 | 선택을 감싸는 상자의 가운데 |

여러 메쉬를 함께 다룰 때 `메쉬별 균등 피벗`을 켜면 공용 피벗을 정점 수가 아니라 메쉬마다 같은 비중으로 계산합니다.

## 칠한 영역 정리 {#칠한-영역-정리}

`선택·이동` 탭의 **칠한 영역 정리**는 선택한 대상 모두에 적용합니다. 패널 상단에 적용 대상 목록이 나옵니다.

1. 영역을 칠하거나, 기존 정점·엣지·페이스 선택에 강도를 적용합니다.
2. 파랑은 처리할 영역, 초록은 보호할 영역입니다. 삭제 모드에서는 주황 면이 실제로 지워질 면입니다.
3. `Ctrl`은 지우기, `Shift`는 영역의 강도를 부드럽게 합니다. `Esc`는 현재 스트로크를 취소합니다.

칠한 영역으로 할 수 있는 일은 다음과 같습니다.

- **칠한 면 삭제**: 칠한 삼각형을 지우고 쓰이지 않는 정점을 정리합니다.
- **칠한 부분을 슈링크 키로 숨기기**: 옷이나 헤어 안쪽으로 들어가는 새 표정 키를 만듭니다. 기존 기본 정점은 그대로 두고, 키 100%에서 미리 봅니다.
- **부분 간소화**: 칠한 강도와 보호 강도를 반영해 정점을 줄입니다. `감소 결과 계산`으로 결과를 먼저 계산하고, `미리보기 결과 적용`으로 적용합니다. 감소한 뒤 같은 영역에 Shrink 키를 만들 수도 있습니다.

주의할 점입니다.

- 기존 표정이 움직이는 정점을 보호하는 옵션은 별도로 있고 기본으로 켜져 있습니다. 얼굴 이름이나 머리 본으로는 보호하거나 제외하지 않습니다.
- UV 이음새, 재질 경계, 열린 경계와 큰 본 웨이트 차이는 보존되므로 목표보다 덜 줄어들 수 있습니다. 목표와 실제 정점 수를 함께 확인하세요.
- 남는 정점의 UV8, 색, 노멀, 탄젠트, 임의의 본 영향, 모든 셰이프 프레임은 원래 값으로 보존합니다.
- 칠한 영역은 세션의 편집 상태입니다. 메쉬의 색 채널을 덮어쓰지 않습니다. 결과는 `메쉬 저장`으로 보관합니다.

## 숨기기 {#숨기기}

| 버튼 | 키 |
|---|---|
| 선택 숨기기 | `H` |
| 선택 외 숨기기 | `Shift+H` |
| 모두 표시 | `Alt+H` |

:::note[숨기기는 되돌리기 대상이 아닙니다]
숨김은 메쉬 데이터가 아니라 편집 세션의 표시 상태입니다. `Ctrl+Z` 대상이 아니며, 구조가 바뀌면(삭제·분리·병합) 자동으로 풀립니다.
:::

## 노멀 {#노멀}

| 항목 | 하는 일 |
|---|---|
| 노멀 표시 | 씬뷰에 노멀 방향을 그립니다. 길이를 조절할 수 있습니다 |
| 노멀 뒤집기 | 선택 페이스의 winding을 반전합니다 |
| 노멀 재계산 | 선택 정점의 노멀을 다시 계산합니다 |

뒤집기는 블렌드쉐이프의 노멀·탄젠트 델타까지 함께 반전하므로, 표정 키가 있는 메쉬에서도 안쪽 면이 어긋나지 않습니다.

## 삭제 {#삭제}

`X` 또는 `Delete`로 선택한 페이스를 지웁니다. 지운 뒤 그 페이스만 쓰던 정점은 남아 있다가, `메쉬 저장`할 때 한 번 정리됩니다. → [사용되지 않는 정점 정리](/internals/bake#고아-정점-정리)

### 선택 분리·선택 삭제 버튼 {#선택-분리-선택-삭제-버튼}

면을 고르면 선택 도구 아래에 `선택 분리 (P)`와 `선택 삭제 (X · N 페이스)` 버튼도 나타납니다. 접힌 `메쉬 작업` 섹션(`쉽게 시작`에서는 `자세한 설정` 안)의 같은 명령과 같은 동작이며, 누른 결과는 버튼 아래에 한동안 표시됩니다.

선택 확장·축소·연결·그룹 배정이 아무것도 바꾸지 않으면 이유를 알려 줍니다. 예: `이미 모두 선택되어 있어요.` · `줄일 수 있는 선택이 없어요.` · `선택은 이미 연결되어 있어요.` · `선택한 면은 이미 G{n}에 있어요. 바뀐 것이 없어요.`

## 분리 {#분리}

| 조작 | 키 | 결과 |
|---|---|---|
| 선택 분리 | `P` | 선택한 요소를 떼어냅니다 |
| 아일랜드 분리 | `Shift+P` | 선택 영역을 연결 덩어리별로 나눠 떼어냅니다 |
| 그룹별 분리 | 그룹 G0~G9 | 면을 그룹에 배정한 뒤 한 번에 나눕니다 |

그룹별 분리에서 G0은 원본에 남고, G1~G9는 각각 조각이 됩니다.

떼어낸 조각은 씬에 **미저장 조각**으로 나타나고, `메쉬 저장`할 때 원본 옆에 `<이름>_Part….asset`으로 저장됩니다. 저장하기 전에 `편집 버리기`를 누르면 원본을 되돌리고 미저장 조각을 지웁니다.

보존되는 것: 정점, 노멀, 탄젠트, UV0~UV3, 컬러, 서브메쉬·재질 대응, bindpose, 정점마다의 본 영향 수와 값 그대로의 본 웨이트(4개를 넘는 영향 포함), 블렌드쉐이프 프레임.

분리 작업 전체가 하나의 되돌리기 단계입니다. 도중에 실패하면 원래 상태로 되돌리고 만들다 만 파일도 지웁니다.

:::caution[떼어낸 파트의 본 영향]
떼어낸 `_Part` 조각은 원본의 본 영향 개수를 그대로 옮깁니다. 4슬롯으로 줄이지 않습니다. 원본 쪽은 그대로입니다. → [현재 제한](/limitations)
:::

`Ctrl`이나 `Cmd`가 함께 눌린 조합(`Ctrl+P`, `Ctrl+R`, `Ctrl+X` 등)은 Unity 단축키로 남으며 선택·이동 동작을 실행하지 않습니다. 예외는 `Ctrl+A`, `Ctrl+I`, `Ctrl` + `+`/`-`입니다.

## 거리로 병합 {#거리로-병합}

`거리로 병합`은 `병합 거리` 안에 있는 중복 정점을 하나로 합칩니다. 삭제나 분리 뒤에 남은 중복을 정리할 때 씁니다.

:::note[UV가 다르면 합치지 않습니다]
위치가 같아도 UV가 다르면 합치지 않습니다. 그래야 UV 심이 살아남고 텍스처가 깨지지 않습니다. 같은 이유로 블렌드쉐이프 델타가 크게 다른 정점도 합치지 않습니다.
:::

본 웨이트와 블렌드쉐이프는 유지됩니다.
