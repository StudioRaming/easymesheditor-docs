# 편집

**이 문서를 읽으면** 정점·엣지·페이스를 고르는 법, 기즈모와 블렌더식 모달 변형의 차이, 엣지 루프를 Alt 클릭으로 잡는 규칙, 숨기기·피벗·노멀·병합·분리까지 `편집` 탭의 모든 동작을 알 수 있습니다.

## 요소 모드 {#요소-모드}

| 버튼 | 키 |
|---|---|
| `정점 (1)` | `1` |
| `엣지 (2)` | `2` |
| `페이스 (3)` | `3` |

선택 상태는 `선택 — 정점 {0} · 엣지 {1} · 페이스 {2}` 로 표시됩니다.

## 선택 {#선택}

| 조작 | 결과 |
|---|---|
| 클릭 | 교체 선택 |
| `Shift`+클릭 또는 `Ctrl`+클릭 | 토글 |
| 더블클릭 또는 `L` | 커서 아래 연결 요소 전체 선택 (`링크드 선택 (L)`) |
| `Shift+L` | 연결 요소 해제 |
| `B` 또는 빈 공간 드래그 | 박스 선택 (`Shift`=추가, `Ctrl`=제거) |
| `A` / `Alt+A` | `전체 선택 (A)` / `선택 해제 (Esc)` |
| `Ctrl+I` | `반전 (Ctrl+I)` |

`B`를 누르면 창이 `박스 선택 준비 — 씬뷰에서 드래그 · Shift=추가 · Ctrl/Cmd=제거 · Esc/B=취소` 로 알려 줍니다. 박스 선택은 삼각형의 변이 사각형에 걸친 경우도 잡습니다.

:::note[UV 심 정점은 함께 잡힙니다]
Unity 메쉬는 UV 경계에서 같은 위치의 정점이 여러 개로 쪼개져 있습니다. 선택은 위치를 기준으로 그 무리 전체를 함께 잡으므로, 화면에서 점 하나를 골랐는데 뒤에서 실제로는 서너 개가 함께 움직입니다. → [웰드 그룹](/internals/session-and-undo#웰드-그룹)
:::

X-Ray(`Alt+Z`)가 꺼져 있으면 가려진 요소는 표시도 선택도 되지 않고, 켜면 뒷면까지 투과해 선택합니다.

### 엣지 루프와 엣지 링 {#엣지-루프와-엣지-링}

- `Alt+클릭` (누른 자리에서 움직이지 않고 떼기) — 엣지 루프
- `Ctrl+Alt+클릭` — 엣지 링
- 둘 다 `Shift`를 함께 누르면 기존 선택에 추가

:::caution[`Alt+드래그`는 씬 회전 그대로입니다]
Unity의 씬 회전을 뺏지 않기 위해, 루프 선택은 **드래그하지 않은 클릭**에서만 일어납니다. `Alt`를 누른 채 조금이라도 끌면 평소처럼 카메라가 돕니다.
:::

루프와 링은 극점(폴)과 경계에서 멈춥니다.

### 선택 확장과 축소

- `Ctrl` + `+` — `선택 확장 (Ctrl++)`
- `Ctrl` + `-` — `선택 축소 (Ctrl+-)`

숫자패드의 `+` `-` 도 동작합니다.

## 기즈모 {#기즈모}

| 버튼 | 키 |
|---|---|
| `보기 (Q)` | `Q` |
| `이동 (W)` | `W` |
| `회전 (E)` | `E` |
| `스케일 (R)` | `R` |

Unity의 기본 도구 배치와 같습니다. 본이 있는 스킨드 메쉬에서도 안전하게 역스킨을 적용해 변형하므로, 포즈가 잡힌 상태에서 화면에 보이는 대로 끌면 됩니다.

여러 메쉬에서 각각 요소를 골랐다면 월드 공간의 공용 기즈모 하나로 함께 변형합니다. → [다중 메쉬](/guides/multi-mesh)

## 모달 변형 {#모달-변형}

블렌더식 `G` / `R` / `S` 입니다. 선택이 있는 상태에서 씬뷰에서 누르면 마우스만으로 변형이 시작됩니다.

| 키 | 동작 |
|---|---|
| `G` | `이동 (G)` |
| `R` | `회전 (R)` |
| `S` | `스케일 (S)` |

모달 중에는 이렇게 조작합니다 — `X/Y/Z=축(두 번=월드) · Shift+축=평면 · 숫자=수치 입력 · Enter/좌클릭=확정 · Esc/우클릭=취소`

- 같은 축 키를 한 번 더 누르면 로컬 축에서 월드 축으로 바뀝니다 (`로컬` / `월드` 로 표시).
- `Shift+X`는 X를 뺀 평면으로 구속합니다 (`{0} 제외 평면({1})`).
- 숫자를 치면 정확한 값이 들어갑니다. 회전은 `도` 단위입니다.
- 여러 메쉬를 함께 다루면 로컬 축이 하나로 정해지지 않으므로 `여러 메쉬 → 월드 축` 으로 폴백합니다.

:::note[`R` 이 두 가지 일을 합니다]
`R` 은 **선택이 있고 커서가 씬뷰 위에 있을 때만** 회전 모달입니다. 그 밖에는 기존대로 Unity식 `R` = 스케일 기즈모로 동작합니다.
:::

모달 한 번이 되돌리기 한 단계입니다. 대칭과 프로포셔널 편집은 기즈모와 완전히 같게 적용됩니다.

## 프로포셔널 편집 {#프로포셔널-편집}

`프로포셔널 편집 (O)` 을 켜면 선택하지 않은 주변 정점이 `반경` 안에서 부드럽게 따라옵니다. 감쇠는 스무스 곡선입니다.

- `연결된 것만` **켜짐** — 토폴로지 거리로 계산합니다. 겹쳐 있는 다른 파츠가 딸려오지 않습니다.
- `연결된 것만` **꺼짐** — 공간 거리로 계산합니다.

반경은 `[` `]` 로 조절합니다(프로포셔널이 꺼져 있으면 같은 키가 정점 표시 크기를 조절합니다).

[마스크 모드](/guides/sculpt#마스크-모드)로 어둡게 해 둔 정점은 프로포셔널 영향에서 제외됩니다.

## 대칭

`대칭` X / Y / Z 를 조합합니다. 씬뷰 토글은 `Shift+Alt+X` · `Shift+Alt+Y` · `Shift+Alt+Z` 입니다.

편집 탭의 대칭은 **선택을 늘리지 않습니다.** 선택한 요소를 변형한 결과를 로컬 축 반대편에 그대로 적용하는 방식입니다. 대칭면 위의 중앙 정점은 평면에 고정됩니다.

## 피벗 {#피벗}

`피벗` 에서 회전·스케일의 기준점을 고릅니다. 기즈모와 `G`/`R`/`S` 모달 양쪽에 함께 적용됩니다.

| 모드 | 기준 |
|---|---|
| `중앙점` | 선택 요소의 평균 위치 |
| `개별 원점` | 각 요소가 자기 자리를 기준으로 |
| `활성 요소` | 마지막에 고른 요소 |
| `바운딩 박스 중심` | 선택을 감싸는 상자의 가운데 |

여러 메쉬를 함께 다룰 때 `메쉬별 균등 피벗` 을 켜면 메쉬마다 자기 피벗을 씁니다.

## 숨기기 {#숨기기}

| 버튼 | 키 |
|---|---|
| `숨기기 (H)` | `H` |
| `선택 외 숨기기 (Shift+H)` | `Shift+H` |
| `모두 표시 (Alt+H)` | `Alt+H` |

숨긴 개수는 `숨김 {0}개 — Alt+H 로 모두 표시` 로 표시됩니다.

:::note[숨기기는 되돌리기 대상이 아닙니다]
숨김은 메쉬 데이터가 아니라 편집 세션의 표시 상태입니다. 블렌더와 같게 `Ctrl+Z` 대상이 아니며, 구조가 바뀌면(삭제·분리·병합) 자동으로 풀립니다.
:::

## 노멀 {#노멀}

| 항목 | 하는 일 |
|---|---|
| `노멀 표시` | 씬뷰에 노멀 방향을 그립니다. `노멀 길이` 로 길이 조절 |
| `노멀 뒤집기` | 선택 페이스의 winding을 반전합니다 |
| `노멀 재계산` | 선택 정점의 노멀을 스무스로 다시 계산합니다 |

결과는 `페이스 {0}개의 노멀을 뒤집었습니다` · `정점 그룹 {0}개의 노멀을 재계산했습니다` 로 보고됩니다.

뒤집기는 블렌드쉐이프의 노멀·탄젠트 델타까지 함께 반전하므로, 표정 키가 있는 메쉬에서도 안쪽 면이 어긋나지 않습니다.

## 삭제 {#삭제}

`선택 삭제 (X · {0} 페이스)` — `X`, `Delete`, `Backspace` 모두 동작합니다. 선택된 페이스를 지웁니다.

지운 뒤에도 그 페이스만 쓰던 정점은 정점 버퍼에 남습니다. 이 고아 정점은 `Bake` 할 때 한 번 정리됩니다. → [고아 정점 정리](/internals/bake#고아-정점-정리)

## 분리 {#분리}

| 버튼 | 키 | 결과 |
|---|---|---|
| `선택 분리 (P)` | `P` | 선택 요소를 새 오브젝트로 떼어냅니다 |
| `아일랜드 분리 (Shift+P)` | `Shift+P` | 선택 영역을 연결 덩어리별로 나눠 떼어냅니다 |

분리된 오브젝트와 함께 원본 옆에 `<원본명>_Part.asset` 이 만들어집니다. → [생성되는 파일](/reference/output-files)

보존되는 것: 정점, 노멀, 탄젠트, UV0~UV3, 컬러, 서브메쉬·재질 대응, bindpose, 본 웨이트, 블렌드쉐이프 프레임.

분리 전체가 하나의 되돌리기 단계입니다. 도중에 실패하면 `분리에 실패해 되돌렸습니다: {0}` 와 함께 원래 상태로 롤백되고 만들다 만 `_Part.asset` 도 지워집니다.

:::caution[분리된 파트의 본 영향은 4개로 제한됩니다]
Unity 2020.1 이상에서 정점당 4개를 넘는 본 영향을 가진 메쉬를 분리하면, **떼어낸 파트 쪽은 레거시 4슬롯으로 제한**됩니다. 원본 쪽은 그대로입니다. → [제한 사항](/limitations)
:::

## 거리로 병합 {#거리로-병합}

`정점 병합` 섹션의 `거리로 병합` 은 `병합 거리` 안에 있는 중복 정점을 하나로 합칩니다. 삭제·분리 뒤에 남은 중복을 정리할 때 씁니다.

결과는 `정점 {0}개를 병합했습니다` · `병합할 정점이 없습니다` · `정점 병합에 실패해 메쉬를 그대로 두었습니다` 중 하나로 보고됩니다.

:::note[UV가 다르면 합치지 않습니다]
위치가 같아도 UV0가 다르면 병합 후보에서 빠집니다. 그래야 UV 심이 살아남고 텍스처가 깨지지 않습니다. 같은 이유로, 블렌드쉐이프 델타가 메쉬 크기 대비 눈에 띄게 다른 정점도 병합하지 않습니다.
:::

본 웨이트와 블렌드쉐이프는 유지됩니다. 합쳐진 무리의 속성은 가장 작은 인덱스의 정점 것을 씁니다.
