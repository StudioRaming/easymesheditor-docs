## 업그레이드 시 확인할 것

:::caution[편집 세션을 열어 둔 채 업데이트하지 마세요]
열려 있는 편집은 `메쉬 저장`으로 저장하거나 `편집 버리기`로 버린 뒤 창을 닫고 업데이트하세요. 소스(`.cs`) 판을 설치했던 프로젝트는 먼저 소스 판을 지워야 합니다. → [설치](/getting-started/installation#0-1x에서-올리기)
:::

:::caution[탭과 버튼 이름이 바뀌었습니다]
창의 탭은 `모양 다듬기` · `선택·이동` · `표정 키` · `뼈 연결`입니다. 버튼은 `불러오기` · `메쉬 저장` · `편집 버리기`이고, 새 키 저장은 `새 키로 저장`입니다. 이전 문서의 이름은 이 문서들에서 대응하는 이름으로 읽으세요. → [창 사용법](/guides/window)
:::

:::caution[같은 원본을 쓰는 렌더러는 각각 따로 편집합니다]
0.1.x에서는 같은 원본 메쉬를 쓰는 렌더러 중 하나만 열렸습니다. 1.0.0에서는 각각 따로 불러와 따로 편집하고, 저장 결과도 따로 나옵니다. → [다중 메쉬](/guides/multi-mesh)
:::

:::caution[작업을 버리는 확인창에서 Enter와 Esc는 작업을 남깁니다]
`Enter`는 `그대로 두기`, `Esc`는 `취소`입니다. 두 키 모두 작업을 그대로 두며, 실행하려면 동작 이름이 적힌 버튼을 눌러야 합니다.
:::

## 새 기능

- **Unity 6 지원**: Unity 6000.0과 6000.3 (LTS)을 지원합니다. 지원 범위는 Unity 2019.4, 2021.3, 2022.3, 6000.0, 6000.3 (LTS)입니다. → [설치](/getting-started/installation)
- **여러 메쉬 동시 편집**: MeshRenderer와 SkinnedMeshRenderer를 Hierarchy나 후보 목록에서 골라 함께 편집합니다. → [다중 메쉬](/guides/multi-mesh)
- **칠한 영역 정리**: 칠한 면을 지우거나, 칠한 부분을 Shrink 키로 숨기거나, 부분 간소화로 정점을 줄일 수 있습니다. 기존 표정이 움직이는 정점을 지키는 옵션은 기본으로 켜져 있습니다. → [선택·이동](/guides/edit#칠한-영역-정리)
- **펜 필압 크기와 세기**: 필압을 `필압 크기`와 `필압 세기`에 각각 0~100%로 적용할 수 있습니다. → [모양 다듬기](/guides/sculpt#필압-적용량)
- **메쉬 분리**: 선택 분리, 연결 아일랜드 분리, 그룹별 분리(G0~G9)를 쓸 수 있습니다. 조각은 메쉬 저장 때 파일로 나옵니다. 분리할 때 UV, 블렌드쉐이프 프레임, 정점당 영향 본 수를 그대로 옮깁니다. → [선택·이동](/guides/edit#분리)
- **뼈 연결 탭 재구성**: 본 트리와 히트맵, 자동 정규화, 최대 영향 본 수, 대칭 페인트, 본 잠금, 본 웨이트 합치기, 다른 메쉬에서 웨이트 가져오기를 한 탭에서 씁니다. → [뼈 연결](/guides/weight-paint)
- **표정 키 기능 확장**: 미러 키 자동 생성, 델타 히트맵, 다른 메쉬에서 키 가져오기, 키 잠금, 적용값 합치기, 여러 키 일괄 처리를 씁니다. → [표정 키](/guides/blendshape)
- **씬뷰 오버레이 위에 그리기**: Unity 2021.2 이상에서는 씬뷰의 힌트, 도구 패널, 단축키 시트가 Unity 기본 씬뷰 오버레이 위에 그려집니다. 2019.4와 2020에서는 기존 방식으로 그립니다.
- **Connected Only 위치 추가**: `연결된 것만` 옵션을 씬뷰 오버레이와 쉽게 시작 보기의 `자세한 설정`에서도 켤 수 있습니다.
- **편집 내용 보존**: 편집 중인 메쉬는 Play, 창 닫기, 씬 닫기, 스크립트 리로드, 에디터 종료 때 묻지 않고 보존했다가, 돌아오면 복원합니다. 미저장 편집이 있으면 60초 간격으로 체크포인트를 남기고, 비정상 종료 뒤에는 복구 배너로 복원을 고를 수 있습니다. → [세션과 되돌리기](/internals/session-and-undo#자동-보존과-복원)
- **편집 중 씬 저장**: 편집 중에 씬이나 프리팹을 저장하면 원본 메쉬를 기록하고, 편집 세션은 그대로 이어집니다.
- **저장 이름 규칙**: 메쉬 저장 결과는 원본 옆의 `<원본명>_Edit.asset`에 저장됩니다. 다른 사람의 에셋은 덮어쓰지 않습니다. → [생성되는 파일](/reference/output-files)

## 변경

- 되돌릴 수 있는 동작은 확인창 없이 바로 실행됩니다. 에셋을 쓰거나 작업을 버리는 동작만 확인을 묻습니다. → [세션과 되돌리기](/internals/session-and-undo)
- `Esc`는 진행 중인 스트로크나 크기 조절만 취소하고, 표정 키 편집은 버리지 않습니다.
- 저장하지 않은 편집이 있으면 다른 대상을 바로 불러오지 않고 안내를 띄웁니다.
- 이름이 같은 표정 키를 만들 때와 키 편집을 취소할 때 확인을 묻습니다. 확인창의 `Enter`와 `Esc` 동작은 위 `업그레이드 시 확인할 것`을 보세요.
