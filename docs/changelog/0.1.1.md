## 업그레이드 시 확인할 것

:::caution[`Bake` 할 때 사용되지 않는 정점이 정리됩니다]
페이스를 지운 뒤 남아 있던 고아 정점이 `Bake` 출력에서 제거됩니다. 정점 인덱스가 바뀌므로, 정점 인덱스에 의존하는 외부 도구가 있다면 다시 확인하세요. → [문서](/internals/bake#고아-정점-정리)
:::

:::caution[`웨이트` 탭에 `자동 정규화` 옵션이 생겼습니다]
기본값은 켜짐이라 기존 동작과 같습니다. 끄면 순수 가감산이 되고, 웨이트 합이 1이 아닌 채로 남을 수 있습니다. → [문서](/guides/weight-paint#자동-정규화와-최대-영향-본-수)
:::

:::caution[`편집` 탭에서 `Alt+클릭` 이 엣지 루프를 선택합니다]
드래그하지 않은 `Alt+클릭` 에만 반응하므로 `Alt+드래그` 씬 회전은 그대로입니다. `Alt` 를 누른 채 클릭하던 습관이 있다면 선택이 바뀔 수 있습니다. → [문서](/guides/edit#엣지-루프와-엣지-링)
:::

:::caution[`Bake` 출력의 메쉬 이름이 파일 이름과 같아집니다]
에셋 안의 메쉬 오브젝트 이름을 파일 이름에 맞춥니다. 메쉬 이름 문자열로 에셋을 찾는 스크립트가 있다면 확인하세요. → [문서](/internals/bake)
:::

## 새 기능

- **`G` / `R` / `S` 모달 변형** — 축 구속과 수치 입력이 되는 블렌더식 이동·회전·스케일. → [문서](/guides/edit#모달-변형)
- **엣지 루프와 엣지 링** — `Alt+클릭` 으로 루프, `Ctrl+Alt+클릭` 으로 링을 잡습니다. → [문서](/guides/edit#엣지-루프와-엣지-링)
- **선택 확장 / 축소** — `Ctrl` + `+` / `-`. → [문서](/guides/edit#엣지-루프와-엣지-링)
- **숨기기** — `H` · `Shift+H` · `Alt+H`. 되돌리기 대상이 아니며 구조가 바뀌면 자동 해제됩니다. → [문서](/guides/edit#숨기기)
- **피벗 모드 4종** — `중앙점` · `개별 원점` · `활성 요소` · `바운딩 박스 중심`. → [문서](/guides/edit#피벗)
- **노멀 표시 · 뒤집기 · 재계산** — 뒤집기는 블렌드쉐이프 노멀·탄젠트 델타까지 함께 반전합니다. → [문서](/guides/edit#노멀)
- **`거리로 병합`** — UV가 다르면 합치지 않아 UV 심이 보존됩니다. → [문서](/guides/edit#거리로-병합)
- **`핀치 (4)` · `인플레이트 (5)` 브러시** 추가. → [문서](/guides/sculpt#브러시)
- **브러시 마스크와 박스 마스크** — 아일랜드 클릭에 더해 반경으로 칠하기와 화면 사각형 선택. → [문서](/guides/sculpt#마스크-모드)
- **`대칭 평면 표시`** — 미러 평면과 반대편 브러시 자리를 씬뷰에 그립니다. → [문서](/guides/sculpt#대칭)
- **`브러시 프리셋` 3슬롯** — 자주 쓰는 브러시 설정을 저장하고 불러옵니다. → [문서](/guides/sculpt#브러시-프리셋)
- **미러 키 생성** — 이름의 좌우 표기를 뒤집어 반대편 표정 키를 만듭니다. → [문서](/guides/blendshape#미러-키)
- **다른 메쉬에서 키 가져오기** — 얼굴 메쉬의 표정 키를 근접 매핑으로 옮깁니다. → [문서](/guides/blendshape#키-전송)
- **솔로 프리뷰 · 키 잠금 · 접두사 그룹 · 델타 히트맵 · `확장 범위`** — 목록이 길어져도 다룰 수 있게. → [문서](/guides/blendshape#솔로-프리뷰)
- **여러 키 일괄 처리** — `Ctrl` · `Shift` 클릭으로 골라 값·잠금·순서·삭제를 한 번에. → [문서](/guides/blendshape#다중-선택)
- **다른 메쉬에서 웨이트 가져오기** — 아바타 바디의 웨이트를 의상으로 옮기는 의상 맞춤의 기본 작업. → [문서](/guides/weight-paint#다른-메쉬에서-웨이트-가져오기)
- **`대칭 페인트`** — 반대편 정점에 좌우 대응 본을 함께 칠합니다. → [문서](/guides/weight-paint#대칭-페인트)
- **`본 웨이트 합치기`** — 본을 지우기 전에 웨이트를 부모나 다른 본으로 옮깁니다. → [문서](/guides/weight-paint#본-웨이트-합치기)
- **`블러 (4)` · `평균 (5)` 웨이트 브러시**와 **본 잠금**. → [문서](/guides/weight-paint#브러시)
- **`최대 영향 본 수`** — 한 정점이 가질 본의 개수를 1~4로 제한합니다. → [문서](/guides/weight-paint#자동-정규화와-최대-영향-본-수)
- **미저장 배지** — `저장됨` · `변경 있음` · `트랜잭션 중`. → [문서](/guides/window#상태-배지)
- **`불러올 후보` 목록** — `Load` 전에 정점 수와 중복·Read/Write 경고를 확인합니다. → [문서](/guides/window#불러올-후보)
- **`Keys` 단축키 시트** — 지금 탭의 단축키를 씬뷰에서 바로 봅니다. → [문서](/guides/window#단축키-시트)
- **컴팩트 모드** — 창을 좁게 도킹하면 헤더와 가이드를 접어 본문을 넓힙니다. → [문서](/guides/window#컴팩트-모드)
- **Bake 결과표** — 여러 메쉬를 구웠을 때 성공·실패를 한 표로 정리합니다. → [문서](/guides/window)

## 변경

- 축 대칭 단축키가 `Shift+Alt+X` / `Y` / `Z` 로 통일됐습니다. 단독 `X` `Y` `Z` 와 `Alt+Z` 는 Unity 툴 핸들과 X-Ray로 남겨 둡니다. → [문서](/reference/shortcuts#스컬프트)
- `R` 은 선택이 있고 커서가 씬뷰 위일 때만 회전 모달이고, 그 밖에는 기존대로 스케일 기즈모입니다. → [문서](/reference/shortcuts#편집)
- 씬뷰 상태 표시가 상단 대상 행과 겹치지 않게 정리됐습니다. → [문서](/guides/window)
- 구조 되돌리기 스냅샷에 메모리 상한이 생겨, 넘으면 오래된 기록부터 버리고 알려 줍니다. → [문서](/internals/session-and-undo#되돌리기)

## 개선

- 여러 메쉬의 삭제·분리·일괄 키 작업이 하나의 되돌리기 단계로 묶이고, 하나라도 실패하면 전부 되돌아갑니다. → [문서](/guides/multi-mesh#원자적-롤백)
- 웨이트 전송에서 소스와 대상의 트랜스폼이 다르면 경고하고, 바인드포즈 로컬 공간으로 맞추는 옵션을 제공합니다. → [문서](/guides/weight-paint#전송-공간)
- 프레임이 여러 개인 키를 편집하면 경고하고, 저장할 때 중간 프레임을 변화량에 비례해 갱신합니다. → [문서](/guides/blendshape#다중-프레임)
- 같은 원본 메쉬를 쓰는 렌더러가 여럿이어도 출력 파일이 서로 덮어쓰지 않습니다. → [문서](/reference/output-files#provenance와-owner)
- 이름에 쓸 수 없는 문자가 든 블렌드쉐이프 키는 저장할 때 자동으로 정리됩니다. → [문서](/guides/blendshape#새-쉐이프-조형)
- 씬뷰 피킹과 오버레이가 화면 밖 요소를 건너뛰어 고밀도 메쉬에서 가벼워졌습니다. → [문서](/limitations)
- `Bake` 에 진행률 표시가 붙었습니다. → [문서](/internals/bake)
- 브러시 필압이 한 스트로크 동안 유지되어 값이 튀지 않습니다. → [문서](/guides/sculpt#브러시-설정)

## 수정

- **웨이트를 한 번 칠하면 메쉬 전체의 본 영향이 4개로 잘리던 문제**를 고쳤습니다. 이제 칠하지 않은 정점의 5개 이상 영향은 그대로 보존됩니다. → [문서](/internals/bake#가변-본-웨이트)
- **스크립트를 저장해 에디터가 다시 컴파일되면 편집이 경고 없이 사라지던 문제**를 고쳤습니다. 리로드 직전에 자동 저장하고 끝나면 복원합니다. → [문서](/internals/session-and-undo#자동-저장과-복원)
- **삭제·분리를 되돌리면 5개 이상 본 영향과 UV4~UV7이 사라지던 문제**를 고쳤습니다. → [문서](/internals/session-and-undo#되돌리기)
- **Read/Write가 꺼진 메쉬를 `Load` 하면 렌더러가 고장난 상태로 남던 문제**를 고쳤습니다. 이제 안내와 함께 `Read/Write 켜기` 버튼을 보여 주고 원래대로 되돌립니다. → [문서](/getting-started/installation)
- **기존 키를 편집해도 그 키의 노멀 델타가 갱신되지 않던 문제**를 고쳤습니다. → [문서](/internals/bake)
- 되돌리기가 블렌드쉐이프 편집 시작 시점보다 앞으로 가면 편집을 조용히 진행하지 않고 취소합니다. → [문서](/internals/session-and-undo#트랜잭션)
- 컬러 채널이 8비트인 메쉬에 float 컬러를 쓰다 나던 런타임 오류를 고쳤습니다. → [문서](/internals/bake)
- 분리에 실패하면 만들다 만 `_Part.asset` 을 지우고 원래 상태로 되돌립니다. → [문서](/guides/edit#분리)
- 삭제·분리 뒤에 숨김 상태가 남아 있던 문제를 고쳤습니다. → [문서](/guides/edit#숨기기)
- 노멀을 뒤집을 때 블렌드쉐이프의 노멀·탄젠트 델타가 함께 반전되지 않던 문제를 고쳤습니다. → [문서](/guides/edit#노멀)
